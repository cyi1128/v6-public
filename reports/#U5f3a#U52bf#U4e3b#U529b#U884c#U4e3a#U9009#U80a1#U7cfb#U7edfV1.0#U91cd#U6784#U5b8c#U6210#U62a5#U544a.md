本次重构将 QuantMonitorV6 从传统指标选股体系升级为**「强势主力行为识别系统」**。核心逻辑从"技术指标筛选"转变为"主力行为模式识别"，专注寻找有资金介入的强势股票，识别主力吸筹、洗盘、突破、二次启动等行为。

**核心原则**:
- 不是在旧策略上叠加，而是删除旧策略重新建立
- 实证主义驱动：所有逻辑可回测验证

- 所有UI数据来自真实计算，严禁Hardcode

## 四、三个核心模型实现

### 4.1 模型一：涨停回调模型（强势股低吸模型）

**核心逻辑**: 涨停/大阳启动 → 回调整理 → 缩量洗盘 → 关键位置支撑 → 再次启动

**识别条件**:
1. 近30个交易日内存在涨停（≥9.8%）或大阳线（≥5%）启动
2. 启动后出现调整（最大回撤1%-20%）
3. 调整过程中成交量持续下降（近期均量<前期70%）
4. 无连续放量下跌

**支撑判断**（4重支撑）:
- MA5附近支撑（2%容差）
- MA10附近支撑（2%容差）
- 前期涨停启动位置支撑（2%容差）
- 箱体底部支撑（2%容差）

**输出标签**: 【涨停回调】【缩量低吸】【强势洗盘】

**买点**:
- 缩量调整结束
- 重新站上5日线
- 次日回踩5日线不破
- 成交量重新放大

**风险**: 跌破涨停启动位置、跌破箱体底部、放量下跌

### 4.2 模型二：横盘箱体突破模型（二波启动模型）

**核心逻辑**: 强势上涨 → 横盘整理 → 缩量筑平台 → 突破箱体 → 第二波上涨

**识别条件**:
1. 前期有明显上涨趋势（近40日涨幅>15%）
2. 上涨后形成横盘箱体（10-30天，幅度3%-25%）
3. 箱体特点：高低点稳定、波动减少（后半段振幅<前半段1.2倍）、成交量缩小（<前期80%）、均线粘合（MA5/MA10差距<5%）

**三买点**:
- 第一买点：缩量结束，重新站上MA5
- 第二买点：放量突破箱体压力位（量能>箱体均量1.2倍）
- 第三买点：突破后回踩箱体顶部不破（回踩低点≥箱体顶98%）

**输出标签**: 【箱体突破】【二次启动】【平台蓄势】

**风险**: 跌破箱体底部、突破失败重新进入箱体

### 4.3 模型三：极限缩量量价突破模型（主力启动模型）

**核心逻辑**: 极限缩量筑底 → 量价齐升 → 突破压力 → 回踩确认 → 再次放量突破

**5阶段识别**:
- **阶段1 极限缩量筑底**: 成交量达阶段低位（低于前后5天均值50%）、股价横盘（波动<10%）、抛压减少
- **阶段2 量价齐升**: 股价上涨>5%、成交量同步增加（>前期1.3倍）、阳线增加
- **阶段3 突破压力**: 突破前期高点/箱体（>压力位1%）、成交量放大
- **阶段4 回踩确认**: 回踩突破位置（低点≥突破位97%）、成交量缩小（<突破前90%）、不跌破突破位
- **阶段5 再次放量突破**: 价格>突破位1.02倍、成交量>近5日均量1.3倍

**输出标签**: 【量价突破】【主力启动】【二次确认】

## 五、AI评分系统（总分100，6维度）

### 5.1 评分维度

| 维度 | 权重 | 评分逻辑 |
|------|------|----------|
| **主力行为结构** | 40分 | 匹配模型数量(≤20) + 阶段质量(≤10) + 主力资金痕迹(≤10) |
| **量价关系** | 20分 | 当日量价配合(≤10) + 近10日上涨/下跌量能比(≤10) |
| **趋势均线** | 15分 | 多头排列(≤8) + 价格位置(≤4) + 均线方向(≤3) |
| **涨停强势基因** | 10分 | 近60日涨停次数(≤6) + 近30日大阳线次数(≤4) |
| **技术指标确认** | 10分 | KDJ金叉/多头(≤5) + MACD金叉/多头(≤5) |
| **市场环境** | 5分 | 大盘涨跌环境（默认中性2.5分） |

### 5.2 评分等级

| 分数区间 | 等级 | 操作建议 |
|----------|------|----------|
| 90-100 | 强势启动候选 | 重点关注，可考虑介入 |
| 80-90 | 重点观察 | 加入观察池，等待买点确认 |
| 70-80 | 普通观察 | 普通观察，暂不介入 |
| 70以下 | 过滤 | 自动过滤，不进入股票池 |

### 5.3 评分理由生成
系统自动生成自然语言评分理由，包含匹配模型、主力行为特征、量价配合情况、趋势方向等，实现AI辅助解释。

## 六、全市场扫描流程

### 6.1 扫描流程
```
全市场股票（无数量限制）
    ↓
强势股初筛（排除ST/退市/价格异常/新股）
```

- **结果缓存**：5分钟缓存，避免重复计算
- **评分筛选**：支持70/80/90分三档筛选

### 7.1 区域颜色定义

| 颜色 | 区域类型 | 说明 |
|------|----------|------|
| 🟢 绿色 (#22c55e) | 缩量区域 | 成交量低于均量70%，持续≥3天 |

### 7.3 标注数据结构

```python
  markers: [{type(buy/risk), idx, date, price, label, model}]
```
