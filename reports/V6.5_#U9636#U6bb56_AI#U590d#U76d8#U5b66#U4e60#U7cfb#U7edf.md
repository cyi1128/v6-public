## 一、模块架构说明

### 1.1 设计原则

- **新增独立模块**：`AICaseLearning` 类，不修改现有标注模块 `kline_annotator.py`
- **真实数据**：案例库从通达信本地K线数据自动生成，不使用模拟数据
- **可扩展**：支持从K线标注、回测结果、扫描结果三种来源生成案例
- **DuckDB存储**：高性能列式数据库，支持快速检索和统计

### 1.2 核心类结构

```
AICaseLearning
├── __init__(db_path)                     # 初始化DuckDB连接
├── _init_db()                            # 创建案例库表和索引
├── add_case(case) → case_id              # 添加单个案例
├── batch_add_cases(cases) → count        # 批量添加
├── extract_features(kline, idx, ...) → CaseFeatures  # 特征提取（静态方法）
├── generate_cases_from_kline(...)        # 从K线标注/信号生成案例
├── generate_cases_from_backtest(...)     # 从回测交易生成案例
├── find_similar_cases(features, top_n, case_type) → List[SimilarCaseResult]
├── calculate_similarity(f1, f2) → float  # 计算两案例相似度
├── get_case_statistics(similar_cases) → CaseStatistics
├── get_library_stats() → CaseStatistics  # 全库统计
├── update_weights(case_id, actual_result) # 动态权重优化
└── get_all_cases() / clear_library()     # 调试方法
```

### 1.3 数据类

| 类 | 用途 | 字段数 |
|----|------|--------|
| `CaseFeatures` | 案例特征向量（基础信息+K线+均线+指标+量价+后续标签） | 35+ |
| `SimilarCaseResult` | 相似案例匹配结果（含各维度相似度） | 12 |
| `CaseStatistics` | 案例统计（成功率/平均涨幅/回撤/分布） | 11 |

## 三、特征提取方法

### 3.1 K线形态编码（5日）

每根K线编码为3字符：`阴阳(Y/N) + 实体大小(S/M/L) + 影线(U/D/B/N)`

- **阴阳**：收盘≥开盘为Y（阳），否则N（阴）
- **实体大小**：实体/振幅 <30%为S（小），30-60%为M（中），>60%为L（大）
- **影线**：上影>实体0.5倍为U，下影>实体0.5倍为D，都有为B，都无为N

示例：`YMD-YLN-YLD-YSN-YLN`（5日K线形态序列）

### 3.2 量能模式编码（5日）

2字符：`趋势(I/D/V/F) + 量能水平(H/M/L)`

- **趋势**：5日量能线性回归斜率 >0.05为I（递增），<-0.05为D（递减），标准差>0.3为V（波动），否则F（平稳）
- **水平**：最后一日量比 >1.5为H（高），<0.7为L（低），否则M（中）

### 3.3 均线排列

- **多头**：MA5 > MA10 > MA20
- **空头**：MA5 < MA10 < MA20
- **粘合**：其他情况

### 3.4 技术指标

复用 `strategy/base.py` 的 `TechnicalIndicators`：
- KDJ(13,3,3)
- MACD(8,21,5)
- RPS20：简化版（20日涨幅映射到0-100）

### 3.5 后续标签

对每个案例点，计算后续5/10/20日：
- **收益率**：(期末收盘 - 入场价) / 入场价 × 100%
- **最大回撤**：(期间最低 - 入场价) / 入场价 × 100%
- **成功标签**：后续5日涨幅 > 3% 记为成功

## 四、相似度算法

### 4.1 总相似度

```
总相似度 = 形态相似度 × 0.40 + 量价相似度 × 0.30 + 指标相似度 × 0.30
```

### 4.2 形态相似度（40%）

| 子项 | 权重 | 计算方式 |
|------|------|----------|
| 均线排列匹配 | 0.30 | 完全匹配+0.3，多头/粘合近似+0.15 |
| 5日K线形态匹配 | 0.40 | 逐位比较编码，匹配率×0.4 |
| 10日价格趋势接近 | 0.20 | max(0, 1-斜率差/5) |
| 当日涨跌幅接近 | 0.10 | max(0, 1-涨跌幅差/10) |

### 4.3 量价相似度（30%）

| 子项 | 权重 | 计算方式 |
|------|------|----------|
| 量比接近度 | 0.50 | min(量比)/max(量比) |
| 5日量能模式匹配 | 0.50 | 完全匹配+0.5，趋势相同+0.25 |

### 4.4 指标相似度（30%）

| 子项 | 权重 | 计算方式 |
|------|------|----------|
| KDJ接近度 | 0.40 | max(0, 1-K/D/J平均差/50) |
| MACD接近度 | 0.30 | 归一化相对差异 |
| RPS接近度 | 0.30 | max(0, 1-RPS差/50) |

### 4.5 动态权重

每个案例有 `feature_weight` 字段（默认1.0，范围0.5-1.5）：
- 成功案例（实际结果>0）：权重+0.1
- 失败案例（实际结果≤0）：权重-0.1
- 最终相似度 = 计算相似度 × feature_weight

## 八、集成方式说明

### 8.1 基本使用

```python
from strategy.ai_case_learning import AICaseLearning, CaseFeatures

# 初始化
learner = AICaseLearning()

# 从K线生成案例
cases = learner.generate_cases_from_kline("000001", kline_data, stock_name="平安银行")
learner.batch_add_cases(cases)

# 提取当前股票特征
cur = AICaseLearning.extract_features(kline_data, len(kline_data)-1,
                                       stock_code="000001", case_type="buy")

# 查找相似案例
similar = learner.find_similar_cases(cur, top_n=10, case_type="buy")

# 统计
stats = learner.get_case_statistics(similar)
print(f"成功率: {stats.success_rate:.1f}%, 平均5日: {stats.avg_5d_return:.2f}%")
```

| 现有模块 | 状态 | 集成方式 |

## 九、后续优化方向

1. **扩大案例库**：当前仅12只股票376案例，后续可扩展到全市场5000+股票，案例数可达10万+
2. **多信号类型**：当前仅B2（金叉）和S1（死叉），后续接入B1/B3/S2/S3/S4等更多信号
3. **深度学习匹配**：用自编码器将K线形态编码为低维向量，提升匹配精度
4. **时间衰减**：近期案例权重高于远期案例，适应市场风格变化
5. **行业匹配**：增加行业/板块维度，优先匹配同行业案例
6. **大盘环境匹配**：结合阶段4市场环境，只匹配相同市场环境下的案例
7. **实时学习**：每日扫描结束后自动将新信号加入案例库，持续积累
8. **权重自优化**：根据案例后续实际表现自动调整特征权重，形成闭环学习
