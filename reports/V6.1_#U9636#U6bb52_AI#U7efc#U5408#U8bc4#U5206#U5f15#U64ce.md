## 一、模块架构说明

### 1.1 设计目标

当前系统存在多个独立评分体系，各策略各自为政，缺乏统一的最终评分输出。V6.1 阶段2新增 **AI综合评分引擎**，融合所有策略评分，输出统一的最终评分和交易建议。

### 1.2 架构层次

```
策略层（强势主力 / 九重共振 / 五买 / 三倍量 / 回调五日线 / 缠论）
    │
    ▼
统一因子池（各策略评分 + 技术指标 + 市场环境）
    │
    ▼
AI综合评分引擎（加权融合 + 缺失自动调权 + 因子校验扣分）
    │
    ▼
最终输出（综合评分 + 等级 + 交易建议 + 各维度得分明细）
```

### 1.3 核心类

| 类名 | 说明 | 状态 |
|------|------|------|
| `AICompositeScoreEngine` | V6.1 新版综合评分引擎，四因子加权融合 | **新增** |
| `AICompositeScore` | 旧版三因子评分引擎（35/35/30权重） | 保留兼容 |
| `V61CompositeResult` | 新版评分结果数据类 | 新增 |
| `CompositeScoreResult` | 旧版评分结果数据类 | 保留兼容 |

### 1.4 设计原则

- **独立模块**：新增代码不修改现有策略核心逻辑
- **纯计算无副作用**：可被任何模块调用，不依赖全局状态
- **向后兼容**：保留旧版 `AICompositeScore` 类和 `get_ai_composite_score()` 函数
- **缺失容错**：某个策略评分缺失时自动调整权重，不影响总分
- **因子校验**：价格、成交量、均线趋势等基础因子作为校验项

## 二、评分融合逻辑和权重

### 2.1 默认权重配置

| 因子 | 权重 | 说明 | 数据来源 |
|------|------|------|----------|
| `force_behavior` | **0.30** | 强势主力行为评分（0-100） | `data/cache/scan_result_cache.json` → `score.total` |
| `nine_filter` | **0.30** | 九重共振综合评分（0-100） | `data/cache/nine_filter_scan_cache.json` → `score.total` |
| `ai_six_dim` | **0.25** | AI六维评分（0-100，六维原始0-120自动归一化） | `cache/ai_analysis/` → `attention_score` |
| `market_environment` | **0.15** | 市场环境评分（0-100，预留） | 可选输入，当前版本预留 |

### 2.2 加权计算公式

```
综合评分 = Σ(各因子原始评分 × 有效权重) - 校验扣分
```

其中**有效权重**根据可用因子动态计算：

1. 识别所有非空（非None、非0越界）的因子
2. 计算可用因子的默认权重之和
3. 每个可用因子的有效权重 = 默认权重 / 可用权重之和
4. 缺失因子不参与计算，其权重按比例分配给其他因子

**示例**：若仅有强势主力(0.30)和九重(0.30)两个评分可用：
- 可用权重之和 = 0.30 + 0.30 = 0.60
- 强势主力有效权重 = 0.30 / 0.60 = 0.50
- 九重有效权重 = 0.30 / 0.60 = 0.50
- 综合评分 = 强势评分 × 0.50 + 九重评分 × 0.50

### 2.3 因子校验扣分机制

在加权得分基础上，根据基础因子校验结果进行扣分：

| 校验项 | 扣分 | 条件 |
|--------|------|------|
| 价格无效 | -20分 | price 为空或 ≤ 0 |
| 均线空头排列 | -5分 | MA5 < MA10 < MA20 |
| 趋势不一致 | -3分 | 价格与均线方向矛盾（非数据不足情况） |

扣分后综合评分限制在 [0, 100] 区间内。

### 2.4 评分字段兼容映射

引擎支持多种字段名自动识别：

| 因子 | 直接字段 | 嵌套字段（需source标记） |
|------|----------|--------------------------|
| 强势主力 | `force_behavior_score` | `score.total`（source="main_force"） |
| 九重共振 | `nine_filter_score` | `score.total`（source="nine_filter"） |
| AI六维 | `ai_six_dim_score` | `total_score`（source="ai_six_dim"，自动÷120×100归一化） |
| 市场环境 | `market_environment_score` / `market_env_score` | — |

## 五、集成方式说明

### 5.1 核心API

```python
from strategy.ai_composite_score import AICompositeScoreEngine, calculate_composite_score

# 方式1：直接使用引擎
engine = AICompositeScoreEngine()
result = engine.calculate({
    "code": "000001",
    "name": "平安银行",
    "force_behavior_score": 85.0,
    "nine_filter_score": 72.5,
    "ai_six_dim_score": 68.0,
    "price": 11.40,
    "ma5": 11.19, "ma10": 11.22, "ma20": 11.28,
})
# result: {composite_score, grade, trading_advice, factors, ...}

# 方式2：从现有缓存自动读取
result = calculate_composite_score("000001")

results = engine.batch_calculate(stock_list)
distribution = engine.grade_distribution(results)
```

### 5.3 与现有模块的集成点

**不修改现有代码**，提供以下集成方式：

1. **强势主力选股结果增强**：在UI层调用 `engine.calculate()` 追加 `composite_score` 字段，不修改 `main_force_behavior.py` 的评分逻辑
2. **九重共振选股结果增强**：同上，在UI层追加综合评分
3. **独立查询**：`calculate_composite_score(stock_code)` 可从任意位置调用，自动读取缓存
4. **批量排序**：`engine.batch_calculate()` 可对任意股票列表计算并排序

## 七、后续优化方向

### 7.1 短期优化

1. **市场环境因子落地**：当前 `market_environment` 权重0.15为预留，需接入 `market_state_engine.py` 的市场状态评分
2. **AI六维评分全覆盖**：当前仅260只股票有AI分析缓存，需扩大覆盖范围，或直接调用 `SixDimensionScorer` 实时计算
3. **UI集成**：在股票详情页增加"AI综合评分"卡片，显示综合评分、等级、各维度雷达图/柱状图、交易建议

### 7.2 中期优化

4. **动态权重优化**：基于历史回测数据，用Walk Forward验证优化各策略权重，而非固定30/30/25/15
5. **策略评分一致性校准**：当前强势主力评分普遍偏高（90+占比大），九重评分分布更均匀，需做评分分布校准
6. **五买/三倍量/回调五日线/缠论评分接入**：将更多策略评分纳入因子池
7. **评分衰减机制**：根据扫描时间距当前天数对评分进行衰减

### 7.3 长期优化

8. **AI解释层集成**：接入Ollama本地大模型，对综合评分生成自然语言化理由，解析为结构化JSON
9. **实盘-回测一致性校验**：验证综合评分在实盘和回测环境下的一致性
10. **组合层面优化**：从单股票评分扩展到股票组合评分，考虑相关性和仓位分配
