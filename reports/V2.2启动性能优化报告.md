## 三、根本原因与修复

### 🔴 问题1（最主要）：NewsService过度获取全市场财务信息

**原代码** (`service/unified_data_service.py:40-55`):
```python
def _load_stock_names(self):
    from utils.tdx_stock_list import get_full_market_quotes
    stocks = get_full_market_quotes(main_board_only=False, exclude_st=False)
    # 只需要name→code映射，却获取了全市场5217只股票的行情+财务信息！
```

**调用链**:
```
NewsService.__init__
  → _load_stock_names()
    → get_full_market_quotes(5217只)
      → get_realtime_quotes_tdx(5217 codes)  # 分批105批，10-30秒
      → get_finance_info_batch(5217 codes)    # 🔴 逐只请求！5217次！3-5分钟
```

**问题本质**: `get_finance_info_batch()`实现为 `for code in need_fetch: api.get_finance_info(market, code)`，每只股票一次网络请求，5217只 = 5217次请求，每次30-50ms，总计3-5分钟。

**修复后**:
```python
def _load_stock_names(self):
    from utils.tdx_stock_list import get_stock_list_tdx
    stocks = get_stock_list_tdx()  # 只返回code/name/market，<1秒
```

**效果**: 新闻服务初始化从3-5分钟降至<0.1秒。

---

### 🟡 问题2：NewsPage同步加载新闻阻塞主线程

**原代码** (`ui/battle_console_v2.py:582`):
```python
class NewsPage(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self._build_ui()
        self._load_news()  # 🔴 同步调用4个新闻接口，阻塞5-40秒
```

**修复后**:
```python
class NewsPage(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self._build_ui()
        self.count_label.setText('正在加载新闻...')
        QTimer.singleShot(300, self._load_news)  # 延迟加载，主窗口先显示
```

**效果**: NewsPage创建从5-40秒降至<0.01秒，主窗口立即显示，新闻在后台加载完成后自动更新。

---

### 🟢 附带修复：东方财富新闻方法缺失

**问题**: `_get_eastmoney_news()`方法的代码写在`_get_sina_7x24()`的return语句之后，成为死代码，导致`get_news()`调用时报`AttributeError`。

**修复**: 将死代码移到正确位置，定义为独立的`_get_eastmoney_news()`方法。
