## 一、市场环境评分指标和权重

### 1.1 四维度评分体系

| 指标 | 权重 | 满分 | 计算方式 |
|------|------|------|----------|
| **大盘趋势** | 30% | 30分 | 上证指数MA5/MA10/MA20排列 + 近5日涨幅 |
| **赚钱效应** | 30% | 30分 | 上涨家数/下跌家数比例 + 涨停数/跌停数比例 |
| **涨停数量** | 20% | 20分 | 当日涨停股票数量 + 连板高度加权 |
| **市场成交额** | 20% | 20分 | 沪深两市总成交额 + 与20日均量对比 |

### 1.2 各维度评分规则

#### 大盘趋势分（0-30）

| 条件 | 得分 |
|------|------|
| MA5 > MA10 > MA20（多头排列） | +30 |
| MA5 > MA10 但 MA10 < MA20 | +15 |
| MA5 < MA10 < MA20（空头排列） | +0 |
| 其他排列 | +10 |
| 近5日涨幅 > 2%（叠加） | +5 |

#### 赚钱效应分（0-30）

| 条件 | 得分 |
|------|------|
| 上涨家数/下跌家数 > 2 | +30 |
| 上涨家数/下跌家数 1-2 | +15 |
| 上涨家数/下跌家数 < 1 | +0 |
| 涨停数/跌停数 > 5（叠加） | +5 |

#### 涨停数量分（0-20）

| 条件 | 得分 |
|------|------|
| 涨停数 > 80 | +20 |
| 涨停数 50-80 | +15 |
| 涨停数 30-50 | +10 |
| 涨停数 < 30 | +5 |
| 连板高度 ≥ 5（叠加） | +5 |

#### 成交额分（0-20）

| 条件 | 得分 |
|------|------|
| 两市成交额 > 1.5万亿 | +20 |
| 两市成交额 1-1.5万亿 | +15 |
| 两市成交额 0.8-1万亿 | +10 |
| 两市成交额 < 0.8万亿 | +5 |
| 成交额 > 20日均量 × 1.2（叠加） | +5 |

## 四、集成到综合评分引擎的方式

### 4.1 新增方法（仅新增，不修改原有逻辑）

在 `AICompositeScoreEngine` 类中新增：

```python
# 设置市场环境
engine.set_market_env(env_score=80.0, env_type="牛市", factor=1.2)

# 清除市场环境（恢复纯策略评分）
engine.clear_market_env()
```

### 4.2 评分调整流程

```
原有评分流程（不变）：
  各策略评分 → 加权计算 → 因子校验扣分 → composite_score

V6.3 新增（仅在设置了市场环境时生效）：
  composite_score × 环境系数
  → 风险环境(factor=0)时评分上限59.9
  → 限制在[0, 100]区间
  → 等级划分 → 交易建议
```

### 4.3 结果输出新增字段

在 `calculate()` 返回结果的 `factors` 字段中新增：

```python
"_market_env": {
    "env_score": 80.0,      # 市场环境评分
    "env_type": "牛市",      # 环境类型
    "factor": 1.2,           # 应用的系数
    "adjusted": True         # 是否经过环境调整
}
```

### 4.4 与现有模块的关系

| 模块 | 关系 | 说明 |
|------|------|------|
| `market_environment.py` | **新增** | 独立市场环境评分模块 |

## 五、数据来源说明

### 5.1 上证指数K线

- **数据源**：通达信本地数据 `C:\new_tdx\vipdoc\sh\lday\sh999999.day`
- **说明**：由于 `tdx_data_engine` 的路径判断对999999代码有误（不以6开头被误判为深市），本模块直接读取 `.day` 文件，格式为 `<IIIIIfII`，价格除以100
- **数据范围**：1990-12-19 至 2026-08-19，共8707个交易日

### 5.2 市场广度数据（涨跌家数、涨停跌停）

- **优先来源**：`cache/stock_pool_cache.json`（如果股票数≥500）
- **备用来源**：通达信全市场主板股票（2232只），逐只读取最近2日K线计算涨跌幅
- **计算方式**：
  - 上涨：pct_chg > 0
  - 下跌：pct_chg < 0
  - 涨停：pct_chg ≥ 9.5%
  - 跌停：pct_chg ≤ -9.5%

### 5.3 两市成交额

- **优先来源**：市场广度数据中所有股票的 `amount` 求和
- **备用来源**：上证指数成交额 × 2（估算两市）

## 八、后续优化方向

### 8.1 短期优化

1. **实时数据接入**：当前使用通达信本地数据（最近交易日），可接入 `MarketDataProvider`（东方财富/新浪）获取实时涨跌家数和成交额
2. **连板高度统计**：当前连板高度为0，需接入涨停连板数据（`limit_up_data_provider.py`）
3. **分层扫描集成**：在 `layered_scanner.py` 的L4阶段自动调用 `set_market_env()` 应用环境系数

### 8.2 中期优化

4. **历史环境回溯**：保存每日市场环境评分，用于回测时按对应日期应用环境系数
5. **环境切换预警**：当环境类型发生变化时（如震荡→弱势），发出预警信号
6. **板块环境分化**：除了大盘环境，增加行业/板块级别的环境评分

### 8.3 长期优化

7. **AI环境解释**：接入Ollama本地大模型，对市场环境生成自然语言化分析
8. **环境自适应权重**：根据不同市场环境自动调整各策略评分的权重（如牛市增加趋势因子权重）
9. **环境-策略匹配**：不同环境下推荐不同策略（牛市→追涨，震荡→低吸，弱势→防守）
