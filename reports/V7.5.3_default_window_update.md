# V7.5.3 默认扫描周期调整报告

> 完成时间：2026-08-23
> 优化范围：UI层默认扫描周期+排序+提示（不修改任何策略/评分/模型）
> 验证样本：200只主板股票，lookback=3

---

## 一、默认扫描周期调整说明

### 1.1 调整内容

| 项目 | 调整前(V7.5.2) | 调整后(V7.5.3) |
|------|----------------|----------------|
| 默认扫描周期 | 今日(1天) | **近3天** |
| 重点关注池数量 | 0只（今日无强信号） | ~11只（全市场推算） |
| 是否达标(10-30) | ❌ 过少 | ✅ 达标 |

### 1.2 调整原因

V7.5.2验证发现核心问题：
- **今日(1天)**：200只中0只score>=50，最高46分，全部为观察级
- **近3天**：1只买入窗口(51分)，全市场推算约11只，在目标10-30范围
- **近5天**：4只买入窗口+2只有效观察，全市场推算约44只，偏高

**策略逻辑决定：** V7.4模型不是每天产生新信号，而是主力吸筹→评分达到50+→持续2-3天→等待低吸机会。"今日信号"定义过窄，近3天刚好覆盖买入窗口，符合"主力启动前1-3天"的策略目标。

### 1.3 保留手动切换

扫描周期下拉框保留4个选项，用户可手动切换：
- 今日(1天) — 仅显示当日新信号（强信号较少）
- **近3天**【默认】— 匹配主力启动前1-3天买点模型（推荐）
- 近5天 — 扩大候选范围（含有效观察信号）
- 近10天 — 历史回测验证用（信号较多）

## 二、重点关注池默认显示规则

### 2.1 默认显示

重点关注池默认显示范围：**"重点关注池(🟢新+🟡窗口)"**

包含：
- 🟢**新出现**：score>=50 且 首次信号日=最新信号日=今日
- 🟡**买入窗口**：score>=50 且 信号持续<=3天

### 2.2 默认隐藏

- 🔵**有效观察**：score>=50 但 持续>3天 — 移到观察池
- 🔵**观察级**：40<=score<50 — 显示在观察池
- ⚪**失效**：score<40 或 持续>5天 — 过滤不显示

### 2.3 显示范围切换

用户可通过"显示范围"下拉框切换：
- 重点关注池(🟢新+🟡窗口)【默认】
- 观察池(🔵有效+🔵级)
- 全部信号

## 三、排序优化说明

### 3.1 排序规则

重点关注池表格排序优先级：

| 优先级 | 排序字段 | 方向 | 说明 |
|--------|---------|------|------|
| 第一 | 信号状态 | 升序 | 🟢新出现(0) > 🟡买入窗口(1) > 🔵有效观察(2) > 🔵观察级(3) > ⚪失效(4) |
| 第二 | 评分 | 降序 | 高分优先 |
| 第三 | 信号距离 | 升序 | 距离信号越近越优先（1天>2天>3天） |

### 3.2 状态优先级常量

```python
STATUS_PRIORITY = {
    'new': 0,         # 🟢新出现 最优先
    'buy_window': 1,  # 🟡买入窗口 次优先
    'watch_valid': 2, # 🔵有效观察 第三
    'watch_level': 3, # 🔵观察级 第四
    'expired': 4,     # ⚪失效 最后
}
```

### 3.3 排序实现

```python
sorted_results = sorted(filtered, key=lambda x: (
    STATUS_PRIORITY.get(x.get('signal_status', 'watch_level'), 3),
    -x.get('enhanced_score', 0),
    x.get('signal_duration', 99)
))
```

## 四、过期保护说明

### 4.1 设计原则

距离信号>3天的股票**不删除**，只降低优先级。

**原因：** 有些股票可能第1天产生信号，第3天才给低吸机会。如果直接删除会错过买点。

### 4.2 实现方式

- 在排序中，距离信号>3天的"有效观察"状态自动排到"买入窗口"之后
- 用户切换到"全部"显示时，可以看到这些股票，但标记为"🔵有效观察"
- 建议操作显示"等待回调或升级"

### 4.3 状态转换

```
第1-3天：🟡买入窗口（重点关注池显示，建议买入）
    ↓
第4-5天：🔵有效观察（移到观察池，等待回调或升级）
    ↓
第6天+：⚪失效（过滤不显示）
```

## 九、每日使用流程

### 推荐流程

1. **启动程序** → 打开"⭐ V7.4精准买点"页面
2. **确认默认窗口** → 近3天（自动选中，匹配主力启动前1-3天）
3. **点击全市场扫描** → 2232只扫描，3-5分钟完成
4. **查看重点关注池** → 默认显示🟢新出现+🟡买入窗口，约10-30只
5. **按排序查看** → 新出现优先，然后评分降序，然后距离升序
6. **双击股票查看K线** → 验证横盘/均线/MACD/KDJ形态
7. **生成买卖计划** → 次日低吸买入，+8%止盈，-7%止损，10天持仓
8. **跟踪持仓** → 每日查看信号状态变化（新出现→买入窗口→有效观察→失效）
9. **自动复盘** → 5日后自动统计实际表现，30天自动优化参数

## 十、未解决的问题

### 10.1 "新出现"状态为0

- 近3天验证中🟢新出现为0，全部是🟡买入窗口
- **原因**：去重后如果股票只有1次信号，first=latest=该信号日期，但该日期不一定等于current_date（窗口内最新日期）
- **影响**：不影响功能，买入窗口已覆盖主力启动前1-3天
- **建议**：后续可优化"新出现"判断逻辑，或单独标记"今日新增"

### 10.2 全市场验证基于200只推算

- 当前验证基于200只样本比例推算全市场
- 建议后续跑全市场2232只确认实际数量

### 10.3 ST股票未过滤

- 扫描结果可能包含ST股票
- 属于策略层面过滤，本次未修改（用户禁止修改策略）
