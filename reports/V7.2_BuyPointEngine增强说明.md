## 一、新增字段（7个，全部为额外输出）

在 `BuyPointResult` 数据类中新增以下字段，**原有字段全部保留不变**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `buy_point_logic` | Dict | 买点逻辑详解：类型/核心触发条件/辅助确认条件/失效条件 |
| `position_context` | Dict | 买点位置描述：趋势阶段/价格位置/形态位置/支撑压力位 |
| `why_this_position` | List[Dict] | 为什么这个位置买：3-5条，每条含指标名+当前值+阈值+判断+评分贡献 |
| `why_this_price` | Dict | 为什么这个价格买：最佳区间/突破价/止损/目标的完整计算过程（公式+代入值+结果+依据） |
| `why_this_stock` | Dict | 为什么选择这个股票：评分亮点/核心优势/资金关注度/涨停基因 |
| `action_advice` | Dict | 操作理由：操作建议/仓位建议/持有周期/关键观察点/失效信号 |
| `action_summary` | str | 自然语言操作理由摘要（200-300字，人类可读） |

`to_dict()` 方法已同步包含以上7个新字段。

## 二、六个维度解释生成逻辑

### 维度1：买点逻辑（buy_point_logic）

按买点等级（A/B/C/D）分别定义：
- **核心触发条件**（3个，必须满足的）：每个条件含描述、解释、当前是否满足、实际值
- **辅助确认条件**（2个，加分项）：同上
- **失效条件**（4个）：什么情况下这个买点作废

示例（B型涨停回调）：
```
核心条件 (1/3满足):
  ✗ 近期涨停/大阳启动 — 有主力启动痕迹
  ✗ 回撤5%-15% (回撤0.0%) — 健康回调幅度
  ✓ 不破20日线 — 趋势支撑有效
辅助条件:
  ✗ 缩量调整 — 抛压减轻
  ✓ 再次放量 — 二次启动信号
失效条件:
  ⚠ 跌破20日线且3天内无法收回
  ⚠ 回撤幅度超过20%（趋势可能反转）
```

### 维度2：买点位置（position_context）

- **趋势阶段**：启动期/主升期/调整期/下跌期（基于MA5/10/20/60排列和60日趋势）
- **价格位置**：距MA20%、距MA60%、距60日高点%、距60日低点%、60日位置百分位
- **形态位置**：涨停后天数、距近期高点天数、横盘天数、下跌后反弹天数/幅度
- **支撑压力位**：最近支撑/压力、MA20、MA60

### 维度3：为什么这个位置买（why_this_position）

按重要性排序，最多5条，每条结构：
```python
{
    "indicator": "均线多头排列",           # 指标名称
    "current_value": "MA5=12.30 > MA10=12.15 > MA20=11.80",  # 当前实际值
    "threshold": "MA5>MA10>MA20",          # 判断阈值
    "passed": True,                         # 是否通过
    "score_contribution": "+10分（趋势因子）",  # 评分贡献
    "explanation": "短期、中期均线多头排列，趋势向上确立"  # 说明
}
```

覆盖的指标类型：均线趋势、MACD动量、KDJ位置、成交量、缠论确认/背驰。

### 维度4：为什么这个价格买（why_this_price）

每个价格项都包含**完整计算过程**：
```
公式: 下限 = 当前价 - 0.5×ATR; 上限 = 当前价 + 0.25×ATR
代入: 下限 = 11.40 - 0.5×0.17; 上限 = 11.40 + 0.25×0.17
结果: 11.31 - 11.44
依据: 基于ATR(14)波动率，在当前价附近给出低吸区间，上限偏紧避免追高
```

四个价格项：
- **最佳买入区间**：ATR波动率计算
- **突破价**：前高压力位×1.005（含压力位候选列表）
- **止损价**：min(支撑位-1.5×ATR, MA20×0.97)，含ATR止损价和MA20止损价分别计算
- **目标价**：突破价+风险×(2.0~3.0)盈亏比

### 维度5：为什么选择这个股票（why_this_stock）

- **评分亮点**：四个维度中得分率最高的1-2个，含具体分数和占比
- **核心优势描述**：自然语言总结
- **资金关注度**：5日量比、量能状态（放量/温和/平稳/缩量）、近3日阳线数
- **涨停基因**：近60日涨停次数、基因强度（强/中/弱/无）

### 维度6：操作理由（action_advice）

- **操作建议**：强烈买入/买入/试仓/观望/回避（基于等级+评分+风险）
- **仓位建议**：低风险30-50%、中风险15-30%、高风险5-15%或观望
- **持有周期**：按买点类型（A型5-15天、B型3-10天、C型10-20天、D型5-15天）
- **关键观察点**：2-3个买入后需重点关注的信号
- **失效信号**：立即止损离场的条件

### 自然语言摘要（action_summary）

自动生成200-300字人类可读文本，格式：
```
【操作理由】
该股属于【涨停回调(形成中)】，当前处于调整期（上升趋势中回调）。
现价11.40，距20日线+1.03%，60日位置百分位84.4%。

为什么买：
1. 站上20日线：现价11.40 > MA20=11.28（股价站上20日生命线...）
2. MACD改善：DIF=0.0580 > 2日前0.0233（DIF拐头向上...）
3. 成交量放大：近5日均量比=1.35（量能放大确认资金进场...）

买入策略：
- 最佳买入区间：11.31-11.44，依据ATR(0.17)波动率计算
- 突破确认价：11.69，突破后可加仓
- 止损位：10.64，跌破立即离场
- 目标位：13.79-14.84，盈亏比3.8:1

操作建议：买入，仓位15%-30%，持有周期3-10个交易日。
风险提示：暂无明显风险信号
关键观察：20日线10.90是否持续支撑
```
