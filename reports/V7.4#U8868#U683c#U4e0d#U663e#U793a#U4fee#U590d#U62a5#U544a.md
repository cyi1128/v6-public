# V7.4精准买点表格不显示修复报告

**修复时间**: 2026-08-23  
**问题现象**: 扫描发现673个信号，但表格显示0只，统计全为0  
**根本原因**: 表格创建时列数（16列）与数据填充时列数（23列）不一致，导致表格填充异常

---

## 一、数据丢失环节定位

通过逐层诊断（扫描→去重→生命周期→表格填充），确认数据在各环节的数量：

| 环节 | 数量（100只样本） | 状态 |
|------|-------------------|------|
| V7.6扫描返回信号 | 39个 | ✅ 正常 |
| 去重后 | 29只 | ✅ 正常 |
| 生命周期计算后 | 29只 | ✅ 正常 |
| 信号状态分布 | expired:22, watch_valid:5, new:1, buy_window:1 | ✅ 正常 |
| UI筛选（买入池+观察池） | 7只 | ✅ 正常 |
| **表格显示** | **0只** | **❌ 异常** |

**结论**: 数据在扫描→去重→生命周期→UI筛选各环节均正常，**数据丢失发生在表格填充环节**。

---

## 二、根本原因

### 原因1：表格列数与数据列数不匹配（核心原因）

**表格创建时**（`_create_focus_pool_tab`方法）：
```python
headers = ['代码', '名称', '最高评分', '等级', '模型', '信号状态', '距离信号', '建议操作',
           '当前价', '建议买入价', '止盈价', '止损价', '首次信号日', '最新信号日', '信号次数', '持仓天数']
# 共16列
self.focus_table = create_table(headers)
```

**数据填充时**（`_update_focus_pool`方法）：
```python
col_keys = ['代码', '名称', '精准评分', '池子', 'V76评分', '原始分', '板块+', '市场+',
            '行业', '等级', '模型', '信号状态', '距离信号', '建议操作',
            '当前价', '建议买入价', '止盈价', '止损价',
            '首次信号日', '最新信号日', '信号次数', '为什么进入', '风险提示']
# 共23列
fill_table(self.focus_table, rows, col_keys, grade_col='等级')
```

**问题**: 表格只有16列，但`fill_table`尝试填充23列数据。虽然`QTableWidget.setItem`会自动扩展列数，但水平表头标签只有16个，且列宽调整（`resizeColumnsToContents`）可能导致新增列宽度为0或被隐藏，最终表现为表格看起来是空的。

### 原因2：列名不匹配

- 表格列名：`最高评分`
- 数据字段名：`精准评分`、`池子`、`V76评分`等新增字段

虽然`fill_table`按`col_keys`顺序填充数据（不依赖列名），但列名不匹配导致用户看到的表头与数据内容不一致。

## 三、修复内容

### 修复1：统一表格列定义（核心修复）

**文件**: `ui/v74_precision_buy_page.py`  
**方法**: `_create_focus_pool_tab`

将表格创建时的headers从16列改为23列，与`_update_focus_pool`中的`col_keys`完全一致：

```python
# 修复前（16列）
headers = ['代码', '名称', '最高评分', '等级', '模型', '信号状态', '距离信号', '建议操作',

headers = ['代码', '名称', '精准评分', '池子', 'V76评分', '原始分', '板块+', '市场+',
           '行业', '等级', '模型', '信号状态', '距离信号', '建议操作',
           '当前价', '建议买入价', '止盈价', '止损价',
           '首次信号日', '最新信号日', '信号次数', '为什么进入', '风险提示']
```

### 修复2：fill_table增加列数自动保护

**文件**: `ui/v74_precision_buy_page.py`  
**函数**: `fill_table`

在填充数据前检查表格列数是否与`col_keys`一致，不一致时自动调整：

```python
def fill_table(table, rows, col_keys, grade_col=None):
    # 新增：确保表格列数与col_keys一致
    if table.columnCount() != len(col_keys):
        table.setColumnCount(len(col_keys))
        table.setHorizontalHeaderLabels(col_keys)
    # ... 原有填充逻辑
```
