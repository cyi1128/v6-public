## 二、520金叉数学定义（严格实现）

**核心公式**:
```
金叉条件 = (MA5[T0] > MA20[T0]) AND (MA5[T-1] <= MA20[T-1])
```

即：**昨天MA5<=MA20，今天MA5>MA20**，才叫520金叉。

**信号等级**:
- **S级**: 当天刚刚发生520金叉 + MA20向上/走平 + 价格站在MA20上方
- **A级**: 最近1~3个交易日发生520金叉 + MA5继续向上 + MA20没有明显下降
- **B级**: 520金叉发生一段时间 + MA5>MA20 + MA20向上 + 价格仍然强势
- **C级**: 低优先级观察，不作为企业微信重点推送

**金叉有效期**: 最近10个交易日内发生的金叉才纳入信号池

## 三、AI-520评分模型（7维度100分）

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 520金叉强度 | 20分 | 今日金叉20分 / 1-3天15分 / 4-7天10分 + 金叉幅度 |
| 趋势 | 15分 | MA5>MA10>MA20多头15分 / MA5>MA20 8分 |
| 价格位置 | 15分 | 距8个月高点-10%内15分 / -15%~-10% 10分 |
| 成交量 | 15分 | 健康放量15分 / 正常10分 / 缩量6分 / 巨量冲高5分 |
| 涨停记忆 | 10分 | 年涨停>=10次10分 / >=5次8分 / >=3次6分 + 近20日涨停+2 |
| 板块强度 | 15分 | 板块涨幅+排名+涨停数+资金流入（无板块数据给基础分5） |
| 短线启动 | 10分 | 站上MA5+3 / 创10日新高+4 / 阳线+2 / 涨幅合理+1 |

**风险扣分**: 涨幅>7%扣3分 / 接近高点扣2分 / 巨量冲高扣3分 / 放量滞涨扣2分

**等级划分**: S>=85 / A>=75 / B>=65 / C>=55 / D<55
