# 强势主力行为选股系统 V1.3.16 修复完成报告

## 一、问题描述

用户截图显示两个问题：
1. **K线数量不足**：当前K线图只有约60-80根（从2026-05-28到2026-08-14），用户要求300根
2. **MA120均线不显示**：K线图上方显示了MA5/MA10/MA20/MA120的数值标签，但K线图上只有三条均线（白/黄/紫），MA120没有绘制出来

## 二、根因分析

### 2.1 K线数量不足
`ui/force_behavior_panel.py` 中两处调用 `get_kline_data` 时传入的天数参数都是 `days=120`：
- 第880行：测试分析诊断成功后的K线渲染
- 第1117行：选中股票后的K线渲染

### 2.2 MA120均线不显示
通过检查 `ui/echarts_kline.py`，发现MA120的计算和显示逻辑都是正确的：
- 第237行：`var ma120 = calculateMA(120, klineData);` — MA120已计算
- 第529-536行：MA120的series配置，颜色为红色 `#ef5350`
- 第310-315行：MA120的数值标签

**根本原因**：K线只有120根，MA120从第120根开始有值，前119根为null。如果只有120根K线，MA120只有最后1根有值，在图上看起来就像没有显示。

## 三、修复内容

### 3.1 K线数量增加到300根（ui/force_behavior_panel.py）

修改两处 `get_kline_data` 调用，将 `days=120` 改为 `days=300`：

**第一处**（第880行，测试分析诊断成功后）：
```python
# 获取K线数据并渲染（V1.3.16：300根K线，支持MA120均线显示）
if ECHARTS_AVAILABLE and hasattr(self, 'kline_widget') and self.strategy:
    kline_data = self.strategy.get_kline_data(code, days=300)
```

**第二处**（第1117行，选中股票后）：
```python
# V1.3.8：优先渲染ECharts K线图（V1.3.16：300根K线，支持MA120均线显示）
if ECHARTS_AVAILABLE and hasattr(self, 'kline_widget') and self.strategy:
    try:
        kline_data = self.strategy.get_kline_data(stock.code, days=300)
```

### 3.2 MA120均线显示（ui/echarts_kline.py）

MA120的计算和显示逻辑已经正确，无需修改：
- `calculateMA(dayCount, data)` 函数：前dayCount-1根返回null，从第dayCount根开始计算简单移动平均
- MA120 series配置：`name: 'MA120'`, `type: 'line'`, `lineStyle: { color: '#ef5350', width: 1.5 }`（红色）
- 300根K线下，MA120有181根有值（300-119=181），能正常显示
