## 二、阶段识别逻辑

### 2.1 五阶段定义

| 阶段 | 判定条件 | 典型特征 |
|------|----------|----------|
| **吸筹** | 近20日振幅<15% + 量比<0.8缩量 + 均线偏差<5%粘合 | 低位横盘、缩量、均线粘合 |
| **启动** | 突破近20日平台(收盘>20日最高×0.98) + 量比>1.2，或MA5上穿MA10金叉 | 平台突破、放量、金叉 |
| **主升** | MA5>MA10>MA20多头 + 近10日涨幅>10% + 量比≥0.8 | 多头排列、持续上涨、量能配合 |
| **加速** | 近5日涨幅>15% + 偏离MA5>8% + 量比>1.5 | 连续大阳、急速拉升、放量 |
| **风险** | 高位放量滞涨(近3日涨幅<1%但量比>1.5)，或MACD死叉，或MA5拐头 | 放量不涨、指标转弱 |

### 2.2 优先级

加速 > 风险 > 主升 > 启动 > 吸筹（高优先级先判定）

---

## 三、优势/风险生成逻辑

### 3.1 优势来源（按优先级排序，取前3条）

1. **均线多头排列**：MA5>MA10>MA20，附具体数值
2. **量价配合**：放量上涨（量比>1.5）或温和放量（1.2-1.5）
3. **MACD红柱**：HIST>0，附具体值
4. **KDJ金叉/低位**：K>D且K<70，或K<30超卖
5. **平台突破**：接近/突破20日高点
6. **RPS强势**：RPS20>80
7. **阶段优势**：主升/启动阶段说明
8. **相似案例成功率高**：>50%

### 3.2 风险来源（按优先级排序，取前3条）

1. **短期涨幅过大**：近5日>15%（超买）或>10%（获利盘多）
2. **偏离均线过大**：偏离MA5>10%（回归压力）或>7%（回踩需求）
3. **KDJ超买**：K>90（严重超买）或>80（超买区）
4. **MACD死叉/绿柱**：HIST<0或红柱缩短
5. **均线空头**：MA5<MA10<MA20
6. **放量滞涨**：量比>1.5但涨跌幅<1%
7. **接近压力位**：距60日高点<5%
8. **阶段风险**：风险/加速阶段说明
9. **市场环境**：弱势/风险环境
10. **相似案例成功率低**：<30%
11. **兜底**：涨停追高风险 / 高分需关注量能 / 大盘环境变化

### 3.3 质量保证

- 每条优势/风险必须包含具体数值（如"MA5(27.54)>MA10(24.11)>MA20(17.97)"）
- 禁止模板化空话
- 优势和风险不重复
- 兜底机制确保每只股票至少有1条风险

## 四、操作建议逻辑

| 建议 | 条件 |
|------|------|
| **买入** | S+/S级 +（启动/主升阶段）+ 非风险环境；或A级 + 主升阶段 |
| **等待** | A级 + 启动阶段 + 震荡/牛市；或B级 + 主升阶段；或S+/S级 + 吸筹阶段 |
| **观察** | B级 + 任何阶段；观察级 + 非弱势环境；S+/S级 + 加速阶段 |
| **减仓** | 风险级 + 任何环境；加速阶段 + 放量滞涨 + S/A级；风险阶段 + S/A级 |
| **观望** | 风险阶段 + B级及以下；风险环境 |

## 五、架构升级前后对比

### 升级前（V6.0）

```
策略层：强势主力选股 / 九重共振选股
  ↓
评分：各策略独立评分，无统一评分
  ↓
扫描：固定500只，AI分析100只
  ↓
回测：T日收盘价成交，无手续费/滑点
  ↓
输出：选股列表 + 独立评分
```

### 升级后（V6.5）

```
策略层：强势主力 / 九重 / 五买 / 三倍量 / 回调五日线 / 缠论
  ↓
统一因子池 → AI综合评分（加权融合+因子校验+市场环境系数）
  ↓
全市场分层扫描：L1(2232)→L2(1456)→L3(300)→L4(80)，14.4秒
  ↓
真实性回测：T+1成交+滑点+手续费+印花税+成交限制+防未来函数
  ↓
AI学习闭环：案例库积累→相似匹配→权重优化→报告生成
  ↓
输出：AI详情报告（评分+阶段+优势+风险+建议+相似案例）
```

### 关键提升

| 维度 | 升级前 | 升级后 |
|------|--------|--------|
| 评分体系 | 各策略独立 | 统一综合评分+6等级 |
| 扫描范围 | 固定500只 | 全市场2232只分层过滤 |
| 扫描速度 | 慢（AI全量分析） | 14.4秒（四层逐级过滤） |
| 回测真实性 | T日成交、无费用 | T+1+滑点+手续费+印花税 |
| 市场环境 | 无 | 四维度评分+系数调整 |
| 学习能力 | 无 | DuckDB案例库+相似度匹配 |
| 输出形式 | 选股列表 | AI详情报告（评分+阶段+优风险+建议） |
