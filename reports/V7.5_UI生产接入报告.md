## 四、6个页面区域功能说明

### 4.1 区域1：🎯 今日重点关注池

**功能**：展示今日score≥50的股票，按评分降序排列。

**字段**：代码、名称、评分、等级、模型(TOP1/TOP3/共振)、当前价、建议买入价、止盈价、止损价、持仓天数

**交互**：
- 颜色标记：S红/A橙/B黄/重点关注蓝
- 双击行打开股票详情（当前显示信息弹窗，后续可接入现有K线详情页）
- 顶部统计栏：重点关注数量、平均评分、S级数量、A级数量

**数据来源**：点击"全市场扫描"按钮，后台调用 `V74BuyPointLayer.scan_market()`

### 4.2 区域2：⭐ A/B级信号

**功能**：展示今日精确触发TOP1（A级）和TOP3（B级）的股票，最高优先级信号。

**结构**：QTabWidget二级切换，A级Tab + B级Tab

**字段**：代码、名称、等级、模型、评分、买入条件（如"多头排列+一阳穿均线"）、止盈(+8%)、止损(-7%)、当前价

**交互**：双击行打开股票详情

### 4.3 区域3：📋 买卖计划

**功能**：根据冻结交易规则为每只股票生成完整买卖计划。

**字段**：代码、名称、评分、等级、建议买入价（次日低吸价=当前价×0.99）、止盈价(+8%)、止损价(-7%)、建议持仓(10天)、仓位建议（根据市场状态）、模型

**市场状态指示器**：
- 上涨市（绿）：100%仓位
- 震荡市（黄）：50%仓位，优先A/B级
- 下跌市（红）：0%仓位，停止新增

**交互**：
- "🔄 刷新市场状态"按钮
- "📥 导出买卖计划"按钮 → 导出CSV

### 4.4 区域4：📊 历史交割单

**功能**：读取V7.4.6/V7.4.7/V7.4.8历史交割单CSV，合并展示6051笔交易。

**字段**：版本、交易编号、代码、名称、信号日、买入日、买入价、卖出日、卖出价、卖出原因、持仓天数、收益率(%)、收益金额

**筛选**：
- 版本筛选：全部/V7.4.6/V7.4.7/V7.4.8
- 等级筛选：全部/S级/A级/B级/重点关注/观察
- 收益率筛选：全部/盈利/亏损

**统计栏**：共N笔 | 胜率X% | 平均收益+X% | 盈亏比X

**交互**："📥 导出CSV"按钮

**当前数据**：6051笔，胜率54.5%，平均收益+1.03%，盈亏比1.24

### 4.5 区域5：📈 模拟资金曲线

**功能**：读取V7.4.6_daily_nav.csv，展示819天资金曲线。

**统计卡片（6项）**：
- 初始资金：100,000元
- 当前资金：144,621元
- 总收益率：+44.62%
- 年化收益率：+11.92%
- 最大回撤：-6.70%
- 胜率：54.5%（从交割单计算）

**时间范围选择**：近3月/近6月/近1年/近3年/全部

**曲线展示**：ASCII风格文字曲线（每10个交易日取一个点，带柱状图和涨跌标记），避免matplotlib依赖问题。后续可接入ECharts组件。

### 4.6 区域6：🔄 自动复盘结果

**功能**：读取v74_signals.db（DuckDB），展示500条近期信号复盘结果。

**字段**：信号日、代码、名称、等级、评分、模型、状态、实际收益率(%)、最大盈利(%)、最大回撤(%)

**统计栏（4项）**：
- 近30天信号数：500

## 五、技术实现说明

### 5.1 后台扫描线程

`V74ScanThread(QThread)`：
- 调用 `V74BuyPointLayer.scan_market()` 进行全市场扫描
- 通过 `progress` 信号实时更新进度条（done/total/found）
- 通过 `finished_scan` 信号返回扫描结果（自动过滤score≥50）
- 支持 `cancel()` 取消扫描
- 扫描不阻塞UI，用户可在扫描期间切换Tab

### 5.2 数据接口封装

| 函数 | 功能 | 数据源 |
|------|------|--------|
| `read_csv_safe()` | 安全读取CSV，编码容错 | 通用 |
| `load_trade_orders()` | 合并加载V7.4.6/7/8交割单 | 3个CSV |
| `load_daily_nav()` | 加载资金曲线数据 | V7.4.6_daily_nav.csv |
| `load_feedback_signals()` | 加载DuckDB复盘信号，字段名统一 | v74_signals.db |
| `detect_market_state()` | 检测市场状态（简化版，默认震荡） | 可接入上证指数 |

### 5.3 通用表格工具

`create_table(headers)`：创建标准深色主题表格，统一设置：
- 隐藏行号、交替行颜色、整行选择、禁止编辑
- 列宽自适应、最后一列拉伸
- 行高28px

`fill_table(table, rows, col_keys, grade_col)`：
- 自动填充数据，数值格式化
- 等级颜色标记（S红/A橙/B黄/重点关注蓝）
- 收益率颜色（盈利绿/亏损红）

### 5.4 深色主题

自定义QSS样式 `DARK_STYLE`，与现有项目深色终端风格一致：
- 背景：#0d1117（主）/ #161b22（次）
- 文字：#c9d1d9（主）/ #8b949e（次）
- 边框：#30363d
- 强调色：#58a6ff（蓝）/ #238636（绿）/ #f85149（红）

## 七、使用说明

### 7.1 打开V7.4精准买点页面

1. 启动QuantMonitorV6主程序
2. 顶部菜单栏 → 🎯 选股复盘 → ⭐ V7.4精准买点
3. 独立窗口打开，默认大小1400×900

### 7.2 全市场扫描

1. 在"今日重点关注池"Tab或任意Tab，点击顶部"🔍 全市场扫描"按钮
2. 选择回看天数（今日/近3天/近5天/近10天）
3. 进度条显示扫描进度，状态栏显示"扫描中... X/Y只，已发现N个信号"
4. 扫描完成自动刷新3个信号Tab（重点关注池/A-B级信号/买卖计划）
5. 可点击"⏹ 取消"中止扫描

### 7.3 查看买卖计划

1. 切换到"📋 买卖计划"Tab
2. 查看每只股票的建议买入价、止盈价、止损价、仓位建议
3. 关注顶部市场状态指示器（上涨/震荡/下跌）
4. 点击"📥 导出买卖计划"保存CSV

### 7.4 查看历史交割单

1. 切换到"📊 历史交割单"Tab
2. 使用版本/等级/收益率筛选器过滤
3. 查看统计栏（胜率/平均收益/盈亏比）
4. 点击"📥 导出CSV"保存

### 7.5 手动触发复盘

1. 切换到"🔄 自动复盘结果"Tab
2. 点击"🔄 手动触发5日复盘"按钮
3. 系统调用v74_auto_feedback更新5日前信号的实际表现
4. 表格自动刷新
