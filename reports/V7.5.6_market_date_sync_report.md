# V7.5.6 行情日期同步修复报告

**修复日期**：2026-08-23
**修复范围**：V7.4精准买点页面行情日期显示与数据状态检查
**策略修改**：无（仅增加行情日期显示和数据状态检查）

---

## 一、问题描述

用户反馈V7.4精准买点页面所有信号日期都是20260806（8月6日），当前实际日期2026-08-23，扫描窗口选"近10天"但所有信号都是8月6日旧数据。

**用户怀疑**：V7.5读取旧缓存数据，没有跟主程序行情同步。

---

## 二、根本原因分析

### 实际调查结果

通过代码审计和实际测试，发现：

1. **通达信本地数据是最新的**：`C:\new_tdx`数据最新日期为20260820（8月20日，最近交易日），不是8月6日。
   - 000001平安银行：最新日期20260820，收盘价11.4
   - 000002万科A：最新日期20260820，收盘价3.14
   - 600519贵州茅台：最新日期20260820，收盘价129.15

2. **V7.4扫描没有使用旧缓存**：`scan_stock()`每次都调用`load_stock_data(engine, code, days=350)`，从TdxDataEngine实时加载K线数据，没有独立的行情缓存。

3. **信号日期是8月6日的真实原因**：策略在8月7日-8月20日期间没有产生观察级（score≥40）以上的信号。
   - 测试扫描5只股票（lookback=3），仅发现1个信号：贵州茅台(600519)，date=20260806，grade=观察，score=41
   - 8月7日-8月20日的信号都是过滤级别（score<40），被`scan_market`的`min_grade='观察'`过滤掉了
   - 这是策略信号稀疏的正常表现，不是数据同步bug

### 真正缺失的功能

虽然数据是最新的，但UI存在以下问题：
1. **没有显示当前行情日期**：用户无法判断数据是否最新
2. **没有数据状态检查**：无法区分"行情过期"和"策略最近无信号"
3. **信号日期和行情日期混淆**：用户看到信号日期是8月6日，误以为行情数据也是8月6日

---

## 三、修复内容

### 1. 新增行情日期显示（UI层）

在V7.4精准买点页面标题栏增加行情日期标签：
- 显示格式：`📅 行情日期：2026-08-20（正常）`
- 数据状态颜色：正常=绿色，轻微延迟=黄色，过期=红色，未知=灰色
- 位置：标题栏右侧，市场状态指示器旁边

### 2. 新增market_info信号（扫描线程）

在`V74ScanThread`中增加`market_info`信号，扫描开始时获取并发出最新行情日期：

```python
market_info = pyqtSignal(str, str)  # 行情日期, 数据状态
```

获取方式：
- 从TdxDataEngine获取上证指数(000001)或第一只股票的最新K线日期
- 检查日期是否过期（超过5个自然日为正常，5-10天为轻微延迟，10天以上为过期）

### 3. 新增_on_market_info处理方法

在V74PrecisionBuyPage中增加`_on_market_info(latest_date, status)`方法：
- 格式化日期显示（YYYYMMDD → YYYY-MM-DD）
- 根据数据状态设置颜色
- 更新行情日期标签

### 4. 连接market_info信号

在`_start_scan`方法中连接：
```python
self.scan_thread.market_info.connect(self._on_market_info)
```

## 六、用户使用说明

修复后，用户在V7.4精准买点页面可以看到：

1. **行情日期**：标题栏右侧显示`📅 行情日期：YYYY-MM-DD（状态）`
   - 正常（绿色）：数据在5个自然日内
   - 轻微延迟（黄色）：数据5-10天
   - 过期（红色）：数据超过10天

2. **信号日期**：股票列表中的信号日期是策略产生信号的日期，可能不是最新交易日

3. **区分理解**：
   - 如果行情日期正常但信号日期较旧 → 策略最近无高评分信号，正常现象
   - 如果行情日期过期 → 需要更新通达信数据
   - 如果行情日期正常且信号日期也是最新 → 策略当前有信号

## 七、未解决的问题

1. **策略信号稀疏**：8月7日-8月20日无观察级以上信号，这是策略本身的问题，不是数据同步问题。如果需要增加信号数量，需要调整策略参数（但用户禁止修改策略）。

2. **get_daily_kline与TdxDataEngine日期差异**：`utils.kline_provider.get_daily_kline`返回最新日期2026-08-21，而`TdxDataEngine.get_kline`返回20260820。可能是数据源或缓存差异，不影响核心功能。
