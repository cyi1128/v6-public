# V7.5.7 K线组件统一改造报告

**修复日期**：2026-08-23
**修复范围**：V7.4精准买点页面K线组件，从简易KlineViewerDialog改为复用原程序专业K线KlineContainer
**策略修改**：无（仅修改UI层K线调用方式）

---

## 一、问题描述

用户反馈V7.4精准买点页面当前调用KlineViewerDialog（简易ECharts K线），不能平移拖拽缩放。原程序自选股已有专业K线（支持鼠标拖拽、滚轮缩放、十字光标、MA5/10/20/120、MACD、KDJ、成交量、前复权）。应该直接复用原程序K线组件。

---

## 二、原程序专业K线组件分析

### 组件结构

原程序自选股K线使用以下组件：

| 组件 | 文件 | 功能 |
|------|------|------|
| KlineContainer | `ui/kline_container.py` | K线容器，ECharts优先，QPainter备用，自动降级 |
| EChartsKlineWidget | `ui/echarts_kline.py` | ECharts专业K线，支持拖拽/缩放/十字光标 |
| get_daily_kline | `utils/kline_provider.py` | K线数据提供者，通达信优先，前复权数据 |

### KlineContainer功能

- **ECharts优先**：优先使用ECharts专业K线
- **自动降级**：ECharts加载失败自动切换为QPainter
- **统一接口**：`set_kline_data(kline_data)`接受dict格式数据
- **超时保护**：5秒未初始化完成自动降级
- **支持指标**：MA5/MA10/MA20/MA120、MACD、KDJ、成交量

### 数据格式

`get_daily_kline(code, count=250)`返回：
```python
{
    'open': [],      # 开盘价列表
    'close': [],     # 收盘价列表
    'high': [],      # 最高价列表
    'low': [],       # 最低价列表
    'volume': [],    # 成交量列表
    'pct_chg': [],   # 涨跌幅列表
    'dates': [],     # 日期列表
    'period': 'day'  # 周期
}
```

`KlineContainer.set_kline_data()`接受相同格式，数据完全兼容。

## 三、修复内容

### 1. 新增专业K线对话框

新建 `ui/professional_kline_dialog.py`，封装KlineContainer为独立对话框：

**功能**：
- 嵌入KlineContainer（ECharts专业K线）
- 使用get_daily_kline加载250根日K线（前复权）
- 支持鼠标拖拽平移、滚轮缩放、十字光标
- 显示MA5/MA10/MA20/MA120、MACD、KDJ、成交量
- 顶部显示股票名称、代码、数据状态
- 底部显示操作提示
- 延迟500ms设置数据，等待KlineContainer初始化完成
- 数据设置失败自动重试（最多3次）

**接口**：
```python
ProfessionalKlineDialog(code, name, parent=None)
```

### 2. 修改V7.4页面K线调用方式

修改 `ui/v74_precision_buy_page.py` 的 `_open_stock_detail` 方法：

**修改前**：
```python
from ui.kline_viewer_dialog import KlineViewerDialog
dlg = KlineViewerDialog(code, name, parent=self)
dlg.exec()
```

**修改后**：
```python
from ui.professional_kline_dialog import ProfessionalKlineDialog
dlg = ProfessionalKlineDialog(code, name, parent=self)
dlg.exec()
```

**降级机制**：如果ProfessionalKlineDialog加载失败，自动降级到KlineViewerDialog简易K线，确保用户总能看到K线。

### 3. 保留KlineViewerDialog

不删除`ui/kline_viewer_dialog.py`文件，因为其他地方可能还在使用。V7.4页面不再调用它，但作为降级备选保留。

## 七、降级机制

如果ProfessionalKlineDialog加载失败（如ECharts环境问题），自动降级到KlineViewerDialog：

```python
try:
    from ui.professional_kline_dialog import ProfessionalKlineDialog
    dlg = ProfessionalKlineDialog(code, name, parent=self)
    dlg.exec()
except Exception as e:
    # 降级到简易K线
    from ui.kline_viewer_dialog import KlineViewerDialog
    dlg = KlineViewerDialog(code, name, parent=self)
    dlg.exec()
```

确保用户在任何环境下都能看到K线图。

## 八、未解决的问题

1. **K线窗口独立显示**：ProfessionalKlineDialog是独立对话框，不是嵌入在V7.4页面中。这与自选股页面（K线嵌入在面板中）不同，但作为股票详情查看窗口是合理的设计。

2. **周期切换**：当前只支持日K线，不支持周K/月K切换。如果需要，可以后续增加周期选择下拉框。

3. **标注功能**：不支持在K线上手动标注买卖点。如果需要，可以后续集成K线标注系统。
