### 3.2 选股逻辑（V7.6-A，当前主力）

```
输入：股票代码 + 400天K线（本地+实时补充）
  │
  ▼
第一步：基础过滤
  ├─ 主板非ST
  ├─ 市值30-230亿（原V7.4）
  ├─ 价格5-60
  └─ K线>=60天
  │
  ▼
第二步：MA20位置过滤（V7.5新增，核心优势）
  └─ 价格÷MA20 在 0.95~1.05（±5%以内）
     → 避免下降趋势股和高位追涨
  │
  ▼
第三步：趋势过滤（V7.5新增）
  └─ MA5 >= MA10 且 MA5方向向上
     → 避免下降趋势反弹
  │
  ▼
第四步：8因子100分评分
  ├─ 板块共振：20分（板块涨幅前10+10，板块涨停+10）
  ├─ MA20位置：15分（±5%内+15）
  ├─ 趋势：10分（MA5>=MA10向上+10）
  ├─ 量能：15分（放量1.2-2.5倍+15）
  ├─ MACD修复：10分（绿柱缩短/DIFF拐头+10）
  ├─ KDJ低位：10分（K<50/J拐头+10）
  ├─ 主力形态：10分（十字星/长下影/一阳穿线+10）
  └─ 注：板块因子用市场强度代理（无本地行业分类）
  │
  ▼
第五步：核心条件计数
  └─ 8项条件中满足>=3项
  │
  ▼
输出：评分>=60 且 核心>=3 → 重点买入池
      评分50-60 → 观察池
      评分40-50 → 候选（监控大厅筛选阈值）
      评分<40 → 过滤
```

**V7.6-A回测结果**（600只，7-8月）：
- 胜率53.2%，平均收益+1.42%，总盈亏+17,901元
- 止损仅7笔（比V7.4减少83%）
- 最大回撤4.00%，卡玛35.79，收益因子2.08
- 7月胜率56.7%盈利+17,886，8月微利+15（唯一8月不亏损版本）

### 3.3 交易逻辑（V7.6-A）

```
买入：
  ├─ 信号日次日低吸（开盘-1%则买，否则开盘买）
  └─ T+1规则（买入当天不能卖出）

卖出（多条件，任一触发）：
  ├─ 动态止盈：
  │   ├─ 盈利+5% → 卖出50%仓位
  │   ├─ 盈利+8% → 再卖出50%-70%
  │   └─ 剩余仓位 → 收盘价跌破5日线卖出（V7.5核心优势，最大盈利+20.57%）
  ├─ 动态止损：
  │   ├─ 亏损-5% → 减半仓
  │   └─ 亏损-7% → 全部清仓
  ├─ 时间退出（V7.6-A优化点）：
  │   └─ 第5天收盘收益<0% → 清仓
  │      （V7.5是第3天收益<2%清仓，68笔被误杀）
  └─ 最大持仓：10个交易日

仓位：模拟10万初始，每笔10%仓位
市场过滤：上涨100%/震荡50%/下跌停止
```

### 3.4 回测逻辑

**当前回测方式**：每个策略版本一个独立脚本，直接调用策略函数+交易模拟，输出CSV和统计。

**回测流程**：
```
加载600只股票K线（抽样）
  → 遍历每个交易日
    → 计算策略评分
    → 评分>=阈值 → 生成信号
    → 市场状态过滤（震荡50%）
    → 次日模拟买入
    → 持有期间检查止盈/止损/时间退出
    → 记录交割单
  → 统计胜率/盈亏比/回撤/年化
```

**问题**：
1. 600只抽样而非全市场2232只
