## 三、买点计算流程

### 3.1 整体架构

```
K线数据输入
    │
    ▼
┌─────────────────────────────────┐
│ 1. K线数据解析 (KlineDataParser) │  统一 dict/list[dict] 格式
└─────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────┐
│ 2. 技术指标计算                   │
│    MA5/10/20/60                  │
│    MACD(8,21,5)                  │
│    KDJ(13,3,3)                   │
│    ATR(14)                       │
│    量比(5日)                      │
└─────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────┐
│ 3. 接入外部模块（全部容错）        │
│    ├─ 缠论 ChanlunCore           │  买卖点/背驰/中枢/趋势
│    ├─ 涨停回调 LimitUpPullback   │  模型评分/支撑压力
│    ├─ 箱体突破 BoxBreakout       │  模型评分/支撑压力
│    ├─ 量价突破 VolumeBreakout    │  模型评分/支撑压力
│    ├─ 市场环境 MarketEnvironment │  评分/类型/系数
│    └─ K线形态 AIPatternAnalyzer  │  可选（需annotation）
└─────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────┐
│ 4. 四个买点类型检测               │
│    A 主升启动 (5条件，≥4匹配)     │
│    B 涨停回调 (5条件，≥4匹配)     │
│    C 五买确认 (5条件，≥3匹配)     │
│    D 横盘突破 (4条件，≥3匹配)     │
└─────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────┐
│ 5. 确定主买点类型和等级           │
│    取匹配类型中评分最高者         │
│    无匹配时取最接近类型(形成中)   │
└─────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────┐
│ 6. 多因子评分 (100分制)           │
│    趋势因子 30分 (多头/站20/60日) │
│    资金因子 30分 (持续流入/量比/增长)│
│    形态因子 20分 (模式库/买点匹配) │
│    情绪因子 20分 (涨停/热度/市场/板块)│
└─────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────┐
│ 7. 买入位置计算                   │
│    最佳区间 = 当前价 ± 0.5×ATR   │
│    突破价 = 前高压力 × 1.005     │
│    止损 = min(支撑-1.5ATR, MA20×0.97)│
│    目标 = 突破价 + 风险×(2~3盈亏比)│
└─────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────┐
│ 8. 风险等级 + 星级 + 解释系统     │
│    风险: 低/中/高 (评分+止损空间) │
│    星级: 1-5星 (评分阈值)        │
│    解释: 为什么买/风险/满足/未满足 │
└─────────────────────────────────┘
    │
    ▼
BuyPointResult (完整可追溯结果)
```

### 3.2 四个买点类型检测逻辑

#### A型：主升启动点
| 条件 | 检测逻辑 | 阈值 |
|------|---------|------|
| MA5上穿MA10 | 近3天内MA5从下方穿越MA10 | 回看3天 |
| 成交量放大 | 近5日均量比 ≥ 1.5 | 量比≥1.5 |
| MACD金叉 | 近3天内DIF上穿DEA | MACD(8,21,5) |
| KDJ低位金叉 | K值<50 且金叉 | KDJ(13,3,3) |
| 突破压力位 | 收盘价 > 近20日高点×0.995 | 缓冲0.5% |

匹配条件：≥4个条件满足

#### B型：涨停回调低吸
| 条件 | 检测逻辑 | 阈值 |
|------|---------|------|
| 近期启动 | 近30日内有涨停(≥9.5%)或大阳(≥5%) | 回看30天 |
| 回撤幅度 | 从启动后高点回撤 5%-15% | 5%≤回撤≤15% |
| 缩量调整 | 近5日均量 < 前5日×0.75 | 缩量比0.75 |
| 不破20日线 | 当前价 ≥ MA20×0.98 | 容差2% |
| 再次放量 | 近3日均量 > 缩量阶段×1.05 | 回升5% |

匹配条件：≥4个条件满足

#### C型：五买确认
| 条件 | 检测逻辑 | 阈值 |
|------|---------|------|
| 底背离/下跌结束 | 价格创新低但MACD未创新低，或近5日不再创新低 | — |
| MACD改善 | DIF拐头向上 或 绿柱缩短 | 近3天 |
| KDJ低位金叉 | K值<30 且金叉 | KDJ(13,3,3) |
| 量能恢复 | 近3日均量 > 缩量阶段×0.8 | 恢复比0.8 |
| 五买MA5承接 | 倍量启动后缩量回踩，价格接近/站上MA5 | 容差3% |

匹配条件：≥3个条件满足（C型要求较低，观察/试仓）

#### D型：横盘突破
| 条件 | 检测逻辑 | 阈值 |
|------|---------|------|
| 横盘整理 | 20-60天整理区间，振幅<25% | 20≤天数≤60 |
| 放量突破 | 突破日量比 ≥ 1.3（相对横盘均量） | 量比≥1.3 |
| 突破箱体 | 收盘价 > 箱体上沿×0.995 | 缓冲0.5% |
| 均线发散 | 横盘期间均线粘合(差距<8%)，当前MA5>MA10>MA20 | — |

匹配条件：≥3个条件满足

### 3.3 多因子评分明细

**趋势因子（30分）**
- 多头排列 MA5>MA10>MA20：+10分（部分多头+5）
- 股价站上20日线：+10分（接近+5）
- 60日趋势向上（MA60上行或60日涨幅>0）：+10分

**资金因子（30分）**
- 近3日持续放量上涨（≥2阳且量递增）：+10分
- 量比1.2-3（健康放量）：+10分（爆量+5，平稳+3）
- 近5日均量较前5日增长>20%：+10分（增长>0+5）

**形态因子（20分）**
- 模式库最高分归一化（涨停回调/箱体/量价突破）：+10分
- 买点类型匹配度（四类型最高分归一化）：+10分
- 缠论买点信号额外加分：最多+1分

**情绪因子（20分）**
- 近60日涨停次数（≥5次+5，≥3次+3.5，≥1次+2）
- 近20日涨幅（5-30%热度最高+5，过热+1）
- 市场环境评分（≥70+5，≥50+3.5，≥30+2）
- 板块强度（市场环境系数≥1.2+5，≥1.0+3.5）

### 3.4 买入位置计算

| 价格项 | 计算公式 | 依据 |
|--------|---------|------|
| 最佳买入区间下限 | 当前价 - 0.5×ATR | ATR波动 |
| 最佳买入区间上限 | 当前价 + 0.25×ATR | 偏紧上限 |
| 突破价 | min(前高压力候选) × 1.005 | 前高压力 |
| 止损价 | min(支撑位-1.5×ATR, MA20×0.97)，不低于当前价×0.85 | 支撑位+ATR |
| 目标价下限 | 突破价 + (突破价-止损)×2.0 | 2:1盈亏比 |
| 目标价上限 | 突破价 + (突破价-止损)×3.0 | 3:1盈亏比 |

**支撑位候选**（取最小值）：MA20、近20日低点、三个模型库支撑位、缠论支撑位、横盘箱体底部
**压力位候选**（取最小值）：近20日高点、三个模型库压力位、横盘箱体顶部

## 六、集成方式

### 6.1 基本使用

```python
from strategy.buy_point_engine import BuyPointEngine, get_buy_point_engine

# 方式1：直接实例化
engine = BuyPointEngine()
result = engine.analyze(kline_data, code="600000", name="浦发银行")

# 方式2：使用单例
result = get_buy_point_engine().analyze(kline_data, code="600000")

# 方式3：便捷函数
from strategy.buy_point_engine import analyze_buy_point
result = analyze_buy_point(kline_data, code="600000", name="浦发银行")

# 输出
print(result.to_dict())  # 完整JSON可序列化字典
print(result.grade)      # 买点等级 A/B/C/D/N
print(result.buy_type)   # 买点类型
print(result.score)      # 综合评分
print(result.price_levels.best_buy_low)  # 最佳买入下限
```

### 6.2 输入格式

`kline_data` 支持两种格式（通过 `KlineDataParser` 自动识别）：

**格式1：Dict数组**
```python
{
    "dates": ["20260801", "20260802", ...],
    "open": [10.0, 10.5, ...],
    "high": [10.8, 11.0, ...],
    "low": [9.9, 10.3, ...],
    "close": [10.5, 10.8, ...],
    "volume": [1000000, 1200000, ...],
    "amount": [10500000, 12960000, ...]  # 可选
}
```

**格式2：List[Dict]**
```python
[
    {"date": "20260801", "open": 10.0, "high": 10.8, "low": 9.9, "close": 10.5, "volume": 1000000},
    ...
]
```

最低要求：≥30根K线。

### 6.3 与现有选股流程集成

在现有多因子选股中心（`layered_scanner.py`）扫描出候选股后，可直接接入买点引擎：

```python
# 伪代码：选股后追加买点分析
from strategy.buy_point_engine import get_buy_point_engine
from data.tdx_data_engine import get_tdx_data_engine

tdx = get_tdx_data_engine()
buy_engine = get_buy_point_engine()

for stock in scan_results:
    kline = tdx.get_kline(stock["code"], days=120)
    if kline:
        buy_result = buy_engine.analyze(kline, code=stock["code"], name=stock["name"])
        stock["buy_point"] = buy_result.to_dict()
        # 可按 buy_point.score 排序，筛选高评分买点
```

### 6.5 外部模块接入说明

BuyPointEngine 通过**延迟初始化 + 容错**方式接入以下模块，任一模块不可用不影响整体：

| 模块 | 接入方式 | 用途 | 不可用时 |
|------|---------|------|---------|
| `strategy.chanlun_core.ChanlunCore` | `get_chanlun_core()` | 缠论买卖点/背驰/中枢 | chanlun_result={"error":...} |
| `strategy.models.limit_up_pullback` | 直接实例化 | 涨停回调模型评分 | model_results对应项error |
| `strategy.models.box_breakout` | 直接实例化 | 箱体突破模型评分 | 同上 |
| `strategy.models.volume_breakout` | 直接实例化 | 量价突破模型评分 | 同上 |
| `strategy.market_environment` | `get_market_environment()` | 市场环境评分/系数 | market_env={"error":...}，情绪因子用中性分 |
| `kline_annotation_training.ai_pattern_analyzer` | 直接实例化 | K线形态分析（需annotation） | 跳过，不影响 |

### 6.6 可配置参数

所有阈值参数集中在 `BuyPointEngine.params` 字典中，可运行时调整：

```python
engine = BuyPointEngine()
engine.params["a_volume_ratio_min"] = 1.3  # 放宽A型量比要求
engine.params["b_pullback_max"] = 20.0     # 放宽B型最大回撤
engine.params["stop_loss_atr_mult"] = 2.0  # 放宽止损到2倍ATR
```

## 七、数据结构定义

### BuyPointResult

| 字段 | 类型 | 说明 |
|------|------|------|
| code | str | 股票代码 |
| name | str | 股票名称 |
| date | str | K线最新日期 |
| grade | str | 买点等级 A/B/C/D/N |
| buy_type | str | 买点类型（主升启动/涨停回调/五买确认/横盘突破/无明显买点） |
| score | float | 综合评分 0-100 |
| score_breakdown | ScoreBreakdown | 四维评分明细 |
| stars | int | 星级 1-5 |
| risk_level | str | 风险等级 低/中/高 |
| price_levels | PriceLevels | 买入价格计算结果 |
| reasons | List[str] | 为什么买 |
| risks | List[str] | 风险在哪里 |
| conditions_met | List[str] | 满足的条件 |
| conditions_not_met | List[str] | 未满足的条件 |
