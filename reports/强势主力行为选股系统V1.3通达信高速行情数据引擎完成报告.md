# 强势主力行为选股系统 V1.3 完成报告

## 通达信高速行情数据引擎

---

## 一、修复背景

V1.2.5 虽然解决了 L1 架构和真实股票列表问题，但扫描仍依赖网络 API 获取 K 线数据，主板 2000+ 只股票扫描需要 1-2 分钟。

**核心问题**：网络 API 获取 K 线慢、不稳定、有频率限制。

**解决方案**：直接读取通达信本地 `.day` 二进制文件，全部数据从内存读取，零网络请求。

---

## 二、新增模块

### 1. 通达信本地数据引擎 `data/tdx_data_engine.py`

#### .day 文件二进制格式
每根 K 线 32 字节：
| 偏移 | 长度 | 类型 | 字段 | 说明 |
|------|------|------|------|------|
| 0 | 4 | uint32 | date | 日期 YYYYMMDD |
| 4 | 4 | float32 | open | 开盘价 |
| 8 | 4 | float32 | high | 最高价 |
| 12 | 4 | float32 | low | 最低价 |
| 16 | 4 | float32 | close | 收盘价 |
| 20 | 4 | float32 | amount | 成交量（手） |
| 24 | 4 | float32 | vol | 成交额（元） |
| 28 | 4 | float32 | reserved | 保留 |

#### TdxDataEngine 类核心方法

| 方法 | 说明 |
|------|------|
| `is_available()` | 检查通达信本地数据是否可用 |
| `get_kline(code, days)` | 读取单只股票最近 N 天 K 线（内存缓存优先） |
| `get_kline_batch(codes, days)` | 批量读取，8 线程并行读取本地文件 |
| `get_all_main_board_codes()` | 扫描本地 .day 文件目录，获取所有主板股票代码 |
| `get_latest_price(code)` | 从 K 线最后一根获取最新价格和涨跌幅 |
| `preload_to_memory(codes, days)` | 预加载股票 K 线到内存缓存（8 线程并行） |
| `get_memory_cache_stats()` | 返回内存缓存统计（股票数/K线总数/内存占用/最新日期） |
| `get_latest_data_date()` | 获取本地数据最新日期 |
| `is_data_up_to_date()` | 检查本地数据是否为今日 |

#### 关键性能优化
- **批量读取**：`ThreadPoolExecutor(max_workers=8)` 8 线程并行读取本地文件
- **内存缓存**：预加载后 K 线存在字典 `{code: kline_list}`，扫描时直接读内存
- **只读需要的天数**：从文件末尾倒序读取 N 根，`f.seek(offset)` 不读全部历史
- **自动路径检测**：支持 `C:\new_tdx`、`D:\new_tdx`、`C:\通达信` 等常见路径，也支持配置文件自定义

## 三、修改模块

### 1. `strategy/main_force_behavior.py`

#### 数据获取优先级（V1.3）
```
第一优先：通达信本地数据引擎（TdxDataEngine，内存缓存+本地.day文件）
第二优先：DuckDB本地缓存（kline_cache_db.py，增量更新）
第三优先：聚宽JQData（如果已认证）
第四优先：网络API（通达信pytdx / 腾讯 / 东方财富）
```

#### `_get_kline_with_fallback` 修改
在方法最前面增加通达信本地数据检查：
```python
# V1.3：第一优先 - 通达信本地数据引擎
if self.tdx_engine and self.tdx_engine.is_available():
    kline = self.tdx_engine.get_kline(code, days=days, use_cache=True)
    if kline and len(kline) >= min(days, 20):
        self._kline_cache_hits += 1
        return kline
```

#### `scan_full_market` 步骤2 修改
增加通达信本地零网络扫描路径：
1. 如果通达信可用，从本地文件目录获取主板股票列表
2. 预加载所有主板 K 线到内存（8 线程并行，约 5-10 秒）
3. 从内存 K 线构建股票列表（含最新行情 price/change_pct/volume/amount）
4. 设置 `_stock_list_has_quotes=True`，L1 零额外网络请求
5. 整个扫描过程 L1/L2/L3 全部从内存读取 K 线

通达信不可用时，降级到 V1.2.5 的东方财富 → 通达信网络 → 失败终止流程。

### 2. `ui/force_behavior_panel.py`

#### 缓存状态条增加数据源显示

💾 最后扫描: 2026-08-20 15:00 | 缓存股票: 86只 | 模式: 快速扫描 | 状态: 有效

通达信不可用时显示：
```

```

### 3. `ui/main_window.py`

#### 启动预加载增加通达信 K 线预加载
程序启动后 3 秒，`_preload_force_behavior` 分两步：
1. **通达信 K 线预加载**（如果可用）：8 线程并行读取所有主板 .day 文件到内存，最多等 30 秒
2. **完整扫描预加载**：利用内存 K 线执行快速扫描，交易时段且无有效缓存时启动

## 四、修复后扫描流程（通达信可用时）

```
程序启动
  ↓
3秒后后台预加载
  ├─ 通达信K线预加载到内存（8线程，5-10秒）
  └─ 完整扫描（内存读取，10-30秒）
  ↓
打开选股面板
  ↓ 直接看结果（缓存有效）
  ↓ 或点击重新扫描
扫描开始
  ├─ 步骤1：数据提供者检查
  ├─ 步骤2：通达信本地扫描
  │   ├─ 从.day文件目录获取主板股票列表（~2000只）
  │   ├─ 预加载K线到内存（8线程，5-10秒）
  │   └─ 从内存K线构建股票列表+行情（零网络）
  ├─ 步骤3：主板过滤
  ├─ L1基础筛选：从内存K线最新一根获取行情（零网络，<1秒）
  ├─ L2行为预筛：从内存读30日K线（零网络，~5秒）
  └─ L3深度分析：从内存读120日K线+三模型+AI评分（零网络，~15秒）
  ↓
输出股票池（50-300只）
```

**整个扫描过程零网络请求，全部从内存读取。**

## 五、性能对比

## 六、备用机制

### 通达信不可用时
- 自动检测 `.day` 文件目录是否存在
- 不存在时降级到 DuckDB 缓存 → 聚宽 → 网络 API
- UI 显示警告 `⚠️网络API（通达信本地不可用）`，不崩溃

### 数据更新提示
- 通达信本地数据需要用户在通达信软件中下载盘后数据
- 如果 K 线最新日期不是今天，UI 显示 `数据日期: 2026-08-19（非今日）`
- 建议用户在通达信中执行「盘后数据下载」

### 配置自定义路径
- `config/tdx_path.json` 中设置 `tdx_path` 字段
- 留空自动检测常见路径
- 支持多个路径自动检测

## 十、用户操作建议

1. **安装通达信**：确保电脑已安装通达信软件（如 `C:\new_tdx`）
2. **下载盘后数据**：在通达信中执行「系统 → 盘后数据下载」，确保数据更新到最新交易日
3. **配置路径**：如果通达信安装在非标准路径，修改 `config/tdx_path.json` 的 `tdx_path` 字段
4. **启动程序**：程序启动后 3 秒自动后台预加载通达信 K 线到内存
5. **查看数据源**：选股面板缓存状态条显示 `📡 数据源: ✅通达信本地` 表示本地数据已启用
6. **数据日期检查**：如果显示 `数据日期: 非今日`，请在通达信中下载最新盘后数据
