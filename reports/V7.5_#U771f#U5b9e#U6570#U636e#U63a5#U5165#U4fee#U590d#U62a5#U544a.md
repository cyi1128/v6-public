## 二、根本原因分析

### 2.1 字段名不匹配（核心原因）

`V74BuyPointLayer.scan_stock()` 返回的字段是：
- `code`（而非UI中使用的 `stock_code`）
- `name`（而非UI中使用的 `stock_name`）
- `price`（而非UI中使用的 `current_price`）

UI代码中全部使用 `r.get('stock_code', '')`、`r.get('stock_name', '')`、`r.get('current_price', 0)`，导致全部返回默认空值/0。

### 2.2 股票名称数据源问题

`TdxDataEngine.get_stock_list_with_names()` 返回的 `name` 字段为空字符串，导致 `V74BuyPointLayer` 中 `name = item.get('name') or code` 回退为代码本身。

项目中存在真实名称文件 `data/stock_names_full.json`（5200条，000001→平安银行），但未被V7.4页面使用。

### 2.3 历史数据代码格式问题

V7.4.6/V7.4.7/V7.4.8的CSV中 `code` 字段为整数（如670），读取后未做 `zfill(6)` 补零。

### 2.4 A/B级信号判断逻辑问题

原代码仅判断 `grade == 'A级'` 或 `grade == 'B级'`，但扫描结果中大部分信号 `grade` 为 `'重点关注'`，且 `top1_raw_trigger`/`top3_raw_trigger` 字段未被用于判断A/B级。

### 2.5 止盈止损价计算基准问题

原代码止盈价 = `当前价 × 1.08`，止损价 = `当前价 × 0.93`，但根据冻结交易规则，应基于**建议买入价**（当前价×0.99）计算。

## 三、修复内容

### 3.1 新增工具函数（文件顶部）

| 函数 | 功能 |
|------|------|
| `get_stock_name_map()` | 从 `data/stock_names_full.json` 懒加载5200条code→name映射 |
| `resolve_stock_name(code)` | 根据代码获取真实名称，找不到返回代码 |
| `normalize_code(code)` | 代码标准化为6位补零字符串（670→000670） |
| `translate_sell_reason(reason)` | 卖出原因英文→中文（stop_loss→止损-7%等） |
| `translate_signal_status(status)` | 信号状态英文→中文（closed→已完成等） |
| `SELL_REASON_CN` / `SIGNAL_STATUS_CN` | 翻译映射字典 |

### 3.2 V74ScanThread字段转换（扫描结果）

在扫描完成后、返回结果前，对每条结果做：
1. `code` → `stock_code`（6位补零）
2. `name` → `stock_name`（用真实名称映射替换代码）
3. `price` → `current_price`（转为float）
4. 过滤 `enhanced_score >= 50`

### 3.3 历史交割单数据修复

`load_trade_orders()` 函数增强：
1. 代码补零：`str(code).zfill(6)`
2. 名称映射：如果CSV中name为空或为数字，用 `stock_names_full.json` 映射
3. 卖出原因中文化：遍历 `sell_reason`/`second_sell_reason`/`first_sell_reason` 字段翻译

### 3.4 自动复盘数据修复

`load_feedback_signals()` 函数增强：
1. 代码补零
2. 名称映射
3. 状态中文化：新增 `status_cn` 字段
4. 字段统一：`signal_date`→`date`，`enhanced_score`→`score`

### 3.5 A/B级信号填充逻辑修复

`_update_ab_signals()` 重写：
1. **A级判断**：`grade == 'A级'` 或 `top1_raw_trigger=True and top3_raw_trigger=False`
2. **B级判断**：`grade == 'B级'` 或 `top3_raw_trigger=True and top1_raw_trigger=False`
3. **S级判断**：`grade == 'S级'` 或 `top1_raw_trigger=True and top3_raw_trigger=True`（归入A级Tab展示）
4. 止盈止损显示具体价格（如 `+8% (10.69)`）
5. 按评分降序排列
6. **空状态提示**：无信号时在表格第一行显示"暂无A级/S级信号"提示，而非空白

### 3.6 止盈止损价计算基准修复

`_update_focus_pool()` 和 `_update_trade_plan()` 中：
- 修复前：止盈价 = 当前价 × 1.08，止损价 = 当前价 × 0.93
- 修复后：止盈价 = **建议买入价** × 1.08，止损价 = **建议买入价** × 0.93
- 建议买入价 = 当前价 × 0.99（次日低吸规则）

### 3.7 K线接入

`_open_stock_detail()` 重写：
- 修复前：显示QMessageBox信息弹窗
- 修复后：延迟导入 `ui.kline_viewer_dialog.KlineViewerDialog`，传入code+name，以模态对话框显示K线图
- 降级处理：K线组件加载失败时回退为信息弹窗

## 五、代码补零和名称映射实现方式

### 5.1 代码补零

```python
def normalize_code(code):
    if code is None:
        return ''
    return str(code).zfill(6)
```

应用场景：
- 扫描结果：`code = normalize_code(r.get('code'))`
- 历史交割单：读取CSV后 `r['code'] = normalize_code(r.get('code'))`
- 自动复盘：DB读取后 `r['stock_code'] = normalize_code(r.get('stock_code'))`

### 5.2 名称映射

```python
def get_stock_name_map():
    # 懒加载，从data/stock_names_full.json读取
    global _STOCK_NAME_MAP
    if _STOCK_NAME_MAP is not None:
        return _STOCK_NAME_MAP
    _STOCK_NAME_MAP = {}
    json_path = os.path.join(PROJECT_ROOT, 'data', 'stock_names_full.json')
    with open(json_path, 'r', encoding='utf-8') as f:
        data = json.load(f)
    _STOCK_NAME_MAP = {str(k).zfill(6): v for k, v in data.items()}
    return _STOCK_NAME_MAP
```

名称补全逻辑：
1. 优先使用数据源中已有的name字段
2. 如果name为空、等于code、或为纯数字，用 `stock_names_full.json` 映射
3. 映射找不到时回退为code本身
