## 二、根本原因分析

### 2.1 核心原因：lookback差异（最关键）

| 指标 | lookback=1（生产默认） | lookback=10（回测方式） |
|------|----------------------|----------------------|
| 有效股票 | 200/200 | 200/200 |
| 平均评分 | 26.66 | 42.17 |
| 最高评分 | 46.00 | 61.00 |
| >=50分 | **0只** | **35只** |
| 重点关注 | 0只 | 33只 |
| 观察级 | 6只 | 87只 |
| 过滤级 | 194只 | 76只 |
| A级 | 0只 | 2只 |
| B级 | 0只 | 2只 |

**结论：** 生产UI默认lookback=1只看最新一天，而回测用lookback多天取历史最佳评分位置。最新一天（2026-08-23）市场环境下，前200只中0只达到50分，最高仅46分。

### 2.2 名称映射100%失效

- `TdxDataEngine.get_stock_list_with_names()` 返回的name字段为空字符串
- `V74BuyPointLayer.__init__` 中 `name = item.get('name') or code` 回退为代码
- 200/200只股票名称等于代码（如000001显示为"000001"而非"平安银行"）
- 项目中存在 `data/stock_names_full.json`（5200条真实名称），但未被使用

### 2.3 UI二次过滤丢弃观察级

- `V74ScanThread` 在扫描完成后执行 `filtered = [r for r in normalized if r.get('enhanced_score', 0) >= 50]`
- 这导致观察级（40-50分）被全部丢弃
- 用户期望看到"重点关注10-30只 + 观察约100只"，但UI只显示重点关注

### 2.4 K线图不显示

- `KlineViewerDialog._load_kline()` 使用 `utils.kline_provider.get_daily_kline()`
- 该函数返回dict而非list，且仅8条数据（count=250时）
- 异步线程加载 + `QTimer.singleShot` 在子线程中不工作
- 导致 `kline_data` 始终为空，K线画布显示"暂无K线数据"

### 2.5 TOP1/TOP3原始触发为0（正常现象）

- `TOP1_RAW_CONDITIONS = ['ma_bullish', 'yang_cross_ma', 'vol_shrink']` 要求3个条件同时触发
- `TOP3_RAW_CONDITIONS = ['kdj13_j_low', 'macd12_26_red_expand', 'macd8_21_green_shrink']` 要求3个条件同时触发
- `check_raw_trigger` 要求所有条件同时为True，非常严格
- 200只中0只同时满足，属于正常现象（A/B级信号本身就稀缺）

## 四、生产扫描 vs 回测差异对比

| 维度 | 生产扫描（修复前） | V7.4.8回测 | 差异原因 |
|------|-------------------|-----------|---------|
| lookback | 1天（最新一天） | 多天（取历史最佳） | 核心差异 |
| 股票来源 | 全市场2232只主板 | 全市场2177只有效 | 基本一致 |
| K线天数 | 350天 | 350天 | 一致 |
| 评分函数 | evaluate_buy_point | 同一函数 | 一致 |
| 等级阈值 | >=50重点关注, 40-50观察 | 同一阈值 | 一致 |
| UI过滤 | 二次过滤score>=50 | 不过滤，统计所有等级 | UI丢弃观察级 |
| 名称映射 | 失效（显示代码） | 回测不依赖名称 | 生产特有问题 |
| K线图 | 不显示（数据源错误） | 回测不涉及K线 | 生产特有问题 |

## 五、审计结论

1. **扫描链路本身无bug**：K线加载、指标计算、评分函数均正常工作，200/200只完成评分
2. **核心问题是lookback=1**：最新一天市场环境下高分股票极少，前200只中0只>=50分
3. **名称映射失效**：200/200只名称等于代码，需改用stock_names_full.json
4. **UI丢弃观察级**：二次过滤score>=50导致观察级不显示
5. **K线图数据源错误**：utils.kline_provider返回8条dict数据，不适合K线绘制
6. **A/B级为0是正常现象**：TOP1/TOP3原始触发条件严格，同时满足3个条件的股票极少
