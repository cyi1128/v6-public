## 三、各方案详细分析

### 3.1 方案A：半仓止盈+MA5保护

**规则**：盈利≥+5%时卖出50%仓位，剩余50%用MA5保护（收盘破MA5卖出）。

| 指标 | 数值 |
|------|------|
| 交易数 | 681笔 |
| 胜率 | 60.5%（4种方案最高） |
| 盈亏比 | 0.97（低于1，平均亏损>平均盈利） |
| 半仓触发 | 356笔（52.3%） |
| 触发后半仓胜率 | 96.1% |
| 触发后半仓均收益 | +4.83% |
| 未触发半仓胜率 | 21.5% |
| 未触发半仓均收益 | -3.41% |

**分析**：
- 半仓止盈触发后效果极好（胜率96.1%），但触发率仅52.3%
- 未触发的47.7%交易中，很多直接止损-7%，胜率仅21.5%，拉低整体盈亏比到0.97
- 半仓止盈后剩余仓位用MA5保护，部分回吐利润，平均盈利仅+4.52%（4种方案最低）
- 最大盈利+33.73%，说明MA5保护确实捕获了部分大趋势
- 但整体盈亏比<1，意味着长期来看每笔平均亏损大于平均盈利，仅靠胜率60.5%维持正收益

**结论**：半仓止盈提升了胜率，但牺牲了盈亏比。不推荐作为主方案。

### 3.2 方案B：利润锁定（止损上移到+3%）

**规则**：盈利≥+8%时不止盈，止损上移到成本价+3%，继续持有到止损触发或第10天。

| 指标 | 数值 |
|------|------|
| 交易数 | 658笔 |
| 胜率 | 56.1% |
| 盈亏比 | 1.02（几乎不赚钱） |
| 最大回撤 | -11.27%（超标） |
| 年化 | 7.1%（4种方案最低） |
| 最大单笔盈利 | +103.39% |

**分析**：
- 与V7.4.7的方案B结果一致，盈亏比1.02意味着几乎白干
- 锁定3%利润后，很多股票从+8%回落到+3%被卖出，平均盈利被压缩到+4.95%
- 虽然有1笔+103%的大盈利，但无法弥补大量+3%的小盈利
- 最大回撤-11.27%超标，因为利润锁定后止损上移，部分股票从高位回落幅度大
- 年化仅7.1%，远低于15%目标

**结论**：锁定3%利润是最差方案，盈亏比和回撤都不达标。不推荐。

### 3.3 方案C：趋势增强（MA5>MA10继续持有）

**规则**：盈利≥+8%时检查MA5>MA10：是则MA5保护继续持有，否则立即止盈+8%。

- 但胜率52.2%未达55%，主要因为MA5跌破卖出有时会卖在回调低点

## 四、关键发现与洞察

### 4.1 半仓止盈触发后效果极好，但未触发的交易拖累整体

方案A中：
- 触发半仓的356笔：胜率96.1%，均收益+4.83%
- 未触发半仓的325笔：胜率21.5%，均收益-3.41%

**洞察**：能涨到+5%的股票质量明显更高，而涨不到+5%的股票大部分亏损。半仓止盈本质上是一个"质量过滤器"，但它无法改变未触发交易的亏损。

### 4.2 趋势增强让盈利奔跑，但牺牲了胜率

方案C中：
- 平均盈利+6.84%（比D高0.82pp）
- 最大盈利+103.39%（D仅+8%）
- 但胜率52.2%（比D低3.9pp）

**洞察**：MA5保护确实能捕获大趋势（16.1%的交易最高浮盈>10%），但也会在回调时被洗出，降低胜率。盈亏比从1.24提升到1.49，主要靠平均盈利提升，而非胜率提升。

### 4.3 利润锁定（方案B）是陷阱

方案B中：
- 盈亏比1.02，几乎不赚钱
- 回撤-11.27%超标
- 年化仅7.1%

**洞察**：锁定3%利润看似安全，但实际上把很多能涨到+10%以上的股票在+3%就洗出了，同时止损上移到+3%后，部分股票从高位回落幅度大，导致回撤超标。"锁定利润"反而锁定了低收益。

### 4.4 固定+8%止盈（方案D）是最稳健的选择

方案D中：
- 胜率56.1%、年化15.7%、回撤-5.79%三项最优
- 止盈:止损 = 1.59:1，盈利来源清晰
- 逻辑简单，实盘易执行

**洞察**：虽然盈亏比1.24未达1.5，但胜率56%意味着每100笔赚56笔，整体期望为正。在3年验证中总收益+60.7%最高，说明固定止盈在长期来看是最稳健的。

### 4.5 没有"完美方案"，需要在胜率和盈亏比之间取舍

| 方案 | 胜率优势 | 盈亏比优势 | 综合评价 |
|------|---------|-----------|---------|
| A半仓 | ✅ 60.5%最高 | ❌ 0.97最低 | 胜率高但盈亏比<1 |
| B锁定 | ✅ 56.1% | ❌ 1.02 | 表现最差 |
| C趋势 | ❌ 52.2% | ✅ 1.49最高 | 盈亏比接近达标 |
| D对照 | ✅ 56.1% | ⚠️ 1.24 | 综合最稳健 |

**洞察**：提升盈亏比的方法（让利润奔跑）必然牺牲胜率（回调时被洗出）。没有方案能同时达到胜率55%+和盈亏比1.5+。需要根据个人风险偏好选择。

## 五、最佳方案推荐

### 5.1 推荐主方案：D（对照+过滤观察级）

**推荐理由**：

1. **胜率56.1%达标**：4种方案中并列最高
2. **年化15.7%最高且达标**：进入15%-25%目标区间
3. **回撤-5.79%最低**：远低于8%目标，安全边际充足
4. **总收益+60.7%最高**：3年累计收益最高
5. **A级表现优异**：胜率64.7%，盈亏比1.52
6. **逻辑简单清晰**：+8%止盈/-7%止损/10天持仓，实盘容易执行和复盘
7. **止盈:止损=1.59:1**：盈利来源清晰，不是靠运气

**唯一不足**：盈亏比1.24未达1.5（差0.26）。但胜率56%已弥补，整体期望收益为正（+1.24%/笔）。

### 5.2 可选增强方案：C（趋势增强）

**适用场景**：
- 愿意接受略低胜率（52.2%）换取更高盈亏比（1.49）
- 重点关注级股票（盈亏比1.50达标）
- 趋势行情（MA5保护能捕获大盈利，最大+103%）

**不适用**：
- A级股票（趋势增强下胜率仅44.4%）
- 震荡行情（MA5频繁被跌破）

### 5.3 不推荐方案

- **方案A（半仓+MA5）**：盈亏比0.97<1，平均亏损大于平均盈利，长期不可持续
- **方案B（锁定3%）**：盈亏比1.02几乎白干，回撤-11.27%超标，年化仅7.1%
