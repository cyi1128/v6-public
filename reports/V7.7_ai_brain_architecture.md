## 二、核心模块说明

### 1. DataHub — 统一数据接口 (`data_hub.py`)

**职责**: 从已有模块读取信号、评分、因子、交割单、K线数据，做数据聚合和标准化。

**核心功能**:
- `load_trade_orders(filepath)`: 自动识别中英文列名，返回标准化DataFrame
- `load_all_historical_trades()`: 加载所有历史交割单，合并去重
- `get_kline(code, days)`: 获取K线数据
- `get_realtime_signals(lookback)`: 从V7.6生产层获取实时信号
- `get_stock_name_map()`: 股票代码→名称映射

**数据来源**: V7.4.4/6/7/8交割单、V7.5.8/10/11/12/14交割单、V7.6生产层、通达信K线

### 2. TradeMemory — 交易记忆系统 (`trade_memory.py`)

**职责**: 自动保存每一次股票信号，形成交易经验数据库（SQLite）。

**数据库结构**:
- `trades`表: 交易记录（代码/名称/信号日/买卖价/收益率/等级/评分/模型/市场状态/板块）
- `trade_factors`表: 每笔交易的因子快照（MA/MACD/KDJ/RSI/量价/位置/形态）
- `learning_results`表: 学习结果（因子名/胜率/收益/贡献度）

**核心功能**:
- `import_trades(df)`: 从DataFrame导入交易（自动去重）
- `get_all_trades()` / `get_winning_trades()` / `get_losing_trades()`: 查询
- `find_similar_trades(code, signal_date)`: 基于因子相似度搜索相似历史案例
- `get_stats()`: 交易统计摘要
- `save_factor_snapshot(trade_id, factors)`: 保存因子快照

**当前数据**: 19,947笔历史交易（2023-07 ~ 2026-07），胜率50.1%，盈亏比1.35

### 3. FactorLearningEngine — 因子学习引擎 (`factor_learning_engine.py`)

**职责**: 自动分析全部筛选因素，发现盈利/亏损股票共同特征，输出因子贡献度。

**因子类别**（17类）:
- 趋势因子: MA5>MA20、价格>MA20、均线趋势强度
- MACD因子: 柱状图正负、金叉
- KDJ因子: 超买(J>80)、超卖(J<20)、J值区间
- 量价因子: 成交量>5日均量、量比区间、振幅区间
- 位置因子: 5日涨幅区间、距离60日高点区间
- 评分因子: 综合评分区间
- 执行因子: 持仓天数区间

**核心功能**:
- `extract_factors_from_klines(klines, signal_idx)`: 从K线提取17类因子
- `analyze_trades(trades_df, max_samples)`: 分析交易数据，计算因子贡献度
- `generate_optimization_suggestions(contribution)`: 生成优化建议（只建议，不自动修改）

**关键发现**（181笔样本）:
- MACD柱状图为正: 胜率+11.4%，收益+1.55%（**最强正向因子**）
- KDJ超买(J>80): 胜率-27.1%，收益-1.84%（**最强负向因子**）
- 评分60-70分: 胜率85.7%（高分股胜率极高）
- KDJ J值50-80: 胜率64.3%
- 量比0.8-1.5: 胜率58.9%

### 4. StrategyEvolution — 策略进化系统 (`strategy_evolution.py`)

**职责**: 比较当前版本vs历史版本，分析有效/失效条件，生成优化报告。

**核心功能**:
- `compare_versions(trades_df)`: 按数据集（版本）对比表现
- `analyze_time_periods(trades_df, periods)`: 按时间分段，检测策略是否失效
- `generate_evolution_report()`: 生成进化报告
- `suggest_optimizations()`: 生成优化建议

**当前发现**: 时间趋势declining（首段胜率52.5% → 末段43.1%），需关注策略适应性。

### 5. SellMissLearning — 卖飞学习模块 (`sell_miss_learning.py`)

**职责**: 专门分析卖出后继续上涨股票，寻找提前卖出的原因，生成趋势保护规则建议。

**核心功能**:
- `identify_sell_misses(trades_df, threshold)`: 识别卖飞交易（卖出后N天上涨>threshold%）
- `analyze_sell_misses(sell_miss_df)`: 分析卖飞交易的技术特征
- `generate_trend_protection_suggestions()`: 生成趋势保护建议

**当前发现**（80笔样本）:
- 卖飞率26.2%（21/80）
- 平均卖飞幅度: 5日10.3% / 10日15.3%
- 卖飞时76%价格仍在MA5上方，95%MA5在MA10上方
- **结论**: 固定+8%止盈容易卖飞趋势股，建议改用MA5移动止盈

### 6. LossPrevention — 亏损规避模块 (`loss_prevention.py`)

**职责**: 分析历史亏损交易，自动寻找亏损概率高的组合，生成降低评分建议。

**核心功能**:
- `analyze_loss_patterns(trades_df, factor_data)`: 分析亏损模式（按原因/评分/持仓/因子）
- `_analyze_loss_factors(factor_data)`: 分析亏损交易的因子风险模式
- `generate_loss_prevention_suggestions()`: 生成亏损规避建议

**当前发现**:
- 亏损交易9,726笔（48.8%），平均亏损-3.90%
- 大额亏损（≤-3%）占比31.2%
- KDJ超买时亏损率64.7%（比正常区间高19%）
- 无MACD柱状图正向时亏损率52.4%（比有此条件高11.4%）

### 7. OllamaAIEngine — 本地AI引擎 (`ollama_ai_engine.py`)

**职责**: 接入本地Ollama大模型，分析交易数据、生成AI报告。

**模型**: qwen2.5:7b（本地部署，4.7GB）

**核心功能**:
- `analyze_loss_trades(loss_summary)`: AI分析亏损原因
- `analyze_sell_misses(miss_summary)`: AI分析卖飞原因
- `generate_stock_analysis(stock_data, similar_cases)`: 单只股票AI分析
- `generate_strategy_optimization_report()`: 策略优化AI报告
- `summarize_daily_trades()`: 每日交易总结

**AI原则**: 只做分析和建议，不直接决定买卖。

## 三、数据流

### 历史学习数据流
```
历史交割单CSV → DataHub标准化 → TradeMemory存储(SQLite)
                                    ↓
                    FactorLearningEngine提取K线因子
                                    ↓
                    因子贡献度分析 → 优化建议
                                    ↓
                    StrategyEvolution版本对比
                    SellMissLearning卖飞分析
                    LossPrevention亏损规避
                                    ↓
                    OllamaAIEngine生成AI报告
```

### 实盘决策数据流
```
实时行情 → V7.6生产层扫描 → DataHub获取信号
                                    ↓
                    TradeMemory匹配相似历史案例
                    FactorLearningEngine计算因子
                                    ↓
                    生成：成功概率/风险等级/相似案例/操作建议
                                    ↓
                    进入交易界面（AI只辅助，不自动决策）
```

## 四、设计原则

1. **不重复开发**: 所有选股/评分/回测复用已有模块，AI大脑只做数据聚合和学习
2. **AI不决策**: AI只做分析和建议，买卖决策由人或已有策略模型完成
3. **数据真实**: 所有学习基于真实行情、真实回测、真实交割单，不制造虚假数据
4. **不自动修改**: 因子学习只生成优化建议，不自动修改评分模型，需人工确认
5. **渐进式**: 先建立架构和数据接口，验证有效后再接UI
