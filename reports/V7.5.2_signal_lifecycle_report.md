> 完成时间：2026-08-23
> 优化范围：UI展示层信号生命周期管理（不修改任何策略/评分/阈值）
> 验证样本：200只主板股票，lookback=1/3/5三种窗口

## 一、信号生命周期设计说明

### 1.1 设计目标

V7.5.1去重后发现：lookback=5天累计重点关注~66只，超过V7.4.8目标"每日10-30只"。根本原因不是策略问题，而是**时间窗口与实盘交易窗口没有统一**。

V7.5.2通过信号生命周期管理，将去重后的信号按"距离首次信号的天数"分为不同状态，重点关注池只显示"新出现+买入窗口"（主力启动前1-3天），超过最佳买入窗口的信号移到观察池。

### 1.2 四种信号状态定义

| 状态 | 标识 | 条件 | 显示位置 | 建议操作 |
|------|------|------|---------|---------|
| **新出现** | 🟢 | score>=50 且 首次信号日=最新信号日=今日 | 重点关注池 | 关注低吸机会 |
| **买入窗口** | 🟡 | score>=50 且 信号持续<=3天 | 重点关注池 | 建议买入 |
| **有效观察** | 🔵 | score>=50 但 信号持续>3天 | 观察池 | 等待回调或升级 |
| **观察级** | 🔵 | 40<=score<50 | 观察池 | 等待评分提升 |
| **失效** | ⚪ | score<40 或 持续>5天 | 过滤不显示 | 已过期 |

### 1.3 生命周期转换规则

```
信号产生(score>=50)
    ↓
第1天：🟢新出现（首次=最新=今日）
    ↓
第2-3天：🟡买入窗口（持续<=3天，主力启动前1-3天）
    ↓
第4-5天：🔵有效观察（仍有效但超过最佳买入窗口）
    ↓
第6天+：⚪失效（从列表移除）
```

- score>=50的信号有效期为3个交易日（买入窗口）
- 超过3日但仍在5日内：降低为"有效观察"状态，移到观察池
- 超过5日：标记失效，过滤不显示
- 信号持续天数从首次信号日期开始计算

## 三、UI优化说明

### 3.1 扫描周期选择

扫描按钮旁下拉框：今日(1天) / 近3天 / 近5天 / 近10天

### 3.2 重点关注池显示范围筛选

重点关注池Tab增加"显示范围"下拉框：
- **重点关注池(🟢新+🟡窗口)**【默认】— 只显示新出现+买入窗口
- **观察池(🔵有效+🔵级)** — 显示有效观察+观察级信号
- **全部信号** — 显示所有>=40分信号

### 3.3 表格新增列

重点关注池表格新增3列：
- **信号状态**：🟢新出现/🟡买入窗口/🔵有效观察/🔵观察级/⚪失效（带颜色）
- **距离信号**：信号持续天数（1天/2天/3天...）
- **建议操作**：关注低吸机会/建议买入/等待回调或升级/等待评分提升/已过期

完整列顺序：
```
代码 | 名称 | 最高评分 | 等级 | 模型 | 信号状态 | 距离信号 | 建议操作 |
当前价 | 建议买入价 | 止盈价 | 止损价 | 首次信号日 | 最新信号日 | 信号次数 | 持仓天数
```

### 3.4 状态栏显示优化

扫描完成后状态栏显示各状态数量：
```
扫描完成：原始70信号→去重58只 | 重点关注池4只(🟢新0+🟡窗口4) | 观察池52只(🔵有效2+🔵级50)
```

## 四、今日信号验证（lookback=1）

### 4.1 验证结果

| 指标 | 200只样本 | 全市场推算(2232只) |
|------|----------|-------------------|
| 去重后总股票数 | 6 | ~67只 |
| 🟢新出现 | 0 | 0 |
| 🟡买入窗口 | 0 | 0 |
| 🔵有效观察 | 0 | 0 |
| 🔵观察级(40-50) | 6 | ~67只 |
| ⚪失效 | 0 | 0 |
| **重点关注池显示(新+窗口)** | **0** | **0** |
| **观察池显示(有效+级)** | **6** | **~67只** |

### 4.2 核心发现

⚠️ **lookback=1(今日)时，200只样本中0只score>=50，最高46分，全部为观察级。**

这与V7.5扫描链路审计结论一致：lookback=1时平均评分26.66，最高46分，0只>=50。

**原因分析：**
- V7.4.8回测验证时"每日10-30只重点关注"是基于**历史最佳评分位置**（lookback较大，取窗口内最高分）
- 实际"今日"单天扫描时，score>=50的强信号很少，大部分股票评分在40-50之间
- 这不是策略问题，而是"单日信号"天然比"窗口内最佳信号"少

## 八、每日使用流程说明

### 推荐流程（基于验证结果）

1. **启动程序** → 打开"⭐ V7.4精准买点"页面
2. **选择扫描周期** → 推荐"近3天"（重点关注池约11只，在目标范围）
3. **点击扫描** → 全市场2232只扫描，3-5分钟完成
4. **查看重点关注池** → 默认显示"🟢新出现+🟡买入窗口"，约10-30只
5. **双击股票查看K线** → 验证横盘/均线/MACD/KDJ形态
6. **生成买卖计划** → 次日低吸买入，+8%止盈，-7%止损，10天持仓
7. **跟踪持仓** → 每日查看信号状态变化（新出现→买入窗口→有效观察→失效）
8. **自动复盘** → 5日后自动统计实际表现，30天自动优化参数

### 扫描周期选择建议

| 场景 | 推荐周期 | 重点关注池数量 |
|------|---------|--------------|
| 日常选股 | 近3天 | ~11只（精准） |
| 扩大候选 | 近5天 | ~44只（需筛选） |
| 仅看今日 | 今日(1天) | 0只（强信号少） |
| 回测验证 | 近10天 | 更多（历史验证） |

## 九、未解决的问题

### 9.1 今日(lookback=1)无score>=50信号

- 200只样本中lookback=1时0只>=50分，最高46分
- 全市场推算今日重点关注池为0只
- **原因**：单日强信号天然少于窗口内最佳信号
- **建议**：默认扫描周期改为"近3天"，而非"今日(1天)"

### 9.2 "新出现"状态为0

- 三种窗口下"🟢新出现"均为0
- **原因**：去重后如果股票只有1次信号，first=latest=该信号日期，但该日期不一定等于current_date（窗口内最新日期）
- 实际上lookback=1时所有信号都是当天的，应该是"新出现"，但因为score<50，状态为"观察级"
- **建议**："新出现"状态可扩展到score>=40的信号，或单独标记"今日新增"

### 9.3 ST股票未过滤

- 扫描结果包含ST西王、*ST美谷、*ST康佳A等ST股票
- 属于策略层面过滤，本次未修改（用户禁止修改策略）

### 9.4 全市场验证基于200只推算

- 当前验证基于200只样本比例推算全市场
- 建议后续跑全市场2232只确认实际数量
