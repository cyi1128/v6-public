## 四、AI520历史记忆状态机

### 4.1 状态机图

```
┌─────────────────────────────────────────────────────────────────────┐
│                    AI520历史记忆状态机                                │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ① LOW_KDJ_MEMORY (KDJ低位记忆)                                    │
│     过去5~10日曾出现J<=15，不要求今天J<=15                          │
│     保存: kdj_memory_date / kdj_lowest_j / days_ago               │
│                         ↓                                           │
│  ② LIMIT_UP_MEMORY (20日涨停记忆)                                   │
│     过去20日内曾出现涨停，保存涨停日期/次数                          │
│                         ↓                                           │
│  ③ VOLUME_STARTUP (倍量启动)                                        │
│     V1>=V0×1.8，启动阳线2%~9%，非涨停，非一字板                    │
│     保存: startup_date / startup_price / V0 / V1 / volume_ratio    │
│                         ↓                                           │
│  ④ GENTLE_RISE (温和上涨)                                           │
│     启动后1~10日，累计涨幅-5%~+18%，排除连续暴涨/连续涨停          │
│                         ↓                                           │
│  ⑤ SHRINK_PULLBACK (缩量回踩) ★核心定义                            │
│     当前回踩成交量 < V0（启动基准量），不是简单"比5日均量小"        │
│     保存: current_volume / baseline_v0 / volume_vs_v0              │
│                         ↓                                           │
│  ⑥ MA5_SUPPORT / MA20_SUPPORT (均线支撑)                            │
│     MA5: Low<=MA5×1.015                                            │
│     MA20: Low<=MA20×1.02 且 MA20非明显向下                         │
│                         ↓                                           │
│  ⑦ BOTTOM_FRACTAL_CANDIDATE → CONFIRMED (底分型) ★与MA20分开     │
│     候选: Low[i-1]>Low[i]<Low[i+1]（中间低点）                     │
│     确认: 右侧收盘回升 + 重新站上MA5 + 右侧高点抬高                 │
│                         ↓                                           │
│  ⑧ MA5_RECLAIM (重新站回MA5) ★核心买点确认                         │
│     Close>MA5 且 MA5向上 且 MA20非明显下降                          │
│                         ↓                                           │
│  ⑨ BUY_POINT (买点确认) ★最终信号                                   │
│     MA5_RECLAIM + 当前涨幅0.3%~7% + 有启动历史 + 有回踩历史        │
│                                                                     │
│  异常状态: FAILURE (回踩失败/放量破位) / RISK (高位风险)           │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

| LIMIT_UP_MEMORY | 过去20日内曾涨停 | limit_up_date, limit_up_count_20d | +5 |

| GENTLE_RISE | 启动后累计涨幅-5%~+18%，无连续暴涨 | gentle_rise_days, rise_from_startup | +8 |
| SHRINK_PULLBACK | 当前成交量 < V0（启动基准量） | current_volume, baseline_v0, volume_vs_v0 | +15 |
| MA5_SUPPORT | Low<=MA5×1.015 | - | +10 |
| MA20_SUPPORT | Low<=MA20×1.02 且 MA20非向下 | - | +15 |

### 4.3 硬过滤 vs 评分条件分离

**硬过滤（直接拒绝）**:
- 价格 < 6.00元（6.00允许，5.99禁止）
- ST/*ST股票
- 创业板/科创板/北交所（只允许主板60%/00%）
- 明显风险/严重破位

**核心结构（状态机评分）**:
- KDJ低位记忆、20日涨停记忆、倍量启动、温和上涨、缩量回踩
- MA5/MA20支撑、底分型、重新站MA5、买点确认

**加分项**:
- 板块资金流入、板块涨停、相关新闻、同板块联动、10日新高

**设计原则**: 不把所有条件做成硬过滤导致信号消失，也不放宽到失去AI520逻辑。

## 九、核心设计原则

### 9.1 历史记忆 vs 今天同时满足
- **旧模式**: 今天同时满足十几个条件才出现信号 → 信号稀少或条件冲突
- **新模式**: 过去发生过什么（KDJ低位/涨停/倍量启动）→ 现在走到什么阶段（回踩/底分型/重站MA5）→ 最终买点确认
- 状态链: `LOW_KDJ_MEMORY→VOLUME_STARTUP→GENTLE_RISE→SHRINK_PULLBACK→MA20_SUPPORT→BOTTOM_FRACTAL→MA5_RECLAIM→BUY_POINT`

### 9.2 缩量回踩核心定义
- **错误定义**: 当前成交量 < 5日均量（可能每天都满足，无区分度）
- **正确定义**: 当前回踩成交量 < V0（倍量启动前一天成交量）
- 例如: V0=1000万，启动V1=2000万，回踩量=700万 → 700万<1000万 → 真正缩量回踩

### 9.3 MA20 vs 底分型分开
- **MA20**: 位置概念，价格碰到MA20附近
- **底分型**: 结构概念，Low[i-1]>Low[i]<Low[i+1]，需要右侧确认
- 不能"碰MA20就叫底分型"，必须分开识别、分开保存

### 9.4 硬过滤 vs 评分条件
- **硬过滤**: 价格<6/ST/非主板/严重破位 → 直接拒绝，不进入评分
- **核心结构**: KDJ记忆/倍量启动/缩量回踩/MA支撑/底分型/重站MA5 → 状态机评分
- **加分项**: 板块共振/新闻/10日新高 → 额外加分
- 不把所有条件做成硬过滤导致信号消失
