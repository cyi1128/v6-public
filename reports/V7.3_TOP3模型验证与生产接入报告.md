## 六、通过验证模型详细说明

### TOP1: 多头排列+一阳穿均线+缩量

**买入条件**: 均线多头排列(MA5>MA10>MA20) + 一阳穿均线(开盘<MA5/MA10, 收盘>MA5/MA10) + 缩量(量比<0.7)

**策略逻辑**: 均线多头排列确认趋势向上，一阳穿均线是短期强势启动信号，缩量说明抛压轻、主力控盘度高。三者共振预示主力蓄势完毕，即将启动。

**适用场景**: 适用于趋势明确的中盘股，在缩量调整末期出现一阳穿多线时介入。避免在高位放量后使用。

**风险提示**: 多头排列股票已有一定涨幅，需严格执行-5%止损。一阳穿均线后可能有回踩，持仓5天内不追涨。

**卖出条件**: 止盈+8%% / 止损-5%% / 持仓5天

**Walk Forward验证**:
- 训练期胜率: 57.3% (3个窗口均值)
- 测试期胜率: 52.8% (3个窗口均值)
- 测试期均收益: +0.99%
- 测试期盈亏比: 1.30
- 稳定性: 100% (3/3窗口稳定)
- 测试期总信号: 366个

### TOP3: KDJ(13)J低位+MACD红柱扩大+MACD绿柱缩小

**买入条件**: KDJ(13,3,3) J值低位(-40~20) + MACD(12,26,9)红柱扩大 + MACD(8,21,5)绿柱缩小

**策略逻辑**: KDJ低位确认股价处于相对低位，快慢两个MACD同时出现修复信号（慢周期红柱扩大+快周期绿柱缩小），形成双指标共振。这是底部修复的典型信号。

**适用场景**: 适用于经过调整的股票，在KDJ低位区域出现双MACD修复时介入。对横盘筑底后的启动特别有效。

**风险提示**: 双MACD修复可能失败（绿柱重新扩大），需严格止损。KDJ低位可能持续钝化，建议结合成交量确认。

**卖出条件**: 止盈+8%% / 止损-5%% / 持仓5天

**Walk Forward验证**:
- 训练期胜率: 59.3% (3个窗口均值)
- 测试期胜率: 52.4% (3个窗口均值)
- 测试期均收益: +0.81%
- 测试期盈亏比: 1.51
- 稳定性: 67% (2/3窗口稳定)
- 测试期总信号: 398个

## 七、使用说明

### 命令行扫描

```bash
# 全市场扫描（最近1天）
python scan_v73_top.py

# 回看5天，指定输出文件
python scan_v73_top.py --lookback 5 --output reports/my_scan.csv

# 只扫描TOP1模型，限制200只股票（测试用）
python scan_v73_top.py --model TOP1 --limit 200
```

### Python接口调用

```python
from strategies.v73_top_models import V73TopModels
scanner = V73TopModels()

# 单只扫描
signals = scanner.scan_stock("000001", lookback=5)

# 全市场扫描
all_signals = scanner.scan_market(lookback=1)

# 查看模型信息
models = scanner.list_models()
```

### 信号解读

- **综合评分**: 基于测试期胜率(40%)+盈亏比(30%)+稳定性(20%)+收益(10%)计算
- **历史胜率**: Walk Forward测试期胜率，非训练期，避免过拟合
- **止盈/止损价**: 基于当前价格自动计算，+8%止盈/-5%止损
- **建议持仓**: 5个交易日，到期未触发止盈止损则平仓

## 八、下一步优化建议

1. **TOP2模型优化**: TOP2盈亏比1.13接近阈值，可尝试加入成交量过滤（如要求缩量）提高盈亏比
2. **卖出策略增强**: 当前固定+8%/-5%，可测试动态止盈（如跟踪止损MA5）提高盈亏比
3. **市场环境过滤**: 加入大盘MA20趋势过滤，弱市空仓或提高阈值
4. **行业轮动**: 统计各模型在不同行业的表现差异，优先扫描强势行业
5. **模型组合**: 测试TOP1+TOP3交集信号（同时满足两个模型），可能进一步提高胜率
6. **实盘模拟**: 用最近60日做模拟盘，验证实盘滑点和流动性影响
7. **参数寻优**: 对TOP1/TOP3的KDJ/MACD参数进行网格搜索，寻找更优参数组合
8. **UI集成**: 在选股复盘菜单下增加"V7.3最优模型扫描"页面，复用现有股票列表组件
