## 七、已发现问题和修复记录

### 7.1 V8.1紧急修复：筛选不到股票（已修复）

**问题**：全市场扫描2726信号，但重点关注池显示0只

**根本原因**：`determine_signal_status`函数第184行只检查`enhanced_score`字段，但V7.6生产层返回的信号使用`final_score`字段。当`enhanced_score`不存在时，score=0，所有信号被判定为`expired`（失效），导致重点关注池过滤后为空。

**修复内容**：
1. `determine_signal_status`：`signal.get('enhanced_score', 0)` → `signal.get('final_score', signal.get('enhanced_score', 0))`
2. `calculate_signal_lifecycle`：同样修复`current_score`字段名
3. `_on_scan_finished`：增加调试打印，显示数据链路各阶段数量和状态分布
4. `deduplicate_signals`：已增加非字典元素过滤和类型检查（V8.0崩溃修复）

**验证结果**：模拟V7.6信号（只有final_score）经过去重+生命周期后，score>=50的信号正确显示为`buy_window`状态，重点关注池有数据显示。

### 7.2 已知遗留问题

| 问题 | 严重度 | 说明 |
|------|--------|------|
| 上证指数代码不准确 | 🟡 中等 | `TdxDataEngine.get_kline('000001')`获取到的是平安银行(sz000001)，不是真正的上证指数。当前显示的是真实K线数据（非Mock），但指数标的需修正为`sh000001`或`999999` |
| trade_factors表为空 | 🟡 中等 | AI因子学习结果尚未持久化到数据库，学习结果可能只在内存中 |
| 板块数据接口不统一 | 🟡 中等 | 强势/弱势板块TOP3暂无统一接口，AI交易大脑显示"暂无数据" |
| 全市场2232只最终验证未执行 | 🟢 轻微 | V8.0回测仅600只抽样，用户原始要求全市场2232只验证 |

## 九、缺失的能力

1. **实盘交易对接**：当前只有模拟回测，无券商API对接实盘下单
2. **实时行情推送**：TdxDataEngine读取本地.day文件，非实时推送，需要手动更新通达信数据
3. **板块指数数据**：缺少统一的板块/行业指数历史数据接口，板块强度排名计算受限
4. **资金流向数据**：主力资金、大单净量等资金数据缺失
5. **基本面数据**：PE/PB/ROE等基本面数据缺失
6. **AI学习结果持久化**：trade_factors、learning_results表为空，学习结果未持久化
