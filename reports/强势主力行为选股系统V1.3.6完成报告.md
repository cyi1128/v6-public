# 强势主力行为选股系统 V1.3.6 完成报告

## 优化L2预筛条件（太松导致L3处理2125只太慢）

---

## 一、问题

当前L2预筛条件太松，2131只股票只过滤6只，通过2125只。导致L3深度分析要处理2125只（三模型+AI评分），需要15-30分钟，太慢。

当前L2条件统计（抽样200只）：
- 涨幅>10%: 179只
- 量能变化: 125只
- 大阳线: 111只
- 横盘整理: 69只
- 突破迹象: 41只

OR逻辑下几乎所有股票都满足至少1个条件。

---

## 二、优化方案

### 优化目标
L2通过数量控制在 **300-600只**（从2125降到300-600），L3深度分析3-5分钟完成。

### 新的5个条件（更严格）

#### 条件1：近期涨幅（原：近30日涨幅>10%，179只通过）
**改为**：近10日涨幅>8% 或 近20日涨幅>15%
- 缩短时间窗口，提高涨幅阈值
- 预计通过：80-120只

#### 条件2：量能变化（原：只要有变化就算，125只通过）
**改为**：缩量（近5日均量 < 前20日均量×0.7）或 放量（近5日均量 > 前20日均量×1.5）
- 明确缩量/放量阈值，不是只要有变化
- 预计通过：100-150只

#### 条件3：大阳线（原：可能阈值太低，111只通过）
**改为**：近10日内有涨幅>7%的阳线（close>open 且 涨幅>7%）
- 缩短时间窗口，提高涨幅阈值，要求必须是阳线
- 预计通过：80-120只

#### 条件4：横盘整理（原：可能阈值太松，69只通过）
**改为**：近20日振幅<12% 且 近20日收盘价标准差/均值<4%
- 提高横盘判定标准，增加变异系数(CV)约束
- 预计通过：50-80只

#### 条件5：突破迹象（原：可能阈值太低，41只通过）
**改为**：收盘价>近20日最高价×0.98 且 当日成交量>5日均量×1.2
- 增加成交量放大确认
- 预计通过：30-60只

#### OR逻辑保持不变
满足任意1个条件即通过L2。预计总通过：300-600只。

## 三、代码修改

### 1. 重写 `_layer2_check_conditions` 方法

使用新的更严格条件，返回详细的条件字典：
```python
{
    'rise_10d': bool, 'rise_20d': bool,
    'shrink': bool, 'expand': bool,
    'big_yang': bool, 'sideways': bool, 'breakout': bool,
    'rise': bool, 'volume': bool, 'passed': bool
}
```

关键实现：
- 条件1：`closes[last_idx] - closes[last_idx-10]` 计算10日涨幅，`>8%`通过；20日涨幅`>15%`通过
- 条件2：`recent_5_vol / prev_20_vol` 计算量比，`<0.7`缩量或`>1.5`放量通过
- 条件3：遍历近10日，`closes[i] > opens[i]` 且 `(closes[i]-opens[i])/opens[i]*100 > 7` 通过
- 条件4：20日振幅`<12%` 且 收盘价变异系数`CV<4%` 通过
- 条件5：`closes[last_idx] > 20日最高价×0.98` 且 `volumes[last_idx] > 5日均量×1.2` 通过

### 2. 重写 `_layer2_behavior_prescreen` 方法

简化为直接调用 `_layer2_check_conditions` 并返回 `cond['passed']`，避免代码重复。

### 3. L2统计从抽样改为全部统计

原代码抽样最多200只统计条件通过数，改为对全部 `layer1_passed` 股票统计，并打印完整的细粒度条件统计：
```
[L2] 条件统计(全部2131只):
[L2]   近10日涨幅>8%: XX只
[L2]   近20日涨幅>15%: XX只
[L2]   缩量(5日<20日×0.7): XX只
[L2]   放量(5日>20日×1.5): XX只
[L2]   近10日大阳线>7%: XX只
[L2]   横盘(20日振幅<12%+CV<4%): XX只
[L2]   突破(收盘>20日高×0.98+放量): XX只
[L2]   OR逻辑总通过: XXX只
```

### 4. FunnelStats增加L2细粒度字段

新增4个字段：
- `l2_cond_rise_10d`：近10日涨幅>8%通过数
- `l2_cond_rise_20d`：近20日涨幅>15%通过数
- `l2_cond_shrink`：缩量通过数
- `l2_cond_expand`：放量通过数

### 5. 更新 `_print_funnel_summary` 中的L2统计打印

使用新的细粒度字段打印完整条件统计。

## 七、用户操作建议

1. **重新运行扫描**：观察L2通过数量是否降到300-600只
2. **查看L2条件统计**：确认每个条件的通过数是否合理
3. **如果L2通过仍然>600只**：可以进一步提高阈值（如涨幅>10%、缩量<0.6、大阳线>8%）
4. **如果L2通过<300只**：可以适当放宽阈值（如涨幅>6%、缩量<0.8、大阳线>6%）
5. **观察总扫描时间**：应该从20-35分钟降到<6分钟
6. **最终股票池**：应该有50-300只真实股票，评分分布合理
