# V7.5.5 T+1交易Bug修复报告

**修复日期**：2026-08-23
**修复范围**：交易模拟逻辑中的T+0 bug（A股必须T+1，买入当天不能卖出）
**策略修改**：无（仅修复交易模拟中的卖出检查时机）

---

## 一、T+0问题描述

用户在历史交割单中发现2笔T+0交易（持仓天数=0，买入日=卖出日）：

| 交易编号 | 股票 | 信号日 | 买入日 | 卖出日 | 持仓天数 | 卖出原因 | 收益率 |
|---------|------|--------|--------|--------|---------|---------|--------|
| 165 | 万科A(000002) | 20240521 | 20240522 | 20240522 | 0天 | 止盈+8% | +8.00% |
| 178 | 四环生物(000518) | 20240731 | 20240801 | 20240801 | 0天 | 止盈+8% | +8.00% |

**问题本质**：交易模拟逻辑中，止盈/止损检查在买入当天就执行了，导致买入当天就卖出。A股是T+1制度，当天买入的股票当天不能卖出，必须从买入次日（T+1）开始才能卖出。

---

## 二、根本原因分析

### 错误逻辑（修复前）

```python
# 遍历当前日期的所有持仓
for trade_id, pos in open_positions.items():
    hold_days = idx - date_idx_map[buy_date]  # 买入当天hold_days=0
    
    # 直接检查止盈止损（没有判断hold_days>=1）
    if high >= buy_price * 1.08:      # ← 买入当天就检查，导致T+0
        process_sell(...)
    elif low <= buy_price * 0.93:      # ← 买入当天就检查，导致T+0
        process_sell(...)
    elif hold_days >= 10:
        process_sell(...)
```

### 正确逻辑（修复后）

```python
# T+1规则：买入当天(hold_days==0)不能卖出，从买入次日(hold_days>=1)开始检查
if hold_days >= 1:
    if high >= buy_price * 1.08:
        process_sell(...)
    elif low <= buy_price * 0.93:
        process_sell(...)
    elif hold_days >= 10:
        process_sell(...)
# 买入当天只记录持仓过程，不检查止盈止损，不卖出
```

- `strategies/v73_top_models.py`：仅模型信号生成，不涉及交易模拟，无T+0问题

### 修复规则

1. 买入日当天（hold_days=0）：只记录持仓过程，不检查止盈止损，不卖出
2. 从买入日的下一个交易日（T+1，hold_days>=1）开始：检查止盈止损
3. 如果T+1日最高价达到+8%，止盈卖出（卖出价=买入价×1.08）
4. 如果T+1日最低价达到-7%，止损卖出（卖出价=买入价×0.93）
5. 持仓天数 = 卖出日 - 买入日（至少1天，不能为0）
6. 最长持仓到买入日后第10个交易日（T+10），未触发则T+10收盘卖出
