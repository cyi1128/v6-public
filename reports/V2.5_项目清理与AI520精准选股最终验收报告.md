## 五、6元以下股票BUG修复

### 5.1 根因分析
**6元以下股票为什么之前能够进入作战中控台？**

作战中控台的股票列表数据来源是 `ui.real_scan_service.py` 的 `get_main_board_stocks()` 方法。该方法：
1. 调用 `get_full_market_quotes(main_board_only=True, exclude_st=True)` 获取全市场股票
2. 只排除了：非主板（60/000/001开头）、ST/*ST、价格=0
3. **没有排除价格<6元的股票！**

而AI520扫描服务（`strategy.ai_520_scan_service.py`）虽然有价格<6过滤，但作战中控台显示的是real_scan_service的扫描结果，不是AI520扫描结果。因此6元以下股票出现在作战中控台。

### 5.2 修复方案：三层硬过滤

**第一层：数据源过滤（real_scan_service.py）**
- 文件：`ui/real_scan_service.py` 第98-105行
- 修改：在`get_main_board_stocks()`中，排除价格=0之后，添加价格<6过滤
- 代码：
```python
# V2.5全局硬过滤：价格<6.00元直接拒绝（6.00允许，5.99禁止）
if price < 6.00:
    print(f"[REAL_SCAN_FILTER] REJECT PRICE_BELOW_6 code={code} price={price:.2f}", flush=True)
    continue
```

**第二层：AI520扫描过滤（ai_520_scan_service.py）**
- 文件：`strategy/ai_520_scan_service.py` 第328-332行
- 已有：价格<6过滤，日志`[AI520_FILTER] REJECT PRICE_BELOW_6`

**第三层：UI显示防御过滤（battle_console_v2.py）**
- 文件：`ui/battle_console_v2.py` 第399-404行
- 修改：在`_refresh_stock_list()`显示前，添加价格<6防御过滤
- 代码：
```python
# V2.5第三层UI防御性过滤：价格<6.00元绝不显示
before_price_filter = len(filtered)
filtered = [s for s in filtered if s.get('price', 0) >= 6.00 or s.get('price', 0) <= 0]
if before_price_filter != len(filtered):
    print(f"[UI_FILTER] 价格<6防御过滤: {before_price_filter}->{len(filtered)}", flush=True)
```

### 5.3 修复后6元过滤结果

```
LOW_KDJ_MEMORY (KDJ低位记忆，过去5~10日J<=15)
    ↓
LIMIT_UP_MEMORY (20日涨停记忆)
    ↓
VOLUME_STARTUP (倍量启动，V1>=V0×1.8)
    ↓
GENTLE_RISE (温和上涨，启动后-5%~+18%)
    ↓
SHRINK_PULLBACK (缩量回踩，当前量<V0) ★核心定义
    ↓
MA5_SUPPORT / MA20_SUPPORT (均线支撑)
    ↓
BOTTOM_FRACTAL_CANDIDATE → CONFIRMED (底分型，与MA20分开)
    ↓
MA5_RECLAIM (重新站回MA5)
    ↓
BUY_POINT (买点确认)
```
