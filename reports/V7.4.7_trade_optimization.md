**优化1：取消观察级交易**
- 原允许：S/A/B/重点关注(≥50)/观察(40-50)
- 优化后：仅允许S/A/B/重点关注(≥50)

**优化2：移动止盈测试（4种方案）**

## 三、各方案详细分析

### 3.1 方案A：保本止损

**规则**：浮盈≥5%时止损移到买入价（保本），继续持有到+8%止盈。

| 指标 | 数值 |
|------|------|
| 交易数 | 712笔 |
| 胜率 | 49.3% |
| 盈亏比 | 1.47 |
| 移动止盈触发 | 277笔（38.9%） |
| 触发后胜率 | 82.3% |
| 触发后均收益 | +6.15% |

**分析**：
- 保本止损触发后效果很好（胜率82.3%），但触发率仅38.9%
- 未触发的61.1%交易中，很多直接止损-7%，拉低整体胜率到49.3%
- 平均亏损-4.04%是4种方案中最小的（因为保本止损减少了亏损幅度）
- 盈亏比1.47接近1.5，但胜率太低

**结论**：保本止损降低了亏损幅度，但也降低了胜率（很多股票在+5%之前就被止损）。不推荐作为主方案。

### 3.2 方案B：锁定3%利润

**规则**：浮盈≥8%时不止盈，止损移到+3%（锁定利润），继续持有。

| 指标 | 数值 |
|------|------|
| 交易数 | 658笔 |
| 胜率 | 55.9% |
| 盈亏比 | 1.02 |
| 最大回撤 | -11.27%（超标） |
| 移动止盈触发 | 238笔（36.2%） |
| 触发后胜率 | 100% |
| 触发后均收益 | +6.27% |
| 最大单笔盈利 | +103.39% |

**分析**：
- 胜率55.9%达标，但盈亏比仅1.02（几乎不赚钱）
- 最大回撤-11.27%超标（>10%）
- 锁定3%利润后，很多股票从+8%回落到+3%被卖出，平均盈利被压缩到4.96%
- 虽然有1笔+103%的大盈利（涨了1倍），但无法弥补大量+3%的小盈利
- 触发后胜率100%（因为止损在+3%，不可能亏损），但这是"虚假胜率"

**结论**：锁定3%利润是最差方案，盈亏比1.02意味着几乎白干。不推荐。

### 3.3 方案C：MA5保护止盈

**规则**：浮盈≥10%时改用MA5动态止盈，收盘价跌破MA5时卖出。

| 指标 | 数值 |
|------|------|
| 交易数 | 601笔 |
| 胜率 | 51.7% |
| 盈亏比 | **1.54** ✅ |
| 平均盈利 | **+7.11%**（最高） |
| 最大回撤 | -7.14% |
| 连续亏损 | **8次**（最少） |
| 年化收益 | 14.7% |
| 移动止盈触发 | 170笔（28.3%） |
| 触发后胜率 | 90.0% |
| 触发后均收益 | **+9.85%**（最高） |
| 最大单笔盈利 | +103.39% |

**卖出原因分布**：
| 卖出原因 | 笔数 | 占比 |
|---------|------|------|
| 第10天收盘 | 333 | 55.4% |
| 止损-7% | 135 | 22.5% |
| MA5跌破卖出 | 133 | 22.1% |

**按等级统计**：
| 等级 | 交易数 | 胜率 | 平均收益 | 盈亏比 |
|------|--------|------|---------|--------|
| A级 | 17笔 | 41.2% | -0.82% | 1.02 |
| 重点关注 | 584笔 | 52.1% | +1.52% | 1.56 |

**分析**：
- **盈亏比1.54是4种方案中唯一达标（≥1.5）的**
- MA5保护让盈利奔跑，平均盈利+7.11%最高，触发后均收益+9.85%
- 连续亏损8次最少，风险控制好
- 但胜率51.7%未达55%，主要因为MA5跌破卖出有时会卖在回调低点
- A级在MA5保护下表现差（胜率41.2%），因为A级股票波动大，MA5容易被跌破
- 重点关注在MA5保护下表现好（盈亏比1.56）

**结论**：MA5保护在盈亏比和风险控制上表现最优，但胜率略低。适合作为重点关注级的增强方案。

### 3.4 方案D：对照组（原方案+过滤观察级）

**规则**：+8%止盈，-7%止损，第10天收盘卖出。

| 指标 | 数值 |
|------|------|
| 交易数 | 704笔 |
| 胜率 | **56.0%** ✅ |
| 盈亏比 | 1.25 |
| 平均盈利 | +6.04% |
| 最大回撤 | **-5.79%**（最低）✅ |
| 连续亏损 | 10次 |
| 年化收益 | **15.7%**（最高）✅ |
| 最大单笔盈利 | +8.00% |

**卖出原因分布**：
| 卖出原因 | 笔数 | 占比 |
|---------|------|------|
| 第10天收盘 | 292 | 41.5% |
| 止盈+8% | 253 | 35.9% |
| 止损-7% | 159 | 22.6% |

**按等级统计**：
| 等级 | 交易数 | 胜率 | 平均收益 | 盈亏比 |
|------|--------|------|---------|--------|
| A级 | 17笔 | **64.7%** | +3.32% | **1.52** |
| 重点关注 | 687笔 | 55.7% | +1.20% | 1.24 |

**分析**：
- **胜率56.0%是4种方案中最高的**，达标
- **年化15.7%最高**，回撤-5.79%最低，风险收益比最优
- 止盈:止损 = 253:159 = 1.59:1，止盈比止损多94笔，这是盈利的核心来源
- A级表现优异（胜率64.7%，盈亏比1.52），固定止盈适合A级股票
- 重点关注胜率55.7%，但盈亏比1.24偏低
- 盈亏比1.25未达1.5，主要因为+8%止盈截断了大盈利（最大盈利仅8%）

**结论**：对照组（+过滤观察级）综合表现最好，胜率、年化、回撤三项最优。盈亏比1.25虽未达1.5，但胜率56%已弥补，整体期望收益为正（56%×6.04% - 44%×4.84% = +1.27%/笔）。

## 四、过滤观察级效果验证

### 4.1 V7.4.6 vs V7.4.7方案D对比

| 指标 | V7.4.6（含观察级） | V7.4.7 D（只≥50分） | 变化 |
|------|-------------------|---------------------|------|
| 交易数 | 706笔 | 704笔 | -2笔（几乎不变） |
| **胜率** | 52.4% | **56.0%** | **+3.6pp** ✅ |
| 盈亏比 | 1.31 | 1.25 | -0.06 |
| **最大回撤** | -6.70% | **-5.79%** | **减少0.91pp** ✅ |
| **连续亏损** | 14次 | **10次** | **减少4次** ✅ |
| **年化收益** | 12.0% | **15.7%** | **+3.7pp** ✅ |

### 4.2 分析

**过滤观察级效果非常显著**：
1. **胜率提升3.6pp**：从52.4%到56.0%，直接达标
2. **连续亏损减少4次**：从14次到10次，刚好达标

4. **回撤减少0.91pp**：从-6.70%到-5.79%，更安全
5. **交易数几乎不变**：706→704，因为观察级信号虽然多，但很多因为仓位限制没执行

**核心原因**：观察级（40-50分）胜率仅48.7%，低于50%，是纯拖累。过滤后整体质量提升。

## 五、移动止盈触发效果分析

### 5.1 各方案触发统计

| 方案 | 触发率 | 触发后胜率 | 触发后均收益 |
|------|--------|-----------|-------------|
| A 保本止损 | 38.9%（277/712） | 82.3% | +6.15% |
| B 锁定3% | 36.2%（238/658） | 100.0% | +6.27% |
| C MA5保护 | 28.3%（170/601） | 90.0% | +9.85% |
| D 对照 | 0% | — | — |

### 5.2 分析

1. **移动止盈触发后效果都很好**：胜率82%-100%，均收益6%-10%
2. **但触发率不高**：28%-39%，意味着60%+的交易没有触发移动止盈
3. **方案C触发后均收益最高（+9.85%）**：MA5保护让盈利奔跑，效果最好
4. **方案B触发后胜率100%是虚假的**：因为止损在+3%，不可能亏损，但平均盈利仅6.27%

**关键问题**：移动止盈只对28%-39%的交易有效，剩下60%+的交易该亏还是亏。因此移动止盈无法大幅提升整体胜率，只能提升盈亏比（方案C）或降低亏损（方案A）。

## 六、最佳方案推荐

### 6.1 推荐方案：D（对照+过滤观察级）作为主方案

**推荐理由**：
1. **胜率56.0%达标**：4种方案中最高
2. **年化15.7%最高**：进入15%-25%目标区间
3. **回撤-5.79%最低**：风险控制最好
4. **连亏10次刚好达标**：比V7.4.6的14次大幅改善
5. **逻辑简单清晰**：+8%止盈/-7%止损/10天持仓，实盘容易执行
6. **A级表现优异**：胜率64.7%，盈亏比1.52

**唯一不足**：盈亏比1.25未达1.5（差0.25）。但考虑到胜率56%已不低，整体期望收益为正（+1.27%/笔），704笔累计年化15.7%，是可以接受的。

### 6.2 增强方案：C（MA5保护）用于重点关注级

**适用场景**：
- 重点关注级（≥50分）在MA5保护下盈亏比1.56达标
- 适合愿意接受略低胜率（52%）换取更高盈亏比（1.54）的交易者
- 适合趋势行情，MA5保护能捕获大盈利（最大+103%）

### 6.3 不推荐方案

- **方案A（保本止损）**：胜率49.3%太低，保本止损触发率仅38.9%
- **方案B（锁定3%）**：盈亏比1.02几乎白干，回撤-11.27%超标

## 九、存在问题与下一步建议

### 9.1 存在问题

1. **盈亏比1.25未达1.5**：+8%止盈截断了大盈利，最大盈利仅8%。如果能让部分盈利奔跑，盈亏比可提升。
2. **连续亏损10次刚好等于目标**：没有安全边际，实盘中可能超过10次。
3. **第10天到期卖出占比41.5%**：292笔到期卖出平均收益接近0，是"不赚不亏"的交易，资金效率低。
4. **A级样本太少**：仅17笔，虽然表现好但不具统计意义。
5. **S级0笔**：TOP1+TOP3共振条件太严格，3年未出现。
6. **移动止盈触发率低**：28%-39%，大部分交易无法受益于移动止盈。

### 9.2 下一步优化建议

**优先级高（建议V7.5 UI中实现）：**

1. **分级止盈**：+5%卖50%仓位，剩余50%用MA5保护或继续持有到+10%。

## 十一、总结

### 11.1 核心结论

V7.4.7交易执行优化第二轮完成，**过滤观察级+4种移动止盈测试**。

**最重要的发现：过滤观察级效果显著**
- 胜率从52.4%提升到56.0%（+3.6pp）✅ 达标
- 连续亏损从14次降到10次（-4次）✅ 达标

- 回撤从-6.70%降到-5.79%（-0.91pp）✅ 更安全

**移动止盈测试结论**
- 方案C（MA5保护）盈亏比1.54唯一达标，但胜率51.7%未达标
- 方案D（对照）胜率56.0%最高，年化15.7%最高，回撤最低，但盈亏比1.25未达标
- 方案A（保本止损）和方案B（锁定3%）各有明显缺陷，不推荐
- 移动止盈触发率仅28%-39%，无法大幅提升整体表现

### 11.2 推荐方案

**主方案：D（对照+过滤观察级）**
- 胜率56.0% ✅、年化15.7% ✅、回撤-5.79% ✅、连亏10次 ⚠️
- 盈亏比1.25（差0.25），但整体期望收益为正
- 逻辑简单，实盘易执行

**增强方案：C（MA5保护）**
- 盈亏比1.54 ✅、连亏8次 ✅、回撤-7.14% ✅
- 胜率51.7%（差3.3pp），适合趋势行情
