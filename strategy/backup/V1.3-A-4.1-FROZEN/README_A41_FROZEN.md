## 本版本新增功能

### 1. 涨停强度模块（Step 1）
- 连板高度
- 首次封板时间
- 最后封板时间
- 封单金额
- 炸板次数
- 封板质量星级（★★★★★）

### 2. 封单强度比例（Step 1.1）
- 计算公式：封单金额 / 流通市值 × 100%
- 解决单看封单金额误判问题
- 颜色高亮：≥1%红色，≥0.3%金色

### 3. AI短线总结卡（Step 2）
- 规则推理生成，不接入大模型
- 四维度星级：上涨逻辑/热点强度/资金认可/风险等级
- 综合文字总结 + 定位标签
- 免责声明

### 4. 涨停池排序（Step 3）
- 5种排序方式：综合强度/连板高度/封板时间/封单强度/炸板次数
- 轻量级 quick_rank_score（只用涨停池数据，性能优先）
- 完整 rank_score（涨停强度40+热点30+逻辑20-风险10，满分100）
- 列表项显示强度分+标签，颜色分级

## 排序评分模型

### 完整 rank_score（满分100）
| 维度 | 权重 | 评分依据 |
|------|------|----------|
| 涨停强度 | 40分 | 连板高度(20) + 封板时间(10) + 炸板次数(5) + 封单强度(5) |
| 热点强度 | 30分 | hot_score映射(20) + 热点关联H1/H2/H3(10) |
| 逻辑完整度 | 20分 | 主营S/A/B/C(10) + 公告L1/L2(5) + 新闻催化(5) |
| 风险扣分 | -10分 | 炸板>5次(-3) + 主营C(-3) + 无热点(-2) + 无催化(-2) |

### 轻量级 quick_rank_score（列表排序用，满分100）
| 维度 | 权重 |
|------|------|
| 连板高度 | 40分 |
| 封板时间 | 20分 |
| 炸板次数 | 20分 |
| 封单强度 | 20分 |

### 强度标签
- ≥85分：强势涨停（红色）
- ≥70分：热点强势（橙色）
- ≥55分：普通涨停
- <55分：逻辑待确认

## AI总结规则模型

### 四维度星级
| 维度 | 评分依据 |
|------|----------|
| 上涨逻辑 | 主营等级 + 热点关联 + 公告 |
| 热点强度 | hot_score（0-12映射到5星） |
| 资金认可 | 连板数 + 炸板次数 + 封板时间 |
| 风险等级 | 主营 + 炸板 + 连板高度（越高风险越大） |

### 定位标签
- 板块龙头：连板≥3 + 主营S/A
- 热点强势股：连板≥2 + 热点≥7
- 热点中军：主营S/A + 热点>0
- 连板股：连板≥2
- 热点跟风股：热点>0 + 主营C
- 独立涨停：其他
