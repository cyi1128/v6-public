## 本次优化目标

解决 V1.3-A-3.1 版本中热点判断依赖东方财富概念板块接口、接口失败导致大量股票C级的问题。

---

## 核心改进

### 1. 热点检测链路重构

**优化前**:
```
东方财富概念接口 → 接口失败 → hot=0 → 大量股票C级
```

**优化后**:
```
涨停池统计(P0) → 概念-行业映射 → 热点评分 → P1概念行情备用 → 无数据安全降级
```

### 2. 新增模块

- `strategy/market_hot_detector.py`（新建）
  - P0：基于涨停池行业板块统计（真实资金流）
  - P1：基于概念板块行情（降级备用）
  - 概念-行业映射表（100+映射关系）
  - 三级匹配：精确匹配 → 概念-行业映射 → 模糊匹配

### 3. 新增输出字段（5个）

| 字段 | 类型 | 说明 |
|------|------|------|
| `hot_score` | int | 热点评分 0-12 |
| `hot_source` | str | "涨停池统计" / "概念板块行情" |
| `hot_confidence` | str | high / medium / low |
| `hot_reason` | str | 热点原因描述 |
| `hot_relation_level` | str | H1 / H2 / H3 |

### 4. 最小侵入集成

- 通过覆盖 `theme_result['is_hot_topic']` 实现下游无感切换
- `_calc_confidence()` 评分公式完全未修改
- A-1/A-2/主营/公告/原因描述全部冻结

## 评分逻辑说明

### A级（主线龙头 + 真实业务 + 催化）
- 条件：主营≥A 且 (一级公告 或 热点+新闻 或 热点+连板≥3)
- 示例：奥瑞德（主营S + 一级公告重组 + 热点）

### B级（有逻辑支撑，可重点观察）
- 条件：主营有支撑 + 热点/新闻/连板等催化
- 示例：美利云（主营S + 热点 + 产业匹配）

### C级（有涨停表现，但逻辑证据不足）
- 条件：主营弱 + 无有效催化
- 示例：通信跟风股（涨停 + 板块热，但主营C无催化）
