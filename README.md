# 量化盯盘 V6.0 Pro 主升龙头全自动系统 + 机构级AI量化看盘系统

A股短线盯盘量化辅助软件，基于Python + PyQt6 + SQLite + Pandas + pytdx开发。

## V6.0 Pro 新增功能

### 0. UI全面升级 + 实时数据字段
- **专业量化交易终端风格**：深色主题、高对比度、GitHub Dark配色
- **换手率**：每只股票准确显示实时换手率（腾讯财经API）
- **总市值/流通市值**：准确显示个股市值（亿元）
- **主营业务**：显示个股主营业务和所属行业
- **PE/PB**：市盈率、市净率实时显示
- **股票池表格12列**：序号、代码、名称、现价、涨跌幅、成交量、换手率、总市值、主营行业、涨停次数、信号标签、更新时间

### 1. 7×24小时财经快讯（同花顺风格）
- **顶部滚动条**：固定在Tab上方，8秒自动切换下一条快讯
- **完整快讯面板**：独立Tab，显示所有快讯列表
- **多数据源**：新浪财经（主）+ 东方财富 + 财联社
- **自动刷新**：60秒自动更新最新快讯
- **重要性标记**：🔴重大、🟠重要新闻高亮
- **点击跳转**：点击快讯打开原始链接
- **状态栏提醒**：重要新闻在状态栏弹出提醒

### 2. 缠论交易模块
- 缠论一买：下跌趋势末期、股价创新低、MACD底背驰、底分型
- 缠论二买：下跌趋势中、MACD零轴下金叉、回踩不创新低
- 缠论三买：上涨趋势、MACD零轴上金叉、突破前高、放量确认

### 2. 三倍量回踩突破策略（重点）
- 识别三倍量启动K线：成交量≥20日均量×3、阳线、涨幅≥3%、换手率5%-20%优先
- 三倍量回踩确认：回踩生命线、不跌破启动低点、缩量调整
- 三倍量二次启动买点（五星信号）：突破生命线+MA5向上+MACD零轴上+放量确认+KDJ金叉优先
- 横盘突破检测：调整5-20天、振幅≤15%、MA5/MA10走平、突破放量

### 3. AI综合评分系统（100分 - 4×25分新体系）
| 维度 | 分值 | 说明 |
|------|------|------|
| 趋势 | 25分 | MA5>MA10>MA20 +10、站上20日线 +10、120日线向上 +5 |
| 量能 | 25分 | 三倍量阳线 +15、缩量回踩 +5、突破放量 +5 |
| 技术 | 25分 | MACD金叉 +10、KDJ(13,3,3)金叉 +10、RSI强势 +5 |
| 资金 | 25分 | 换手率合理 +10、资金流入 +10、板块强 +5 |

- 评级：90-100强烈关注、80-90重点观察、70-80等待确认、70以下过滤
- 阶段判断：观察/回踩/突破/买入/风险

### 4. 集合竞价AI分析模块

1. 当前价格 > 近8个月最高价 × 70%
2. 当前价格 < 近8个月最高价 × 105%
3. 前一天没有涨停
4. 一年内涨停次数 ≥ 3次
5. 主板股票（排除创业板300/301、科创板688）
6. 排除ST
7. 排除行业：地产、农业、酒、保险
8. 总市值：大于30亿，小于等于230亿
9. 剔除：股价超过60元、股价低于5元
10. 当前价格距离近8个月最高价涨幅 < 15%

## 配置说明

### 切换行情数据源
编辑 `config/settings.py`：
```python
MARKET_API = {
    'provider': 'mock',  # mock / tushare / broker
    'tushare_token': '你的token',
}
```

- `mock`: 模拟数据（默认，用于测试和演示）
- `tushare`: Tushare Pro API（需配置token）
- `broker`: 券商行情接口（需自行实现）

### 调整选股参数
编辑 `config/settings.py` 中的 `FILTER_CONFIG`、`SCORING_CONFIG`、`SIGNAL_CONFIG` 等。

也可以在软件中点击"设置参数"按钮进行调整。

## 使用流程

1. **启动软件** → 自动初始化股票池
2. **点击"启动扫描"** → 执行完整选股+评分+吸筹识别
3. **查看各Tab页** → 龙头榜、竞价榜、吸筹榜
4. **盘中实时监控** → 自动刷新行情和信号
5. **买卖信号提醒** → 底部窗口实时弹出信号

## 扩展开发

### 添加新的行情API
继承 `market/api_base.py` 中的 `MarketAPIBase` 类，实现所有抽象方法，然后在 `data_manager.py` 中注册。

### 添加新的选股策略
在 `strategy/stock_filter.py` 中添加新的过滤方法。

### 添加新的评分维度
在 `strategy/quant_scoring.py` 中添加新的评分方法，并在 `score_stock` 中调用。
