## 三、为什么这一关会砍掉 94%

横盘周K 的建仓价公式（L1117~1121）：

```python
_vw = _vwap20(bars)                      # 中枢 = 20 日「量加权均价」
_entry = _vw - 0.6*_atr + _entry_shift(_f, _atr) + _theme_shift(_th_t, _atr)
```

`_vwap20` 是 20 日成交量加权均价。**横盘末期的价格已经抬到结构上沿附近，
而 20 日均价还留在横盘中部** —— 所以 `VWAP20` 天然低于现价。实测：

| VWAP20 相对现价 | 条数 |
|---|---|
| 落后 > 5% | 5 |
| 落后 2% ~ 5% | 22 |
| 落后 0% ~ 2% | 6 |
| 不低于现价 | 0 |

**33 条全部 VWAP20 低于现价**（0 条不低于）。再叠上 `-0.6×ATR`，
建仓价就离现价更远了。于是 B（建仓价距现价）分布：

| B 档 | 条数 | 闸门(B<=2.5%) |
|---|---|---|
| <= 0% | 0 | 保留 |
| 0 ~ 1% | 0 | 保留 |
| 1% ~ 2.5% | 2 | 保留 |
| 2.5% ~ 5% | 20 | 砍掉 |
| 5% ~ 10% | 11 | 砍掉 |
| > 10% | 0 | 砍掉 |

B 最小 **1.81%** / 中位 **4.38%** / 最大 **7.76%**

也就是说：**33 条的建仓价天然就落在离现价 1.8% ~ 7.8% 的位置，
而闸门卡在 2.5% —— 只有 2 只恰好落进来。这不是筛选，这是巧合。**

把 33 条按 B 分档，看每档的「上涨日放量满足率 up_rate」：

| B <= 1% | 0 | 0.0% | 0.0% |
| B 1~2.5% | 2 | 7.2% | 10.0% |
| B 2.5~5% | 20 | 17.2% | 20.0% |
| B > 5% | 11 | 21.7% | 20.0% |

**B 越大（VWAP20 落后越多）→ up_rate 越高。**

道理很简单：一只股票在横盘末期离 20 日均价越远，说明它在横盘期间「放量往上涨得多」——
那正是「阳线放量、资金进场」的表现。**闸门把 B 大的砍掉，
等于专门把「资金介入最明显」的筛掉。**

## 六、怎么办（三选一）

### 方案 1（推荐）｜横盘周K 的建仓价改锚「现价」，不再用 VWAP20

```python
# 现在（L1117~1118）
_vw = _vwap20(bars) or closes[-1]
_entry = _vw - 0.6*_atr + _entry_shift(_f, _atr) + _theme_shift(_th_t, _atr)

# 改成：和激进模式同一骨架，只是把中枢换成现价
_entry = closes[-1] - 0.3*_atr + _entry_shift(_f, _atr) + _theme_shift(_th_t, _atr)
```

- 理由：这个模式的语义就是**「周K放量确认之后上车」**，建仓参考价本来就该是
  「确认那一刻的价格（现价）附近」，而不是「20 日均价」。VWAP20 是「等回落」的中枢，
  和这个模式的方向不一致。
- 效果：建仓价自然落在现价下方 0.6%~1.5% → 闸门基本不再触发 →
  **横盘周K 从 2 条恢复到 33 条**。
- 闸门（B<=2.5%）保留做兜底，防 ATR 异常时给出过远的价格。

### 方案 2｜把横盘周K 的闸门放宽到 5%

- 效果：33 → 22 条；建仓价距现价 1.8%~5%（还是偏「等回落」的口径）。
- 不推荐：治标，中枢还是错的。

### 方案 3｜直接关掉横盘周K 的闸门

- 效果：33 条全进，但建仓价距现价 2.5%~7.8%，你之前说的「像接飞刀」的观感会回来。
- 不推荐。

### 另外一个独立的点（要不要一起改，你定）

当前「上涨放量」的门槛是 **整个横盘期只要出现 1 次放量就算过**（`up_ok >= 1`）。
33 条里 up_rate 最低的是 3.8%（26 个上涨日只有 1 天放量），这种其实不算「阳线放量」。
如果想让它更贴你的原意，可以把门槛提到「up_rate >= 20%」之类 ——
但这是新增条件，会增加剔除数量，所以单独列出来，你说要才加。33 条的 up_rate 分布：

| up_rate 档 | 条数 |
|---|---|
| 0 ~ 5% | 4 |
| 5% ~ 10% | 3 |
| 10% ~ 20% | 10 |
| 20% ~ 30% | 11 |
| > 30% | 5 |
