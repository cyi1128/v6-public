## 三、「激进」模式实际执行条件（代码逐条，非描述）

**锚点定义**：用户圈选的"基准日" = **洗盘日 D**；**启动日 S** 在 D 的前 1~2 个交易日。

| 阶段 | 条件 | 实现位置 |
|---|---|---|
| ① 启动日 S | `(close-open)/open >= 3%`（实体） | `detect_pattern_aggressive` |
| | `(close-前收)/前收 >= 3%`（涨幅） | 同上 |
| | `volume >= 前5日均量 × 1.0`（p5 严格取 `vols[k-5:k]`，不含当根/未来） | 同上 |
| ② 洗盘日 D | **`D.open > S.high`（严格跳空）** | 同上 |
| ③ 缩量整理 | 整理期（D 之后）**≥ 5 个交易日** | 同上 |
| | **十字星 ≥ 1 根**（`|close-open|/open <= 1%`） | 同上 |
| | 整理期均量 **≤ 启动日量 × 1.5** | 同上 |
| | **剔除长阴**：任一交易日 `跌幅 <= -5%` 且 `量 >= 启动日量×0.8` → 整个模式剔除 | 同上 |
| ④ 通则 | **整理期最低收盘 ≥ 启动日的前一日收盘**（跌破即失效） | 同上 |
| ⑤ 信号 | 🟢 **建仓触发**：今日回踩 MA5（±1.5%）且收盘站上 MA5，且量比 ≥ 1.0 | 同上 |
| | 🟡 **等待确认**：结构成立但尚未回踩 | 同上 |
| 建仓价 | `MA5 - 0.3×ATR + 共振修正`，夹在 `[通则线×1.002, 现价×1.01]` | 同上 |
| 失效价 | **通则线 = 启动日的前一日收盘** | 同上 |

> **注意**：搜索 D 时在最近 25 个交易日内**倒序**（从最近往早），取第一个满足全部条件者。
