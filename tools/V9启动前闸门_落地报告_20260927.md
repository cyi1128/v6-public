## 二、改动 1 实际代码（插在 `detect_pattern_aggressive` 内）

```python
        _M1_FUNNEL['struct'] += 1

        # ---------- 阶段⑤：启动前闸门（V9，2026-09-27 用户确认 15 日口径） ----------
        _ds = len(bars) - 1 - s                                # 启动日距今交易日
        if _ds > 15:
            continue
        _vs = (closes[-1] - sc['close']) / sc['close'] * 100    # 现价相对启动日
        if _vs > 15:
            continue
        _d5 = (closes[-1] - ma5_today) / ma5_today * 100        # 距 MA5
        if not (-2.0 <= _d5 <= 3.0):
            continue
        _mlb = _cur = 0                                          # 近 10 日最大连板
        for _j in range(max(1, len(bars) - 10), len(bars)):
            if bars[_j]['close'] >= bars[_j - 1]['close'] * 1.095:
                _cur += 1
                if _cur > _mlb:
                    _mlb = _cur
            else:
                _cur = 0
        if _mlb >= 2:
            continue
        if bars[-2]['close']:
            _tp = (today['close'] - bars[-2]['close']) / bars[-2]['close'] * 100
            if _tp >= 5:
                continue
        _hi25 = max(b['high'] for b in bars[-25:])               # 25 日结构位
        _lo25 = min(b['low'] for b in bars[-25:])
        if _hi25 > _lo25:
            _p25 = (closes[-1] - _lo25) / (_hi25 - _lo25) * 100
            if _p25 >= 95:
                continue
```

**位置特点**：插在「结构成立」之后、「触发/等待判定」之前 → **触发和等待确认同时受这 6 条约束**，不是只卡等待确认。

## 四、四个模式当前的完整执行条件

### 模式一「激进」（pattern_id = 1）

| 阶段 | 条件 | 阈值 |
|---|---|---|
| ① 启动日 S | 实体涨幅 | ≥ 3% |
| | 当日涨幅 | ≥ 3% |
| | 成交量 | ≥ 前5日均量 × 1.0 |
| ② 洗盘日 D | 跳空 | `D.open > S.high` |
| | 与 S 的距离 | S 后第 1~2 个交易日 |
| ③ 缩量整理 | 整理期长度 | ≥ 5 个交易日 |
| | 十字星 | ≥ 1 根（实体 ≤1%） |
| | 整理期均量 | ≤ 启动日量 × 1.5 |
| | 长阴剔除 | 任一日 跌幅 ≤-5% 且 量 ≥ 启动日量×0.8 → 整只剔除 |
| ④ 通则 | 整理期最低收盘 | ≥ 启动日前一日收盘 |
| **⑤ 启动前闸门（V9 新增）** | **启动日距今** | **≤ 15 交易日** |
| | **现价相对启动日** | **≤ +15%** |
| | **距 MA5** | **∈ [-2%, +3%]** |
| | **近 10 日最大连板** | **< 2** |
| | **今日涨幅** | **< 5%** |
| | **25 日结构位** | **< 95%** |
| 信号 | 🟢 建仓触发 | 回踩 MA5（±1.5%）+ 收盘站上 MA5 + 量比 ≥1.0 |
| | 🟡 等待确认 | 以上结构+闸门全过，但今天没回踩到位 |

### 模式三「横盘周K」（pattern_id = 3）

| 阶段 | 条件 | 阈值 |
|---|---|---|
| 第一关 | 本周量 ÷ 上周量 | ≥ 1.3 |
| | 本周 | 收阳 |
| 横盘窗口 | 长度 | 8~40 个交易日（从长到短取第一个全通过） |
| | 振幅 | ≤ 25% |
| | 低点抬高 | 后半段最低 > 前半段最低 |
| | 均价抬高 | 后半段收盘均价 > 前半段 |
| | 上涨日放量 | 量 ≥ 前5日均量×1.3，至少 1 次 |
| | 下跌日缩量 | 量 ≤ 前5日均量×1.0，满足率 ≥ 55% |
| **第三关（V9 改）** | **结构位** | **∈ [70%, 98%]**（贴在上沿下面，尚未突破） |
