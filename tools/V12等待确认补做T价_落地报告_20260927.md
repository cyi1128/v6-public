## 二、改成了什么

等待确认档没有 MA5 回踩价可用，就借用**分时做T的口径**给出参考买卖价：

```
VWAP = (当日最高 + 当日最低 + 当日收盘) / 3
买点 = VWAP - (0.3 - 0.1f) × ATR14      <- 写入「建仓价」列
卖点 = VWAP + (0.3 + 0.1f) × ATR14      <- 写入「止盈价」列
f = _resonance_f(bars)  引擎已有的共振因子，夹在 [-1, 1]
```

**为什么可以直接用**：分时做T（`ui/battle_widgets/atr_t_widget.py` L558~583）用的是
盘中实时的 `day_high / day_low / price`。收盘后这三个值就等于**当日 K 线的 H / L / C**，
所以盘后重算得到的就是分时做T在收盘那一刻的值 —— 两个模块口径完全一致。

## 四、⚠️ 有 18 条「买点略高于现价」，你要知道

分时做T公式算出来的买点，在 **66 条里有 18 条比现价高一点点**（最高 +1.11%）。

原因不是算错，是**公式的固有特性**：`VWAP = (H+L+C)/3`，当某只股当天**收盘落在日内区间的下部**
（弱势收盘）时，`VWAP > 收盘价`，于是 `VWAP - 0.23×ATR` 仍可能略高于收盘。

**最大偏差只有 +1.11%（1.68 元），大多数在 +0.06% ~ +0.8% 之间。**
我**没有加封顶**，因为你说的是「使用分时做t的买卖价」——
这里跟分时做T模块保持完全一致（那个模块也不封顶）。如果你想让它不高于现价，
加一行 `trig_price = min(trig_price, today['close'])` 就行，说一声。

## 八、口径对照（方便你对两个模块）

| | 分时做T（盘中） | 日K建仓·触发档 | 日K建仓·等待确认档（本次新增） |
|---|---|---|---|
| 中枢 | `(day_high+day_low+price)/3` 实时 | MA5 | `(H+L+C)/3` |
| 建仓价 | `VWAP - (0.3-0.1f)×ATR` | `MA5 - 0.3×ATR + 共振 + 题材` | `VWAP - (0.3-0.1f)×ATR` |
| 止盈价 | `VWAP + (0.3+0.1f)×ATR` | `建仓价 × 1.03` | `VWAP + (0.3+0.1f)×ATR` |
| ATR | 14 日 | 14 日 | 14 日 |

即：**等待确认档严格等于「分时做T口径」，触发档保持原有的 MA5 口径。**
