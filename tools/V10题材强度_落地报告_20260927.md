## 二、题材强度 t 的完整算法

```
t = 0.4 × t_行业  +  0.6 × t_概念 × 时效衰减          ，最终夹在 [-1, 1]
```

### t_行业（数据源：`industry_full_map.json` + `kline_cache.duckdb`）
```
行业涨停 >= 3 家  → +0.5        行业无涨停     → -0.5
行业均涨 >= 2%   → +0.3         行业均涨 >= 0.5% → +0.15
行业均跌 <= -1%  → -0.3
```
**覆盖验证**：`industry_full_map.json` 5211 条 / 30 个行业 / **"未知" 0 只**，全市场 5211/5211 全有行业。

### t_概念（数据源：`data/limit_up_reason.db` 表 `limit_up_reasons`）
```
当日该题材涨停家数  >= 8  → +0.5     >= 3 → +0.3     == 2 → +0.15     == 1 → +0.05     未上榜 → -0.2
时效衰减（距上次涨停）：<=3日 ×1.0   <=10日 ×0.6   <=20日 ×0.3   >20日 ×0
```
**数据存量**：17095 条，最近 12 个交易日连续；107 条建仓信号里 99 条能拿到题材（92.5%）。

### 建仓价
```
新公式 = 中枢 − k×ATR + shift_技术 + shift_题材
         shift_题材 = 0.4 × t × ATR，夹在 ±0.4×ATR 内
         中枢：激进=MA5（k=0.3）／横盘周K=VWAP20（k=0.6）
```

## 五、三个必须让你知道的真实问题

### 问题 1：调价幅度太小，救不了 600977 那类问题

**600977 中国电影 实测**：
```
现价 13.13   ATR 0.361   f(技术) +0.758
题材 t = +0.200        明细：题材[影视院线] 当日 0 家，距今 151 日
技术修正 +0.1370        题材修正 +0.0289
中枢(VWAP20) 12.834     k=0.6
旧建仓 12.75  →  新建仓 12.78   （只动了 0.03 元 / +0.23%）
```

**它仍在名单里，问题一点没解决。** 上一轮我指出 600977 的三个硬伤——止盈价=现价、建仓价低于 MA20、赔率 1:2.6——题材调价一个都没碰到。

**这印证了我上一轮的预判：「±0.4 ATR 的题材调整改不动根本问题」。** 根本问题在**结构位闸门分不清「横盘里横向走到 74.5%」和「从 13.67 回落到 71.7%」**，那需要的是「回落幅度闸门」，不是调价。

### 问题 2：概念项大面积失效 —— 权重 0.6 基本白给

抽查 11 只股票的概念项：

| 股票 | 概念 | 当日该概念涨停家数 | 距上次涨停 | 概念项结果 |
|---|---|---|---|---|
| 600977 中国电影 | 影视院线 | 0 家 | 151 日 | **归零** |
| 002290 禾盛新材 | 参股CPU | 0 家 | 2 日 | −0.2 |
| 603328 依顿电子 | 高端PCB | 0 家 | 1 日 | −0.2 |
| 002899 英派斯 | 健身器材 | 0 家 | 117 日 | **归零** |
| 603119 浙江荣泰 | 人形机器人 | 2 家 | 13 日 | +0.15×0.6=+0.09 |
| 605399 晨光新材 | 功能性硅烷 | 0 家 | 57 日 | **归零** |
| 002879 长缆科技 | 回购增持 | 0 家 | 38 日 | **归零** |

**根因**：`limit_up_reasons` 表里的 `reason` 是**个股级的具体涨停原因**（"参股CPU""高端PCB""功能性硅烷""回购增持"），不是**板块级概念**（"人形机器人""存储芯片""海峡两岸"）。

09-24 涨停榜 top：海峡两岸 10 家、"华"字辈 8 家、福建国资 3 家、半年报增长 3 家……**除了前两个，其余 130 多个题材全是 1~2 家。**

**结果**：`≥8家 +0.5` 这一档几乎只有"海峡两岸"能触发；绝大多数股票概念项要么是 −0.2、要么被时效归零。**权重 0.6 实际起作用的时候很少。**

### 问题 3：题材闸门效果极弱（只剔 1 只）

**数学上 t 的最低值**：
```
t_ind 最负 = -0.5（无涨停）- 0.3（均跌超1%） = -0.8
t_con 最负 = -0.2
t_min = 0.4×(-0.8) + 0.6×(-0.2) = -0.44
```

**所以 t 的理论下界只有 −0.44，而闸门设在 −0.4** —— 只有"行业无涨停 + 行业均跌超 1% + 概念未上榜且有近期涨停"三条同时命中才够得着。106 条里只有 1 只。

**闸门形同虚设。**
