# 一、为什么原来的「盘中监控」是误导

原代码（`_daily_on_loaded`）：

```python
if now.weekday() >= 5:
    tag = '休市'
elif ((h == 9 and m >= 30) or h == 10 or (h == 11 and m <= 30)
      or h == 13 or h == 14) and h < 15:
    tag = '盘中监控'          # ← 按"当前时间"打标签
else:
    tag = '盘后复盘'
self._last_daily_title = f'📈 日K建仓 ({tag}) · {len(self._daily_rows)}只'
```

标签只反映「**现在几点**」，完全不反映「**数据是哪天的**」。
于是盘中打开这个 Tab，看到 `(盘中监控)`，会以为它在实时选股 ——
但信号其实是**盘前 08:46 扫描、数据基准日 9/23** 的静态结果。

# 四、关于源码里还残留的「盘中监控 / 盘后复盘」

搜出来 3 处，**全部在「分时做T」模块，不是日K建仓，故意没改**：

| 行号 | 内容 | 所属模块 | 该不该改 |
|---|---|---|---|
| 369 | `self.set_status('盘后复盘')` | 分时做T `refresh()` | **不改** |
| 821 | `tag = '盘中监控'` | 分时做T `_render_hold_table` | **不改** |
| 825 | `tag = '盘后复盘'` | 分时做T `_render_hold_table` | **不改** |

原因：分时做T **确实是实时跟踪的** —— 它 `start_refresh(5000)` 每 5 秒拉一次实时行情
（`_fetch_and_calc` 第 766 行 `get_realtime_quotes_http`），
标题是 `🎯 分时做T (盘中监控) · 持仓N`。
在它身上「盘中监控」是**准确的**，改了反而失真。

两个模块的标题现在分别是：

```
🎯 分时做T (盘中监控) · 持仓N          ← 实时跟踪，标签准确
📈 日K建仓 (盘中·数据09-23) · 178只     ← 静态信号 + 实时行情，已如实标注
```
