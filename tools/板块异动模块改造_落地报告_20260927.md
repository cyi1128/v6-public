## 一、先说一个卡点：东财板块接口已经不可用了

`strategy.theme_analyzer.get_concept_market()` 走的是东财概念板块接口：

```
https://push2delay.eastmoney.com/api/qt/clist/get
-> RemoteDisconnected("Remote end closed connection without response")
```

**连着重试 3 次，返回 0 条，耗时 0.2~0.3 秒（秒断）。**
所以「今日板块/行业/题材异动」**不能依赖在线板块行情**，改成全部本地聚合。
这也顺带解释了之前「今日涨停模块数据不全」「竞价模块没数据」的一部分原因。

### 聚合规则

```
题材：涨停原因 reason 按 + / ＋ / · / 、 / / 拆词
      -> 例「海峡两岸+工程机械+盾构机+智能矿卡」拆成 4 个关键词
      -> 长度 2~12、去重、去掉中文引号（「“华”字辈」-> 「华字辈」）
      -> 同关键词 >= 2 家才算「异动」

行业：涨停股的 industry 字段聚合，>= 2 家才算异动
      同时算该行业「全市场均涨幅」（样本来自 industry_full_map.json）

排序：家数降序 -> 均涨幅降序；题材和行业混排
```

## 六、有一件事我没有自作主张

**没有做 ST 过滤，也没有做主板过滤。**

原因：「海峡两岸」的领涨股是 **300300 海峡创新（创业板，+19.98%）**，
过滤掉创业板，「海峡两岸」就只剩 8 家、领涨股也变了 —— 题材爆发的真相就是全市场一起动。

但你在其他模块明确要求过「只筛主板、剔除 ST」。所以这一块留给你定：

- **保持现状**（不过滤，看全貌）—— 需要我改就说「保持」
- **只保留主板 + 剔除 ST** —— 说「过滤」我就加，加完「海峡两岸」会变 8 家
