## 一、问题出在哪（精确到文件行号）

### 问题 1：模式一「激进」的「等待确认」分支没有任何当下位置约束

**文件**：`services\band_pattern_engine.py`　**行号：L670~L673**

```python
        else:
            level = LVL_WAIT
            trig_type = '等待MA5回踩'
            trig_price = 0
```

只要**最近 25 个交易日内存在过一个合格结构**（S 启动 + D 跳空 + 缩量整理 + 通则），就**无条件**进"等待确认"，
**完全不检查今天涨了多少、离 5 日线多远、已经比启动日高了多少。**

→ 所以一只 8/21 启动、到今天已经涨了 27% 的股票，仍然挂着"等待MA5回踩"。
→ 而 UI 默认显示「建仓触发 + 等待确认」，所以这些全都出现在你眼前。

### 问题 2：模式三「横盘周K」的第三关要求"已经突破上沿"

**文件**：`services\band_pattern_engine.py`　**行号：L829~L831**

```python
    # ---------- 第三关：本周收盘突破横盘上沿（上沿不含触发周） ----------
    if w_now['close'] <= hi:
        return None
```

**只有周K收盘已经突破横盘上沿，才给信号。** 这是"突破后追入"，方向与你要的"启动前"正好相反。
`横盘周K 55 只` 全部都是这一类。

## 五、模式三「横盘周K」改法

**把 L829~L831 的"已突破上沿"换成"接近上沿但尚未突破"：**

```python
# 原： if w_now['close'] <= hi: return None      ← 突破才给信号（追涨）
# 改： 结构位置 = (现价 - 横盘下沿) / (横盘上沿 - 横盘下沿)
#     要求 0.70 <= 结构位置 <= 0.98            ← 蓄势待发，还没启动
```

`_sim_prelaunch.py` 全市场实测（3018 只主板）：

| 口径 | 产出 |
|---|---|
| 原版（要求已突破上沿） | 63 只 |
| **改版 结构位 ∈ [70%, 98%]** | **50 只** |
| 改版 结构位 ∈ [70%, 90%] | 36 只 |

> 注意：这两批是**不同的股票**。原版 63 只全是"已经突破的"，改版 50 只是"贴在上沿下面还没走的"。
> 周K放量条件（本周量 ≥ 上周量×1.3 且收阳）**保留不动**。

## 六、我的推荐

**方案 A（40 只）+ 模式三改「接近上沿未突破」**，理由：

1. `启动日≤10日` 解决你说的"基准日太久、行业都过去了"；
2. `比启动日≤15%` 解决"已经涨过一波"；
3. `距MA5 ∈[-2%,+3%]` 解决"远离5日线、接飞刀"（单条剔除 113 只，最有效）；
4. `近10日无2连板 + 今日<5% + 结构位<95%` 兜底，把连板股和当天涨停的挡在外面；
5. 模式三反过来做，从"突破后追"改成"突破前埋"。

**需要你确认一个数**：`启动日距今` 卡 **10 日**（严，40 只）还是 **15 日**（宽，88 只）？
其余五条我建议照上面直接落地。
