## 三、三个决定性发现

### 发现 1：**"启动日"根本不是跳空高开**

**S 的跳空幅度（`开盘 - 前一日最高`）：-11.68% ~ +1.94%**

| 条件 | 通过 |
|---|---|
| **S 跳空 > 0%** | **1 / 14（7.1%）** |

14 个案例里**只有 1 个**（芯碁微装 +1.94%）真的是跳空高开。其余 13 个启动日的开盘都**低于前一日最高价**，是**平开/低开高走的大阳线或涨停**。

**这就是"模式一（跳空回踩）"命中率只有 2/13 的根本原因——它要求 `open > 前一交易日 high`，而你的实际形态里 13/14 都不满足。**

**结论：「跳空高开」这个模式名和你的真实玩法不符。真实玩法是"放量大阳启动"。**

### 发现 2：**洗盘日 D 就是启动日的次日**

| 间隔 | 通过 |
|---|---|
| **间隔 1 日** | **13 / 14（92.9%）** |
| **间隔 1~2 日** | **14 / 14（100%）** |

**洗盘日 = 启动日的第 1~2 个交易日。** 没有例外。

### 发现 3：**启动日的形态特征高度统一**

| 条件 | 通过 |
|---|---|
| **S 实体 ≥ 3%** | **14 / 14（100%）** |
| **S 是阳线** | **14 / 14（100%）** |
| **S 涨幅 ≥ 3%** | **14 / 14（100%）** |
| S 涨幅 ≥ 5% | 11 / 14（78.6%） |
| S 涨停 | 9 / 14（64.3%） |
| S 量 ≥ 1.2 倍 | 12 / 14（85.7%） |
| S 量 ≥ 1.0 倍 | 13 / 14（92.9%） |

**"涨幅≥3% 且 实体≥3% 且 收阳"三条 100% 命中。**

## 五、建议的新规则（合并为一个模式）

```
【阶段① 启动日 S】（必须是洗盘日 D 的前 1~2 个交易日）
    实体涨幅 (close-open)/open >= 3%     ← 14/14 命中
    当日涨幅 >= 3%                        ← 14/14 命中
    成交量 >= 前5日均量 × 1.0             ← 13/14 命中
    （不再要求"跳空"—— 实测 13/14 都不跳空）

【阶段② 洗盘回落日 D】
    有上影：上影 (high-max(open,close))/max(open,close) >= 1%   或   收阴
    ← 13/14 命中

【阶段③ 缩量整理】（D 之后）
    整理期 >= 5 个交易日                  ← 14/14 命中
    整理期出现 >= 1 根十字星或小实体(<=3%) ← 14/14 命中
    整理期均量 <= 启动日量 × 1.5           ← 14/14 命中
    整理期不破通则                        ← 13/14 命中

【阶段④ 通则保护】（你说"通则"，我按这条实现）
    整理期最低收盘 >= 启动日的前一日收盘
    ← 13/14 命中

【信号分级】
    🟡 结构成立但未回踩    → "等待确认"
    🟢 回踩 MA5（±1.5%）且收盘站上 → "建仓触发"
    🔴 整理期跌破通则      → "失效"
```

**预期覆盖：14 案例中 12 个能形成"结构候选"，其中 11~12 个最终能出现"回踩 MA5"触发。**

### 关于"无放量长阴"这条

实测只有 9/14 命中（协和电子 08-28、09-14 等 5 个案例在整理期有放量长阴）。
