## 二、为什么没用上一轮说的「赔率 ≥ 1.0」

先做了一次勘察（`_survey_gates2.py`），对 V10 的 40 条触发逐条重算赔率：

```
赔率 = (止盈价 - 建仓价) / (建仓价 - 失效价)
  min = 0.175   P25 = 0.241   中位 = 0.283   max = 0.900
  >= 1.0 : 0 条   <-- 会把 40 条全部剔光
```

**原因不是个别股票差，而是结构性冲突**：止盈价固定 = 建仓价 × 1.03（只 +3%），
而失效价 = 横盘最低（横盘振幅 15~25% 意味着下行有 15~25%）。
**上行 3% 对下行 20%，赔率数学上必然落在 0.2~0.4。** 这个阈值等于删掉整个模式，不能用。

勘察同时暴露了**更根本的问题**：

```
U =（现价 -> 止盈的空间）分布：
  min = -4.97%   中位 = -1.03%   max = +3.44%
  U >= 0% : 只有 12 条 / 40 条
```

**中位数是 −1.03% —— 过半记录的止盈价已经低于现价。**
等于程序在说：「等它跌 4% 到 VWAP20 买入，再涨 3% 到止盈」，而那 3% 只是回到今天。
**这不是选股问题，是「建仓价 / 止盈价」公式本身的设计问题**（见第八节）。

## 四、闸门规则

```
B =（现价 - 建仓价） / 现价 × 100
B > 2.5%  ->  不产生「建仓触发」，整只不记录
```

**作用范围**：只作用于「建仓触发」。
「等待确认」的股票本来就买不了（还在等回踩 MA5 / 等周K），建仓价是将来目标位，
距现价远一点是合理的 —— 所以 66 条等待确认一条未动。

**为什么是 2.5%**（勘察实测）：

| 阈值 | 保留 | 600977 | 600218 | 001322 |
|---|---|---|---|---|
| B ≤ 2.0% | 8 条 | 剔除 | 剔除 | 剔除 |
| **B ≤ 2.5%（采用）** | **9 条** | **剔除** | **剔除** | **剔除** |
| B ≤ 3.0% | 12 条 | ❌ 反被保留 | ❌ 被保留 | ❌ 被保留 |

三只问题股都在 2.6~2.7%，所以阈值必须在 2.5% 或以下；取 2.5% 比 2.0% 少剔 1 只（605208 永茂泰 B=2.24%）。

> 顺带一个数学结论：`现价→止盈空间 U = 3% − 1.03×B`。所以「卡 B ≤ 2.5%」和「卡现价到止盈至少还有 1% 空间」是同一件事，不必重复加两条。

## 十、这次只治了「症」，根还在「建仓价公式」

闸门的作用是**把不合理的记录挡在门外**，但它没有让任何一条记录变得更好。
勘察数据说明根因：

```
激进模式建仓价  = MA5    - 0.3×ATR + 共振修正
横盘周K建仓价   = VWAP20 - 0.6×ATR + 共振修正      <- 中枢落后现价最多
止盈价         = 建仓价 × 1.03                     <- 固定 +3%
失效价         = 通则线 / 横盘最低
```

**两个结构性问题**：

1. **横盘周K 的中枢用 VWAP20（20 日成交量加权均价）**，横盘末段价格已经抬升，VWAP20 天然落在现价下方 3~8%。33 条触发里 31 条因此超标 —— 这次闸门砍掉的 31 条，本质上都是**一个落后中枢造成的**。
2. **止盈价锚在「建仓价」而不是锚在「现价或结构上沿」**，导致现价越高、（建仓价×1.03）反而越低于现价，出现「止盈比现价还低」的荒谬结果。

所以下一步有两个可选方向（**我没动，等你定**）：

- **A｜横盘周K 换中枢**：VWAP20 → MA5/MA10 或「结构上沿 - 0.5×ATR」，让建仓价自然贴在现价下方 1~2%，闸门以后基本不会触发。
- **B｜止盈价改锚**：止盈价从「建仓价×1.03」改成锚定结构上沿（如 `结构上沿 × 1.02`），这样横盘末端买入才有真正的空间，赔率才有意义。

要不要做、做哪个，你说一声。
