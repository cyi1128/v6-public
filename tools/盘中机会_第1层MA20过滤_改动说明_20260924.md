## 三、实际执行条件

**数据源**：`D:\QuantMonitorV6\data\cache\kline_cache.duckdb`

**SQL**（一条窗口函数算完全市场，不逐只查）：
```sql
WITH ranked AS (
  SELECT code, close,
         ROW_NUMBER() OVER (PARTITION BY code ORDER BY date DESC) AS rn
  FROM kline_cache
)
SELECT code, AVG(close) AS ma20, COUNT(*) AS n
FROM ranked WHERE rn <= 20 GROUP BY code
```

**执行规则**：
- 取数要求 `n >= 20` 且 `ma20 > 0`，否则该股不入映射
- 映射缓存 **600 秒**（10 分钟）
- **取不到 MA20 时本轮不做过滤** —— 既不误杀，也不阻塞主流程
- 剔除条件只有一条：**现价 < MA20**

**为什么能放在第 1 层**：实测一条 SQL 算全市场 MA20 只要 **0.06 秒**（3059 只）。而逐只调 `get_latest_kline` 是 26 ms/只，全市场要 80 秒，超过 25 秒的扫描周期，那样才不可行。
