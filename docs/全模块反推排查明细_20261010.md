## 三、本次改动清单（4 个文件 / 6 处，全部已编译通过）

### 3.1 `services\band_pattern_engine.py`（纯 LF，1619 → 1638 行）★影响选股

| 行号 | 改前 | 改后 |
|---|---|---|
| **L124**（新增） | — | 新增 `_lu_threshold(code)`：主板 9.5% / 创业板·科创板 19.5% / 北交所 29.5% |
| **L464** | `'limitup': sum(1 for x in ps if x >= 9.5)` | `'limitup': sum(1 for c, x in ps if x >= _lu_threshold(c))` |
| 同段 | `agg[...].append(p)` | `agg[...].append((code, p))`（保留 code 才能按板判） |
| 同段 | `'avg': sum(ps) / len(ps)` | `'avg': sum(x for _c, x in ps) / len(ps)` |
| 同段 | 大盘 `'limitup': sum(... if x >= 9.5)` | 大盘同口径按板判定 |
| **L155** | `_is_limit_up` 注释写"9.8%" | 更正注释，并注明**该函数全项目无任何调用**（死代码，模式一基准日实际用"实体≥3% 且涨幅≥3%"判定） |

**为什么这处最要紧**：行业涨停家数 / 大盘涨停家数喂给「环境分」和「题材因子」，直接参与日K建仓的等级与排序。旧口径下创业板 +10%~19.4% 的非涨停股被算成涨停 → 涨停家数虚高 → 环境分偏高。

**真实数据实测**（2026-10-09 / 10-08，4411 只可比对）：

| 口径 | 涨停家数 |
|---|---|
| 旧（全市场统一 9.5%） | **87 家** |
| 新（主板9.5 / 创业板·科创板19.5 / 北交所29.5） | **69 家** |
| 差异 | **18 家**（创业板 17 + 科创板 1） |

交叉校验：独立重算 18 家 == 差异 18 家 → **一致**；引擎实际输出 `涨停69家` == 独立重算 69 家 → **一致**。

被纠正的真实个股（涨幅最高的 5 只）：

| 代码 | 改前被误算为涨停的实际涨幅 |
|---|---|
| 300340 | +15.89% |
| 300111 | +14.81% |
| 300019 | +13.62% |
| 301087 | +13.50% |
| 301551 | +13.04% |
