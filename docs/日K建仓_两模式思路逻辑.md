# 日K建仓模块 — 两个模式的思路逻辑

> 核对日期：2026-10-09 ｜ 全部内容按 `services\band_pattern_engine.py`（1362 行）实际代码逐条摘出，非记忆、非推测。

---

## 0. 一句话核心

**不是看到一根大阳线就推荐买入。**

识别链条固定为：

```
启动 / 吸筹迹象  →  缩量整理（结构不被破坏）  →  关键均线 或 周K 确认  →  建仓
```

程序输出的是「**建仓条件正在形成**」，不是追涨信号。

## 3. 前置过滤（`scan_stock()` L1175–1196）

| 顺序 | 条件 | 不满足 |
|---|---|---|
| 1 | `_is_main_a_share(code)` — 主板 600/601/603/605/000/001/002/003 | 剔除 |
| 2 | `_is_st(name)` — 非 ST / 退市 | 剔除 |
| 3 | `_load_bars(code)` 取到 K 线 | 剔除 |
| 4 | K 线长度 ≥ 30 | 剔除 |
| 5 | MA5 / MA20 可算 | 剔除 |
| 6 | `today['close'] >= MIN_PRICE`（**6.0 元**） | 剔除 |
| 7 | **MA20 过滤**（见下） | 降级为「观察」 |

> 第 1、2 步放在取 K 线**之前** —— 全市场 5221 只里 2000+ 只是创业板/科创板/北交所，原先「先取数再过滤」等于每只白跑一次在线请求（约 1.3 秒/只），是全市场扫描慢几十倍的主因。

### MA20 过滤（V15，2026-10-09 补实现）

**原来是空注释。** `L1194` 写着 `# MA20硬过滤：MA20下方只能观察不能建仓`，但下面没有任何代码 —— `ma20` 只被算出来、判了个非空、写进记录，**从未参与过滤**。现已补齐。

口径（按注释原意 + 你 2026-09-26 确认过的版本，**不是「跌破就删」**）：

| 情形 | 处理 |
|---|---|
| 现价 **≥** MA20 | 不变 |
| 现价 **<** MA20 **且原判为「建仓触发」** | **降级为「观察」**，`trigger_type` = `MA20下方·筑底观察` |
| 现价 **<** MA20 但原判为「等待确认」 | 保持不变（等待确认本来就不能买） |

**为什么不直接 `return []` 剔除整只：** 模式三「横盘周K」本身就是底部构筑形态，启动前现价贴近 MA20、甚至短暂在其下方是常态，硬删会误杀正样本。所以只**降级**，记录保留做筑底观察。

实测（500 只样本，写暂存表不碰主表）：

```
产出记录 18 条  ->  等待确认 11 / 建仓触发 5 / 观察 2
现价 < MA20 的记录 4 条，其中 2 条被降级为观察
[降级] 001218 丽臣实业  现价 23.52  MA20 23.67  差 -0.63%
[降级] 001220 世盟股份  现价 31.50  MA20 31.64  差 -0.44%
断言 A/B/C 全过；漏斗 trigger=5 与记录数一致；ma20_below=2 与降级数一致
```

## 4. 模式一「激进」（pattern_id = 1）

### 完整链条

```
启动大阳 S  →  次日/隔日 洗盘日 D 跳空高开  →  缩量整理  →  回踩 MA5  →  建仓
```

### 阶段① 启动日 S（D 的前 1~2 个交易日）

| 条件 | 阈值 |
|---|---|
| 实体涨幅 `(close-open)/open` | **≥ 3%** |
| 当日涨幅 `(close-前收)/前收` | **≥ 3%** |
| 成交量 | **≥ 前5日均量 × 1.0** |

> 前5日均量严格 `p5 = sum(vols[k-5:k]) / 5` —— 不含当根、不含未来。

### 阶段② 洗盘日 D

| 条件 | 阈值 |
|---|---|
| D 的位置 | 最近 **15 个交易日**内倒序搜索（D 之后还要有 ≥5 根） |
| 跳空 | **`D.open > S.high`** |

### 阶段③ 缩量整理（D 之后）

| 条件 | 阈值 |
|---|---|
| 整理期长度 | **≥ 5 个交易日** |
| 十字星 | **≥ 1 根**（实体 `abs(close-open)/open ≤ 1%`） |
| 缩量 | 整理期均量 **≤ 启动日量 × 1.5** |
| 长阴剔除 | 任一交易日 跌幅 ≤ -5% **且** 量 ≥ 启动日量×0.8 → **整个模式剔除**（continue，往前找更早的 D） |

### 阶段④ 通则线

`rule_line = 启动日的前一日收盘`

整理期最低收盘 **< `rule_line`** → 模式失效。

### 阶段⑤ 启动前「六闸门」（V9，2026-09-27 你确认）

| 闸门 | 阈值 | 立此条的依据（实测 242 只等待确认逐只读K线） |
|---|---|---|
| 距启动日 | **≤ 15 个交易日** | 68% 的旧候选启动至今 > 10 日 |
| 现价 / 启动日收盘 | **≤ +15%** | 17.8% 超了 |
| 距 MA5 | **-2.0% ~ +3.0%** | 46.7% 超了 ±3% |
| 近 10 日最大连板 | **< 2** | 31.8% 近10日有涨停 |
| 今日涨幅 | **< +5%** | 当日已冲高 |
| 25 日结构位 | **< 95%** | 贴顶 |

### 触发判定

```
|close - MA5| / MA5 ≤ 1.5%   且   close ≥ MA5   且   量比 ≥ 1.0
   → 🟢 建仓触发   trigger_type = '激进·建仓触发'
否则
   → 🟡 等待确认   trigger_type = '等待MA5回踩'（UI 显示「等五踩」）
```

### 建仓价 / 止盈 / 失效价

```
ATR  = 14日 ATR（真实波幅均值；不足则 close × 0.02）
f    = 共振因子 ∈ [-1, 1]
        = 趋势排列 ±0.7（ma5>ma10 给 +0.4，ma10>ma20 给 +0.3）
        + 5日动能 ±0.2
        + 量能   ±0.1
```

**触发档：**

```
建仓价 = MA5 - 0.3×ATR + 共振修正 + 题材修正
        夹在 [rule_line × 1.002,  现价 × 1.01]
止盈价 = 建仓价 × 1.03
失效价 = rule_line（启动日前一日收盘）
有效期 = 基准日 D 之后第 20 个交易日
```

**等待确认档**（还没有 MA5 回踩价，借用「分时做T」口径给参考买卖价）：

```
VWAP   = (最高 + 最低 + 收盘) / 3
建仓价 = VWAP - (0.3 - 0.1f) × ATR     ，封顶 ≤ 现价
止盈价 = VWAP + (0.3 + 0.1f) × ATR
```

**共振修正量** `_entry_shift(f, atr)`：

| f | 修正 | 含义 |
|---|---|---|
| `f ≥ 0` | `0.5 × f × ATR` | 强势 → 上移（不必等太深） |
| `f < 0` | `0.8 × f × ATR` | 弱势 → 下移（要更厚的安全垫） |

### 建仓价闸门（V11）

`(现价 - 建仓价) / 现价 > 2.5%` → **不产生「建仓触发」**（`_ENTRY_GAP_CAP = 2.5`）

> 亲历案例 600977 中国电影：现价 13.13 / 建仓 12.78（差 2.67%）。到价要连穿 **今日低 13.09 → MA10 13.01 → 9/21 低 12.93 → MA20 12.86** 四道支撑；且止盈 13.16 只比现价高 0.23%，等于没有获利空间 —— 属于接飞刀。
> 40 条实测：B≤2.5% 保留 9 条；600977 / 600218 / 001322（2.6~2.7%）被剔除。
> 只作用于「建仓触发」，等待确认的股票本来买不了，不受影响。

## 5. 模式三「横盘周K」（pattern_id = 3）

### 完整链条

```
底部横盘（阳线放量抬升 / 阴线缩量回撤 / 低点逐渐抬高）
  → 本周成交量 > 上周（放量）且本周收阳
  → 现价结构位落在 [70%, 98%]（贴在上沿下面，还没突破）
  → 建仓
```

### 第二关：横盘窗口（8 ~ 40 个交易日，**从长到短取第一个全通过者**）

窗口 = `bars[si-length : si]`，`si` = 触发周第一根日K的下标，`length` 从 40 递减到 8。

| # | 条件 | 阈值 |
|---|---|---|
| 1 | 结构振幅 `(hi-lo)/lo` | **≤ 25%** |
| 2 | 低点抬高 | **后半段最低 > 前半段最低** |
| 3 | 上涨放量 | 上涨日 量 ≥ 前5日均量 × 1.3，**至少出现 1 次** |
| 4 | 价格抬升 | **后半段收盘均价 > 前半段收盘均价** |
| 5 | 下跌缩量 | 下跌日 量 ≤ 前5日均量 × 1.0，**满足率 ≥ 55%** |
| 6 | 前5日均量 | `p5 = sum(vols[i-5:i]) / 5`，**不含当根、不含未来** |

> 条件 4 是德豪润达(002005)用出来的：它 8/14 那天既有 32 日窗口（上沿 2.63，含 6/24 一次冲高）也有 14 日窗口（上沿 2.45）。缺了这条会选中 32 日窗口而**永久卡死**；补上后正好选中 14 日窗口并突破。

### 第一关：周K（日K聚合，`_to_weekly()`）

```
本周成交量 ≥ 上周成交量 × 1.3    且    本周收阳（close > open）
```

> 最后一周若尚未走完，量取「本周至今累计」，仍与上周完整周量比较 —— 该判据随本周推进**单调变宽松**，不会中途忽真忽假。

### 第三关：结构位（V9，2026-09-27 口径改）

```
结构位 = (现价 - 下沿) / (上沿 - 下沿) × 100     必须落在 [70%, 98%]
```

**原版要求「周K收盘 > 横盘上沿」= 突破后追入，与你「买在启动前」的方向相反 —— 实测 63 只全是已经突破完的。** 改成贴上沿未突破。

### 建仓价 / 止盈 / 失效价（V14）

```
建仓价 = 现价 - 0.3×ATR + 共振修正 + 题材修正
        夹在 [横盘最低 × 1.002,  现价 × 1.01]
止盈价 = 建仓价 × 1.03
失效价 = 横盘最低
有效期 = 基准日之后 14 个自然日
```

**V14 变更记录**（中枢从 `_vwap20` 改为「现价」，系数 0.6 → 0.3，与激进模式同一骨架）：

- 本模式语义是「**周K放量确认之后上车**」，建仓参考价应当是「确认那一刻的价格附近」；
- `VWAP20` 是 20 日量加权均价，横盘末期价格抬升后它**天然落后现价**（实测 33 条里 22 条落后 2~5%）；
- 再叠 `-0.6×ATR` 后，建仓价距现价普遍 2.5~7.8%，被 V11 闸门砍掉 **94%（33 → 2）**；
- 且 B 越大代表横盘期间放量上涨越多 = 资金介入越明显，**闸门方向与形态质量相反**。

换中枢后此闸门基本不再触发，保留作兜底（防 ATR 异常放大时给出过远的建仓价）。

## 6. 两个模式共用的部分

### 6.1 题材闸门（V10，2026-09-27 你确认启用）

```
t = _theme_strength(code) ∈ [-1, 1] = 0.4 × 行业项 + 0.6 × 概念项
t < _THEME_GATE (-0.4)  →  整个候选剔除
```

**放在触发判定之前**，因此对「建仓触发」和「等待确认」**同时生效**。

| 项 | 明细 |
|---|---|
| 行业项（当日行业截面） | 涨停 ≥3 家 **+0.5** ／ 无涨停 **-0.5**；均涨 ≥2% **+0.3** ／ ≥0.5% **+0.15** ／ ≤-1% **-0.3** |
| 概念项（涨停原因库 + 时效衰减） | 当日该题材涨停家数 ≥8 **+0.5** ／ ≥3 **+0.3** ／ ==2 **+0.15** ／ ==1 **+0.05** ／ 未上榜 **-0.2** |
| 时效衰减 | 距上次涨停 ≤3 日 **×1.0** ／ ≤10 日 **×0.6** ／ ≤20 日 **×0.3** ／ 更久 **×0** |

无数据时 `t = 0.0`（不改变建仓价，也不触发闸门）。

### 6.2 题材修正建仓价

```
_theme_shift(t, atr) = 0.4 × t × ATR     夹在 ±0.4 × ATR
```

题材强 → 建仓价上移（强势不必等太深，避免踏空）
题材弱 → 建仓价下移（要更厚的安全垫）

### 6.3 环境分 env_score

按当日市场/行业温度给出**建仓力度建议**：**≥6 正常建仓 / 3~5 谨慎 / ≤2 不建仓**

依据 2025 全年 3564 条历史触发的分档实测：

| 分档 | 后续收益 |
|---|---|
| 行业涨停 ≥3 家 | +0.59 ~ +0.83% ｜ 0 家：-0.63% |
| 行业均涨 1~3% | +0.53% ｜ >3% 过热(一日游)：+0.14% |
| 行业上涨占比 30~70% | +0.28% ｜ >70%：收益归零 |
| 大盘杀跌 < -1.5% | **+2.05%（逆势真强）** ｜ >1.5% 普涨：-0.85% |
| 个股振幅 <4% | +0.41% ｜ >7%：-0.73% |
| 个股量比 <1.0 | **+0.98%** ｜ >2.5：缩量更优 |

数据源：`data\cache\kline_cache.duckdb` 最新两个交易日收盘价。构建失败不抛异常，扫描照常进行，环境分退化为只看个股自身。

## 10. 扫描与输出

`scan_all()` 的运行方式：

1. 清空暂存表 `pattern_record_new`
2. 构建当日环境截面 + 题材热度截面
3. 逐只 `scan_stock()`
4. `_atomic_swap()` 把暂存表**原子替换**成主表

> 旧做法是「先 DELETE 主表再逐条 INSERT」—— UI 在 13 分钟扫描期间会读到空表/半截表。新做法扫描期间主表保持上一次的完整结果。

扫描尾部打印漏斗：

```
[模式一（激进）漏斗]
  启动日S成立(实体>=3%+涨幅>=3%+量>=1.0)
  洗盘日D跳空(D开>S最高)
  缩量整理成立(>=5日/十字/缩量/无长阴/通则)
  回踩MA5→建仓触发
  题材冷剔除(t<-0.4)
  建仓价距现价>2.5%剔除

[模式三（横盘周K）漏斗]
  本周放量收阳(>=上周1.3倍)
  横盘结构成立
  结构位70~98%近上沿→触发
  题材冷剔除(t<-0.4)
  建仓价距现价>2.5%剔除
  周K达标但无合格横盘窗口
```

## 11. 写进代码注释的验证依据

| 模式 | 取证方式 |
